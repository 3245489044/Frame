## 1. 落地口径（与设计稿的两处细化）

| # | 细化 | 理由 |
|---|---|---|
| 1 | 边端点用 `NodeEdgeEndpoint(Kind, Id)`，不把容器/工作流键塞进 `NodeAddress.NodeKey` | `NodeAddress.NodeKey` 的语义是逻辑节点；容器键塞入会破坏 A1。节点/实例端点经 `Of(NodeAddress)` 等价表达 |
| 2 | `NodeWriteWork.Medium`、`NodeExecutionBinding.Behavior` 用 `string` | 介质词（sqlite/graph/config）与 LLM 词属宿主；进框架即破 K1/R4/R9 |

其余按设计稿推荐值执行：U1=A（`@` 并入键文法族）、U2=A（整体拒绝 + 逆序补偿）、U3=A（并存 + `NodeEdge` 视图）、U4=A（信号/预算全声明）、U5=A（`NodeArtifact` 通用化）、U6=A（仅 `Owns` 继承）、U7=A（P-F 一次完成）。

## 6. 已知边界

- 读侧 `SelectionSet` 过滤仍在投影内完成，`NodeSelectionResult.Dropped` 只列信号/limit/budget 三类原因（selection 丢弃不可枚举）；
- `NodeArtifactAssembler.LastProduced` 以「到达序最后一个」为判定（框架不解释“是否产出”）；
- `NodeEdge` 端点 Kind 词表开放（节点/容器/工作流 + 资源类型），跨域词面由宿主声明；
- `NodeFramework.WritePlans` 在未注入介质端口时为 `null`（显式可空，不伪造成功路径）。
