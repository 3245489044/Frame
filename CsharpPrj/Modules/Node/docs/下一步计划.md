## 7. 风险与回退

| 风险 | 触发点 | 缓解 / 回退 |
|---|---|---|
| **委托后行为漂移**（最高风险） | A-1/A-2 改件 | 每件先加对拍用例；旧位保留入口只转发；出现回归即回退该件（单点回退，不影响其它件） |
| **可见化引发日志噪声** | A-1.3 反射兜底改带诊断 | 噪声即目的（治 P15）；如量级过大，先按域降低到 `Info` 级并保留计数 |
| **读视图"先到者胜"随枚举序漂移** | A-1.1 | 必须显式声明「枚举序 = 键序数序」并有 CT-E2 用例（当前框架侧已用 `KeyOrdinalComparer` 实现） |
| **单写门门缝** | A-1.4 | 节点级 ⊆ 库级：在 `NodeWriteGate` 装配处显式声明 target 语义并登记与库级门的关系（治 P16） |
| **Agent 接线遗漏依赖** | P6-B | Agent 用 Reference HintPath（不自动传递）：`Modules.Node` 之外如再引 BasicMethod 需在 Agent csproj 显式声明 |
| **位置反转破坏既有键** | C-0 | L-1 硬约束：`loc` 不产身份；CT-L3（仅改 loc ⇒ Key 不变）作门 |
| **语言类型漏进位置层** | C-2 | 门禁 A 已固化；`Modules.Node` 在任何改动后必跑 `Check-NodeFramework.ps1` |
