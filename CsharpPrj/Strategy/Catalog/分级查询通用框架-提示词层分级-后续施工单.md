## §3 目标设计（端口化，不新增跨工程引用）

```
provide_prompt 装配相位 (Agent.Core)
        │
        │ ctx.ResourceBlockSource : IPromptResourceBlockSource?   ← 组合根注入（AgentServiceSlots）
        ▼
PromptAssembler (Agent.Assembly)  ── toggle=resources 且 provider≠null ──▶ Build(resourceBlock: ...)
        ▲
        │ 实现（Projects）
IPromptResourceBlockSource ── Agent.Modules.Response.PromptResourceBlockSource
        │
        └── PromptTierRegistration.ProjectResourceBlock()  ──▶ PromptTierCatalog.ProjectAll(CatalogQueryService.Shared)
                                                                      │
                                                                      └── CatalogPromptProjector.Index（复用 CatalogGrouper）
```

**设计要点**：
1. 端口接口定义在 **`Agent.Assembly`**（装配契约的归属层），实现留在 `Agent.Modules.Response`（已知 `Strategy.Catalog`）。
2. `Agent.Core` 只经 `AgentServiceSlots.Resolve<IPromptResourceBlockSource>()` 消费（未装配 ⇒ null ⇒ 零回归）。
3. 开关 = 段目录的 `PromptSegmentCatalog.ToggleResources`（档案 `IncludeResources`）；**默认关**，灰度后再开。
4. 失败隔离：投影异常 ⇒ 空块（不发射段），不阻断装配（对齐 `PromptTierCatalog.ProjectAll` 的 skip 语义）。

## §7 风险与回滚

| 风险 | 缓解 | 回滚 |
|---|---|---|
| 模型失去「看到全部函数」⇒ 命中率降 | 先单档案灰度；`catalog_search` 兜底；索引行带计数 | `IncludeResources=false` ⇒ 段不发射 |
| UI 与 LLM 开关不一致 ⇒ R3 红 | §4.6 与 §4.5 同源开关；`Validate()` 把关 Band 非降 | 固定两侧开关同值 |
| 段 Band 变更 ⇒ I3 哈希漂移 | Band 属 `CacheBand.B2`（W8 已定），变更须同步哈希用例 | 固定 Band 归属 |
| 双写（D1）致 token 反增 | 灰度期观测；达阈值即收敛 `state_response` 裸拼串 | 保留旧路径开关 |
| 端口注册遗漏 | 未装配 ⇒ null ⇒ 零回归（fail-safe，不 fail-fast） | 移除注册即回退 |
