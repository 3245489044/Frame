5. 关键设计点

  • 声明式触发：引用是「声明式」的——请求体带 relatedNodes 才建 task→node 边，不是每次入队都自动建
  • 职责分层：ReferenceGrounding（守卫）= 决策/编排，ReferenceGraphCoordinator（协调器）= 纯写边执行者，二者不复制逻辑（SingleImplementation 公理）
  • 幂等性：AddResourceAsync 是 upsert、AddReferenceAsync 先删后加，重复入队/声明不产生重复边
  • 防图库分裂：AttachReferenceGrounding 断言守卫协调器与 AgentUiHost.Database.Resources 必须为同一实例（AgentUiHost.cs:111），否则抛异常
  • 数据分离：实体在 SQLite（ur_tasks / ur_nodes），引用关系在 LiteDB（ur_endpoints 端点 + ur_references 纯边）；LiteDB 不复制实体数据
