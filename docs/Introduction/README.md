## 框架简介

FrameManage 是一个基于**工作流(W)-代码(C)-数据(D)-Prompt(P)**四维数学映射系统的模块化工作流管理和执行框架。它支持跨框架的工作流编排、数据处理和模块化扩展，提供了灵活的元工作流管理机制，能够统一管理来自不同框架的工作流，实现工作流的链式连接和数据处理。
