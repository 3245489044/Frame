# 参数校验框架

## 概述

参数校验框架是FrameManage中的一个核心组件，用于验证各种业务参数的有效性。它提供了两种校验方式：

1. **基于DataAnnotations的校验** - 使用.NET内置的特性标记进行校验
2. **基于FluentValidation的校验** - 使用流畅的API进行更复杂的校验逻辑

## 框架结构

参数校验框架由以下主要组件组成：

- **IParameterValidator** - 核心校验接口
- **ValidationResult** - 校验结果类
- **ValidationExtensions** - 扩展方法
- **DataAnnotationsValidator** - 基于DataAnnotations的实现
- **FluentValidatorBase** - 基于FluentValidation的基类
- **ValidatorFactory** - 校验器工厂

## 安装依赖

框架依赖于以下NuGet包：

- **FluentValidation** (版本 11.11.2) - 用于实现流畅的校验逻辑

## 使用方法

### 1. 基于DataAnnotations的校验

#### 步骤1：定义带有校验特性的类

```csharp
using System.ComponentModel.DataAnnotations;

public class User
{
    [Required(ErrorMessage = "Name is required")]
    [StringLength(50, ErrorMessage = "Name must be less than 50 characters")]
    public string Name { get; set; }

    [Range(18, 100, ErrorMessage = "Age must be between 18 and 100")]
    public int Age { get; set; }

    [Required(ErrorMessage = "Email is required")]
    [EmailAddress(ErrorMessage = "Invalid email address")]
    public string Email { get; set; }
}
```

#### 步骤2：创建并使用校验器

```csharp
using FrameManage.Business.Validation;

// 创建校验器
var validator = new DataAnnotationsValidator<User>();

// 验证对象
var user = new User { Name = "John Doe", Age = 25, Email = "john@example.com" };
var result = validator.Validate(user);

// 检查校验结果
if (result.IsValid)
{
    Console.WriteLine("Validation passed!");
}
else
{
    Console.WriteLine("Validation failed:");
    foreach (var error in result.Errors)
    {
        Console.WriteLine($"{error.PropertyName}: {error.ErrorMessage}");
    }
}
```

### 2. 基于FluentValidation的校验

#### 步骤1：创建FluentValidation校验器

```csharp
using FrameManage.Business.Validation;
using FluentValidation;

public class UserValidator : FluentValidatorBase<User>
{
    public UserValidator()
    {
        RuleFor(x => x.Name)
            .NotEmpty().WithMessage("Name is required")
            .MaximumLength(50).WithMessage("Name must be less than 50 characters");

        RuleFor(x => x.Age)
            .InclusiveBetween(18, 100).WithMessage("Age must be between 18 and 100");

        RuleFor(x => x.Email)
            .NotEmpty().WithMessage("Email is required")
            .EmailAddress().WithMessage("Invalid email address");
    }
}
```

#### 步骤2：使用校验器

```csharp
// 创建校验器
var validator = new UserValidator();

// 验证对象
var user = new User { Name = "John Doe", Age = 25, Email = "john@example.com" };
var result = validator.Validate(user);

// 检查校验结果
if (result.IsValid)
{
    Console.WriteLine("Validation passed!");
}
else
{
    Console.WriteLine("Validation failed:");
    foreach (var error in result.Errors)
    {
        Console.WriteLine($"{error.PropertyName}: {error.ErrorMessage}");
    }
}
```

### 3. 使用扩展方法

框架提供了便捷的扩展方法，使校验代码更加简洁：

```csharp
using FrameManage.Business.Validation;

// 使用扩展方法验证单个对象
var user = new User { Name = "John Doe", Age = 25, Email = "john@example.com" };
var validator = new UserValidator();
var result = user.Validate(validator);

// 使用扩展方法验证对象集合
var users = new List<User>
{
    new User { Name = "John Doe", Age = 25, Email = "john@example.com" },
    new User { Name = "Jane Smith", Age = 30, Email = "jane@example.com" }
};
result = users.ValidateAll(validator);
```

### 4. 使用依赖注入

框架已注册到依赖注入容器中，可以通过构造函数注入使用：

```csharp
public class UserService
{
    private readonly IParameterValidator _validator;

    public UserService(IParameterValidator validator)
    {
        _validator = validator;
    }

    public void CreateUser(User user)
    {
        var result = _validator.Validate(user);
        if (!result.IsValid)
        {
            // 处理校验失败
            throw new ValidationException(string.Join(", ", result.Errors.Select(e => e.ErrorMessage)));
        }

        // 处理用户创建逻辑
    }
}
```

## 最佳实践

1. **选择合适的校验方式**：
   - 简单校验使用DataAnnotations
   - 复杂校验使用FluentValidation

2. **统一校验结果处理**：
   - 使用ValidationResult统一处理校验结果
   - 提供清晰的错误信息

3. **结合业务逻辑**：
   - 在业务逻辑层使用校验器
   - 在数据持久化前进行校验

4. **性能考虑**：
   - 对于频繁验证的场景，考虑缓存校验器实例
   - 只验证必要的属性

## 示例：工作流参数校验

以下是一个工作流参数校验的示例：

```csharp
using FrameManage.Business.Validation;
using FluentValidation;

// 工作流参数类
public class WorkflowParameters
{
    public string WorkflowId { get; set; }
    public string Name { get; set; }
    public string Description { get; set; }
    public Dictionary<string, object> Inputs { get; set; }
}

// 工作流参数校验器
public class WorkflowParametersValidator : FluentValidatorBase<WorkflowParameters>
{
    public WorkflowParametersValidator()
    {
        RuleFor(x => x.WorkflowId)
            .NotEmpty().WithMessage("WorkflowId is required")
            .Guid().WithMessage("WorkflowId must be a valid GUID");

        RuleFor(x => x.Name)
            .NotEmpty().WithMessage("Name is required")
            .MaximumLength(100).WithMessage("Name must be less than 100 characters");

        RuleFor(x => x.Inputs)
            .NotNull().WithMessage("Inputs cannot be null");
    }
}

// 使用校验器
public class WorkflowService
{
    public void ExecuteWorkflow(WorkflowParameters parameters)
    {
        var validator = new WorkflowParametersValidator();
        var result = parameters.Validate(validator);

        if (!result.IsValid)
        {
            throw new Exception(string.Join("\n", result.Errors.Select(e => $"{e.PropertyName}: {e.ErrorMessage}")));
        }

        // 执行工作流逻辑
    }
}
```

## 总结

参数校验框架提供了一种统一、灵活的方式来验证业务参数的有效性。它支持两种校验方式，适应不同复杂度的校验需求，并且与依赖注入系统集成，便于在整个应用程序中使用。

通过使用参数校验框架，可以：

1. 提高代码的健壮性和可靠性
2. 减少运行时错误
3. 提供清晰的错误信息
4. 简化校验逻辑的实现

框架设计遵循了SOLID原则，具有良好的扩展性和可维护性，可以根据业务需求进行定制和扩展。
