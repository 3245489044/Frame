## 1. 核心公式与符号系统

### 1.1 基本公式

```
ℱ_macro(x) = lim_{ε→0} 𝒜_ε [ ℱ_micro(x) ]
```

### 1.2 符号定义

| 符号 | 类型 | 数学含义 | 定义域 |
|------|------|---------|--------|
| `x` | 空间坐标 | 位置向量 | `ℝ³` |
| `ℱ_micro(x)` | 函数 | 位置 x 处的微观状态 | `ℝ³ → 𝕄` |
| `𝒜_ε` | 算子族 | 带参数 ε 的粗粒化算子族 | `𝕄 → 𝕄𝕒𝕔` |
| `ε` | 标量参数 | 算子族的索引参数 | `[0, 1] ⊂ ℝ` |
| `lim_{ε→0}` | 极限操作 | ε→0 时的收敛极限 | — |
| `ℱ_macro(x)` | 函数 | 位置 x 处的宏观状态 | `ℝ³ → 𝕄𝕒𝕔` |

### 1.3 空间定义

```
𝕄  = 微观状态空间（M:B:F:V 四维整数空间）
𝕄𝕒𝕔 = 宏观状态空间（n 维实数向量空间）
𝒜_ε : 𝕄 → 𝕄𝕒𝕔,  ∀ε ∈ [0, 1]
```

### 1.4 设计哲学：从名义主义到算子收敛主义

```
名义主义:  BlockType.Stone → Hardness=3.0 (魔法数字)
算子主义:  BlockType.Granite = 𝒜_ε [ Quartz + Feldspar + Mica ] → Hardness=𝒜_H(成分, ε_结构)

这意味着：
- 任何方块属性都不是"查表得到的"，而是通过算子从原子属性推导的
- ε 参数的物理含义不必严格符合现实，只要在框架内自洽收敛即可
- 计算效率通过算子预编译 + 结果缓存保证
```

## 2. 微观状态空间 ℱ_micro

### 2.1 定义

微观状态 ℱ_micro(x) 是位置 x 处的**四维离散计数器**：

```
ℱ_micro(x) = (M(x), B(x), F(x), V(x))

其中：
  M(x) ∈ ℕ  — 质量粒子计数
  B(x) ∈ ℕ  — 键合粒子计数
  F(x) ∈ ℕ  — 自由粒子计数
  V(x) ∈ ℕ  — 空隙粒子计数
```

### 2.2 四维粒子模型的物理类比

| 粒子类型 | 贡献 | 物理类比 | 游戏作用 |
|---------|------|---------|---------|
| **M (Mass)** | 质量/体积 | 相当于原子核 + 内层电子 | 密度、重量 |
| **B (Bond)** | 键合强度 | 相当于共价键/离子键 | 硬度、强度 |
| **F (Free)** | 自由运动 | 相当于自由电子/松散粒子 | 延展性、导电性 |
| **V (Void)** | 空隙 | 相当于空穴/孔隙 | 孔隙率、浮力 |

每个 1cm³ 区域的完整状态 = **4 个整数** `(M, B, F, V)`，仅 16 bytes。

### 2.3 空间连续性假设

ℱ_micro(x) 在空间中是连续的（一阶可微）：

```
ℱ_micro(x + δx) = ℱ_micro(x) + ∇ℱ_micro · δx + O(||δx||²)

其中 ∇ℱ_micro 是 4×3 雅可比矩阵：
  ∇ℱ_micro = [∂M/∂x, ∂M/∂y, ∂M/∂z;
               ∂B/∂x, ∂B/∂y, ∂B/∂z;
               ∂F/∂x, ∂F/∂y, ∂F/∂z;
               ∂V/∂x, ∂V/∂y, ∂V/∂z]
```

### 2.4 归一化比值

四维比值定义为：

```
r_M = M / (M + B + F + V)
r_B = B / (M + B + F + V)
r_F = F / (M + B + F + V)
r_V = V / (M + B + F + V)

约束：r_M + r_B + r_F + r_V = 1,  r_i ∈ [0, 1]
```

### 2.5 微观状态空间的结构

```
𝕄 = ℕ⁴ / ~  其中 ~ 是比例等价关系：
  (M, B, F, V) ~ (kM, kB, kF, kV),  ∀k ∈ ℕ⁺

等价类由四维比值 (r_M, r_B, r_F, r_V) 唯一确定。
𝕄 同构于三维单纯形 Δ³ = { (r_M, r_B, r_F, r_V) ∈ [0,1]⁴ | Σ r_i = 1 }。
```

## 3. 算子族 𝒜_ε 的数学结构

### 3.1 算子族的定义

𝒜_ε 是一个**单参数算子族**（不是多个独立算子）：

```
𝒜_ε = { 𝒜_ε : 𝕄 → 𝕄𝕒𝕔 | ε ∈ [0, 1] }

关键性质：
  𝒜_ε 是一个算子族，不是多个算子
  ε 是算子族的索引参数，不是算子的属性
  所有宏观属性共享同一个算子族 𝒜_ε
```

### 3.2 算子族的连续性

𝒜_ε 在 ε 参数空间中连续（Fréchet 可微）：

```
lim_{δε→0} ||𝒜_{ε+δε} - 𝒜_ε - (∂𝒜/∂ε)·δε|| / |δε| = 0

其中 (∂𝒜/∂ε) 是 𝒜_ε 关于 ε 的 Fréchet 导数：
  (∂𝒜/∂ε) : 𝕄 → 𝕄𝕒𝕔
```

### 3.3 算子族的代数结构

```
加法： (𝒜_ε + ℬ_ε)[ℱ] = 𝒜_ε[ℱ] + ℬ_ε[ℱ]
数乘： (c · 𝒜_ε)[ℱ] = c · 𝒜_ε[ℱ]
复合： (ℬ_ε ∘ 𝒜_ε)[ℱ] = ℬ_ε(𝒜_ε[ℱ])
```

### 3.4 算子族的范数

定义算子范数：

```
||𝒜_ε|| = sup_{ℱ∈𝕄, ℱ≠0} ||𝒜_ε[ℱ]||_𝕄𝕒𝕔 / ||ℱ||_𝕄

其中：
  ||ℱ||_𝕄 = √(M² + B² + F² + V²)  (欧几里得范数)
  ||·||_𝕄𝕒𝕔 是 𝕄𝕒𝕔 上的范数
```

## 4. 极限操作 lim_{ε→0} 的数学含义

### 4.1 极限的定义

```
lim_{ε→0} 𝒜_ε [ ℱ_micro(x) ] = 𝒜_0 [ ℱ_micro(x) ]

其中 𝒜_0 是极限算子：
  𝒜_0 = lim_{ε→0} 𝒜_ε

极限存在的条件：
  ∀ℱ ∈ 𝕄,  lim_{ε→0} ||𝒜_ε[ℱ] - 𝒜_0[ℱ]||_𝕄𝕒𝕔 = 0
```

### 4.2 极限的物理含义

```
ε = 0  → 理想状态（无缺陷、无风化、无杂质、绝对零度...）
ε > 0  → 现实状态（有缺陷、有风化、有杂质、有限温度...）

极限操作意味着：
  现实状态 = 理想状态 + ε 阶修正
  ℱ_macro = 𝒜_0[ℱ_micro] + O(ε)
```

### 4.3 收敛速度

假设 𝒜_ε 在 ε=0 处解析，则收敛速度为：

```
||𝒜_ε[ℱ] - 𝒜_0[ℱ]||_𝕄𝕒𝕔 = O(ε)  当 ε → 0

更精确地：
  ||𝒜_ε[ℱ] - 𝒜_0[ℱ]||_𝕄𝕒𝕔 ≤ C · ε · ||ℱ||_𝕄

其中 C 是 Lipschitz 常数。
```

## 5. 宏观状态空间 ℱ_macro

### 5.1 定义

宏观状态 ℱ_macro(x) 是位置 x 处的 **n 维实数向量**：

```
ℱ_macro(x) = (P₁(x), P₂(x), ..., P_n(x))

其中每个 P_i(x) 是第 i 个宏观属性在位置 x 的值。
```

### 5.2 宏观属性空间

```
𝕄𝕒𝕔 = ℝⁿ,  n = 9

标准基：
  e_ρ  = (1, 0, 0, 0, 0, 0, 0, 0, 0)  — 密度
  e_H  = (0, 1, 0, 0, 0, 0, 0, 0, 0)  — 硬度
  e_C  = (0, 0, 1, 0, 0, 0, 0, 0, 0)  — 颜色
  e_L  = (0, 0, 0, 1, 0, 0, 0, 0, 0)  — 光照
  e_P  = (0, 0, 0, 0, 1, 0, 0, 0, 0)  — 物理状态
  e_Ch = (0, 0, 0, 0, 0, 1, 0, 0, 0)  — 化学活性
  e_T  = (0, 0, 0, 0, 0, 0, 1, 0, 0)  — 热力学
  e_E  = (0, 0, 0, 0, 0, 0, 0, 1, 0)  — 弹性
  e_O  = (0, 0, 0, 0, 0, 0, 0, 0, 1)  — 光学
```

### 5.3 投影算子

第 i 个宏观属性是 ℱ_macro 在第 i 个坐标轴上的投影：

```
P_i(x) = ⟨ℱ_macro(x), e_i⟩ = 第 i 个分量

其中 ⟨·,·⟩ 是 𝕄𝕒𝕔 上的标准内积。
```

### 5.4 从算子族到投影

```
P_i(x) = lim_{ε→0} ⟨𝒜_ε [ ℱ_micro(x) ], e_i ⟩

即：第 i 个宏观属性 = 算子族输出在第 i 个方向上的投影
```

## 6. 泰勒展开与线性响应理论

### 6.1 算子族在 ε=0 处的泰勒展开

假设 𝒜_ε 在 ε=0 处解析（无限可微），则：

```
𝒜_ε [ ℱ ] = 𝒜_0 [ ℱ ] + ε · (∂𝒜/∂ε)|₀ [ ℱ ] 
             + ½ ε² · (∂²𝒜/∂ε²)|₀ [ ℱ ] 
             + ⅙ ε³ · (∂³𝒜/∂ε³)|₀ [ ℱ ]
             + ...
             + (1/k!) εᵏ · (∂ᵏ𝒜/∂εᵏ)|₀ [ ℱ ]
             + ...

其中：
  𝒜_0 = lim_{ε→0} 𝒜_ε    ← 零阶项（理想状态算子）
  (∂ᵏ𝒜/∂εᵏ)|₀            ← k 阶 Fréchet 导数
```

### 6.2 各阶项的物理意义

| 阶数 | 项 | 数学含义 | 物理含义 |
|------|----|---------|---------|
| **零阶** | 𝒜_0[ℱ] | 极限算子 | 理想状态的宏观属性 |
| **一阶** | ε · (∂𝒜/∂ε)|₀ | 线性响应 | 每个 ε 独立修正所有属性 |
| **二阶** | ½ε² · (∂²𝒜/∂ε²)|₀ | 二次非线性 | ε 的自耦合效应 |
| **k 阶** | (1/k!)εᵏ · (∂ᵏ𝒜/∂εᵏ)|₀ | k 次非线性 | 高阶修正 |

### 6.3 线性响应张量

一阶项 (∂𝒜/∂ε)|₀ 是一个线性算子，可以表示为**线性响应张量**：

```
(∂𝒜/∂ε)|₀ [ ℱ ] = R[ℱ]

其中 R : 𝕄 → 𝕄𝕒𝕔 是线性算子
R 的矩阵表示（在标准基下）：
  R_ij = ⟨ (∂𝒜/∂ε)|₀ [ e_j ], e_i ⟩
   
   其中 e_j 是 𝕄 的基向量，e_i 是 𝕄𝕒𝕔 的基向量
```

### 6.4 截断近似

在实际应用中，截断到一阶：

```
ℱ_macro(x) ≈ 𝒜_0 [ ℱ_micro(x) ] + ε · (∂𝒜/∂ε)|₀ [ ℱ_micro(x) ]

截断误差：
  ||ℱ_macro - (𝒜_0 + ε·(∂𝒜/∂ε)|₀)[ℱ_micro]||_𝕄𝕒𝕔 = O(ε²)
```

## 7. 连续性的两个来源

### 7.1 来源一：ℱ_micro(x) 的空间连续性

微观状态 ℱ_micro(x) 在空间中是连续的：

```
ℱ_micro(x + δx) = ℱ_micro(x) + ∇ℱ_micro · δx + O(||δx||²)

推演：
  ℱ_macro(x + δx) = lim_{ε→0} 𝒜_ε [ ℱ_micro(x + δx) ]
                   = lim_{ε→0} 𝒜_ε [ ℱ_micro(x) + ∇ℱ_micro · δx + O(||δx||²) ]
                   = lim_{ε→0} 𝒜_ε [ ℱ_micro(x) ] + lim_{ε→0} (∂𝒜_ε/∂ℱ) · ∇ℱ_micro · δx + O(||δx||²)
                   = ℱ_macro(x) + ∇ℱ_macro · δx + O(||δx||²)

结论：ℱ_macro(x) 在空间中是连续的。
```

### 7.2 来源二：𝒜_ε 在 ε 参数空间中的连续性

算子族 𝒜_ε 在 ε 参数空间中连续：

```
𝒜_{ε+δε} = 𝒜_ε + (∂𝒜/∂ε) · δε + O(δε²)

推演：
  ℱ_macro(x; ε+δε) = lim_{ε'→0} 𝒜_{ε'} [ ℱ_micro(x) ]   ← 注意：极限操作中的 ε' 是哑变量
                     = 𝒜_0 [ ℱ_micro(x) ]                 ← 极限与 ε 无关
  
  但实际计算中，我们使用有限 ε 的近似：
  ℱ_macro_approx(x; ε) = 𝒜_ε [ ℱ_micro(x) ]
  
  这个近似值在 ε 参数空间中连续：
  ℱ_macro_approx(x; ε+δε) = ℱ_macro_approx(x; ε) + (∂𝒜_ε/∂ε)[ℱ_micro] · δε + O(δε²)
```

### 7.3 连续性的数学意义

```
空间连续性： 相邻位置的宏观属性是相关的
ε 连续性：   不同 ε 对应的宏观属性之间是连续过渡的

这两个连续性共同构成了"宏观属性之间连续联系"的数学基础。
```

## 8. 联系关系的数学形式

### 8.1 共享微观状态

不同宏观属性之间的联系来自于它们共享同一个微观状态 ℱ_micro 和同一个算子族 𝒜_ε：

```
设两个宏观属性：
  P_i(x) = lim_{ε→0} ⟨𝒜_ε [ ℱ_micro(x) ], e_i ⟩
  P_j(x) = lim_{ε→0} ⟨𝒜_ε [ ℱ_micro(x) ], e_j ⟩

它们的联系：
  P_j(x) = ℱ_ij [ P_i(x), ε, ∇ℱ_micro, ... ]
  
  其中 ℱ_ij 是 P_i 到 P_j 的映射函数
  这个映射由 𝒜_ε 和 ℱ_micro 共同决定
```

### 8.2 泛函形式

所有宏观属性是同一个微观状态的泛函：

```
ℱ_macro(x) = lim_{ε→0} 𝒜_ε [ ℱ_micro(x) ]

等价于：

ℱ_macro(x) = ℱ[ ℱ_micro(x), ε, ∇ℱ_micro(x), ∇²ℱ_micro(x), ... ]

其中 ℱ 是一个泛函，输出一个 n 维向量：
  ℱ[ℱ_micro] = (P₁, P₂, ..., P_n)
  
  这个向量的所有分量由同一个 ℱ_micro 决定
  → 分量之间必然存在内在联系
  → 改变 ℱ_micro 会同时改变所有分量
```

### 8.3 联系的存在性定理

**定理 1（联系存在性）**：如果 𝒜_ε 在 ε=0 处可逆（在 𝕄 的一个开邻域上），则对于任意两个宏观属性 P_i 和 P_j，存在一个函数 F_ij 使得：

```
P_j(x) = F_ij(P_i(x), ε, ∇P_i(x), ...)
```

**证明**：由 𝒜_ε 的可逆性，ℱ_micro = 𝒜_ε⁻¹[ℱ_macro]。代入 P_j 的表达式：

```
P_j = ⟨𝒜_ε[ℱ_micro], e_j⟩ = ⟨𝒜_ε[𝒜_ε⁻¹[ℱ_macro]], e_j⟩ = ⟨ℱ_macro, e_j⟩
```

但 ℱ_macro 的分量中包含 P_i，因此 P_j 可以表示为 P_i 的函数。

### 8.4 联系矩阵

定义联系矩阵 C ∈ ℝ^{n×n}：

```
C_ij = ∂P_j / ∂P_i   （在 ℱ_micro 空间中）

其中：
  C_ij 表示属性 i 变化 1 单位时，属性 j 的变化量
  C_ii = 1 （自身到自身的联系）
  C_ij ≠ C_ji 一般成立（联系不一定对称）
```

联系矩阵的链式法则：

```
∂P_k / ∂P_i = Σ_j (∂P_k / ∂ℱ_micro_j) · (∂ℱ_micro_j / ∂P_i)
```

## 9. 通用联系方程

### 9.1 积分形式

对于任意两个宏观属性 P_i 和 P_j，它们之间的通用联系方程为：

```
P_j(x) = ∫_Ω K_ij(x, x') · P_i(x') dx'

其中：
  Ω ⊆ ℝ³ 是空间区域
  K_ij(x, x') 是联系核函数
```

### 9.2 联系核函数的定义

```
K_ij(x, x') = lim_{ε→0} (∂𝒜_εⱼ / ∂P_i) [ ℱ_micro(x') ]

其中：
  𝒜_εⱼ[ℱ] = ⟨𝒜_ε[ℱ], e_j⟩  是 𝒜_ε 在第 j 个方向上的分量
  (∂𝒜_εⱼ / ∂P_i) 是 𝒜_εⱼ 关于 P_i 的 Fréchet 导数
```

### 9.3 局部近似

在大多数游戏场景中，可以假设局部性（相邻体素之间的相互作用为主）：

```
P_j(x) = α_ij · P_i(x) + β_ij · ∇²P_i(x) + γ_ij · ε(x) + O(∇⁴P_i)

其中：
  α_ij = ∫ K_ij(x, x') dx'                    ← 直接比例系数
  β_ij = ½ ∫ K_ij(x, x') · ||x - x'||² dx'    ← 扩散系数
  γ_ij = ∂P_j / ∂ε                             ← ε 敏感度
```

### 9.4 局部近似的推导

从积分形式出发，对 P_i(x') 在 x 处做泰勒展开：

```
P_i(x') = P_i(x) + ∇P_i(x) · (x' - x) + ½ (x' - x)ᵀ · ∇²P_i(x) · (x' - x) + ...

代入积分形式：
  P_j(x) = ∫ K_ij(x, x') · [P_i(x) + ∇P_i(x) · (x' - x) + ...] dx'
         = P_i(x) · ∫ K_ij(x, x') dx' + ∇P_i(x) · ∫ K_ij(x, x') · (x' - x) dx' + ...
         
假设核函数对称：∫ K_ij(x, x') · (x' - x) dx' = 0
则一阶项消失，得到：
  P_j(x) = α_ij · P_i(x) + β_ij · ∇²P_i(x) + ...
```

## 10. 多 ε 参数的完整展开

### 10.1 多参数算子族

在实际应用中，ε 是一个多维参数向量：

```
ε = (ε₁, ε₂, ..., ε_m) ∈ [0, 1]ᵐ

其中：
  ε₁ = porosity（孔隙率）
  ε₂ = defect（缺陷率）
  ε₃ = impurity（杂质率）
  ε₄ = excitation（激发度）
  ε₅ = bond_strength（键合强度）
  ε₆ = weather（风化度）
  ε₇ = thermal（热力学）
  ε₈ = stress（应力）
  ε₉ = density（密度因子）
```

### 10.2 多参数泰勒展开

```
ℱ_macro(x) = lim_{||ε||→0} 𝒜_ε [ ℱ_micro(x) ]

展开为多 ε 参数形式：

ℱ_macro(x) = 𝒜_0[ℱ_micro(x)] 
             + Σ_i ε_i · (∂𝒜/∂ε_i)|₀ [ℱ_micro(x)] 
             + ½ Σ_i ε_i² · (∂²𝒜/∂ε_i²)|₀ [ℱ_micro(x)]
             + Σ_{i<j} ε_i·ε_j · (∂²𝒜/∂ε_i∂ε_j)|₀ [ℱ_micro(x)]
             + O(||ε||³)
```

### 10.3 各阶项的物理意义

| 项 | 数学含义 | 物理含义 | 示例 |
|----|---------|---------|------|
| 𝒜_0[ℱ_micro] | 零阶项 | 理想状态的基准值 | 纯石英的理想密度、硬度 |
| ε_i · (∂𝒜/∂ε_i)|₀ | 一阶线性响应 | 每个 ε 独立修正所有属性 | 孔隙率 ε 同时降低密度和硬度 |
| ε_i² · (∂²𝒜/∂ε_i²)|₀ | 二阶自耦合 | ε 自身的非线性效应 | 高孔隙率导致结构崩塌 |
| ε_i·ε_j · (∂²𝒜/∂ε_i∂ε_j)|₀ | 二阶交叉耦合 | ε 参数之间的协同效应 | 高温 + 高应力 → 蠕变 |

### 10.4 交叉耦合的数学意义

交叉项 ε_i·ε_j 的存在意味着**宏观属性之间的联系不是线性的**：

```
∂²ℱ_macro / ∂ε_i∂ε_j ≠ 0  一般成立

这意味着：
  改变 ε_i 对宏观属性的影响依赖于 ε_j 的值
  → 宏观属性之间的联系是上下文相关的
  → 这就是"连续联系"的非线性本质
```

## 11. 离散化与收敛性

### 11.1 空间离散化

在体素世界中，空间被离散化为体素网格：

```
x → (i, j, k) ∈ ℤ³   （体素坐标）

ℱ_micro(x) → ℱ_micro[i, j, k]
ℱ_macro(x) → ℱ_macro[i, j, k]
```

### 11.2 算子离散化

连续算子 𝒜_ε 离散化为：

```
𝒜_ε [ ℱ_micro(x) ] → 𝒜_ε_disc [ ℱ_micro[i, j, k] ]

其中 𝒜_ε_disc 是 𝒜_ε 在体素网格上的离散近似
```

### 11.3 离散化误差

```
||𝒜_ε[ℱ_micro] - 𝒜_ε_disc[ℱ_micro_disc]||_𝕄𝕒𝕔 = O(h)

其中 h 是体素分辨率（1cm）
```

### 11.4 收敛性定理

**定理 2（收敛性）**：如果 𝒜_ε 在 ε=0 处连续，则对于任意 ℱ_micro ∈ 𝕄：

```
lim_{ε→0} 𝒜_ε [ ℱ_micro ] = 𝒜_0 [ ℱ_micro ]

且收敛速度至少为 O(ε)。
```

**定理 3（离散收敛性）**：如果 𝒜_ε 是 Lipschitz 连续的，则离散化误差随分辨率提高而线性减小：

```
lim_{h→0} ||𝒜_ε[ℱ_micro] - 𝒜_ε_disc[ℱ_micro_disc]||_𝕄𝕒𝕔 = 0
```

### 11.5 数值逼近算法

```
算法：收敛极限逼近

输入：算子族 𝒜_ε，微观状态 ℱ_micro，阈值 δ
输出：ℱ_macro 的近似值

1. 初始化 ε = 1.0
2. 计算当前值 V_curr = 𝒜_ε[ℱ_micro]
3. 循环：
   a. ε ← ε / 2
   b. V_next = 𝒜_ε[ℱ_micro]
   c. 如果 ||V_next - V_curr|| < δ，返回 V_next
   d. V_curr ← V_next
4. 返回 V_curr
```

## 12. 公理体系

### 12.1 基本公理

```
A1（存在性）：存在算子族 𝒜_ε : 𝕄 → 𝕄𝕒𝕔，∀ε ∈ [0, 1]
A2（极限性）：lim_{ε→0} 𝒜_ε 存在且有限
A3（连续性）：𝒜_ε 在 ε 参数空间中连续
A4（因果性）：ℱ_macro(x) 仅依赖于 ℱ_micro(x) 及其在 x 的邻域内的值
```

### 12.2 结构公理

```
S1（共享性）：所有宏观属性共享同一个算子族 𝒜_ε 和同一个微观状态 ℱ_micro
S2（投影性）：第 i 个宏观属性是 ℱ_macro 在第 i 个坐标轴上的投影
S3（可微性）：𝒜_ε 在 ε=0 处 Fréchet 可微
S4（解析性）：𝒜_ε 在 ε=0 处解析（可展开为收敛的泰勒级数）
```

### 12.3 约束公理

```
C1（有界性）：||𝒜_ε[ℱ]||_𝕄𝕒𝕔 ≤ C · ||ℱ||_𝕄，∀ε ∈ [0, 1]
C2（单调性）：ε₁ ≤ ε₂ ⇒ ||𝒜_{ε₁}[ℱ] - 𝒜_0[ℱ]|| ≤ ||𝒜_{ε₂}[ℱ] - 𝒜_0[ℱ]||
C3（归一性）：𝒜_0[0] = 0（零微观状态对应零宏观状态）
```

### 12.4 定理总结

```
T1（联系存在性）：任意两个宏观属性之间存在函数关系
T2（收敛性）：lim_{ε→0} 𝒜_ε[ℱ] 以 O(ε) 速度收敛
T3（离散收敛性）：离散化误差以 O(h) 速度收敛
T4（泰勒展开）：𝒜_ε[ℱ] = Σ_{k=0}^∞ (εᵏ/k!) · (∂ᵏ𝒜/∂εᵏ)|₀[ℱ]
T5（联系方程）：P_j(x) = ∫ K_ij(x, x') · P_i(x') dx'
```

## 13. 物理模拟的数学基础

### 13.1 物理状态作为宏观属性

物理状态不是框架之外的独立系统，而是 ℱ_macro 的一个投影：

```
ℱ_macro(x) = (P₁, P₂, ..., P_n)

其中：
  P₁ = Density（密度）      → 浮力、重力行为
  P₂ = Hardness（硬度）      → 可挖掘性、碰撞响应
  P₃ = ColorHue（颜色）      → 视觉表现
  P₄ = Lightness（发光）      → 光照
  P₅ = Viscosity（粘度）      → 流体行为
  P₆ = Reactivity（反应性）   → 化学变化
  P₇ = MeltingPoint（熔点）   → 相变
  P₈ = Elasticity（弹性）     → 形变、碰撞
  P₉ = Opacity（不透明度）    → 光学
  P₁₀ = PhysicsState（物理状态）← 物理状态本身就是宏观属性之一
```

### 13.2 物理模拟的两种模式

**模式 A：属性推导（静态）**

```
PhysicsState(x) = ⟨ℱ_macro(x), e_physics⟩

从微观状态计算物理属性
触发条件：体素变化时（增量更新）
```

**模式 B：物理演化（动态）**

```
ℱ_micro(t+Δt) = ℱ_micro(t) + Δt · ℱ_physics[ ℱ_micro(t), ε(t) ]

其中 ℱ_physics 是物理演化算子：
  ℱ_physics[ℱ_micro] = (ΔM, ΔB, ΔF, ΔV)

物理演化改变的是微观状态 ℱ_micro，而不是宏观属性 ℱ_macro
```

### 13.3 两种模式的关系

```
模式 A（属性推导）:
  输入: ℱ_micro → 输出: PhysicsState
  触发: 体素变化时
  频率: 低（增量更新）

模式 B（物理演化）:
  输入: ℱ_micro(t) → 输出: ℱ_micro(t+Δt)
  触发: 每帧
  频率: 高（60 FPS）

关系:
  模式 A 是"查询"——体素的物理属性是什么
  模式 B 是"更新"——体素的微观状态如何随时间变化
  模式 B 改变 ℱ_micro，然后模式 A 重新推导 ℱ_macro
```

### 13.4 物理传播的数学描述

物理效应在空间中的传播可以用扩散方程描述：

```
∂ℱ_micro/∂t = D · ∇²ℱ_micro + S[ℱ_micro, ε]

其中：
  D 是扩散系数张量（描述物理传播速度）
  S 是源项（描述物理效应的产生）
  ∇² 是拉普拉斯算子（描述空间扩散）
```

离散化后：

```
ℱ_micro[i, j, k, t+Δt] = ℱ_micro[i, j, k, t] + Δt · (
  D · ∇²ℱ_micro[i, j, k, t] + S[ℱ_micro[i, j, k, t], ε]
)
```
