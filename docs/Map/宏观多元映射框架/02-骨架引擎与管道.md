## 1. 骨架哲学

### 1.1 什么是"骨架"？

**骨架（Skeleton）** 是一个抽象概念，它描述的是"结构"而非"内容"：

```
字段骨架：数据结构的形状（字段名、类型、关系）
算法骨架：计算过程的形状（输入、变换、输出）
```

在 SkeletonFlow 中，`ISkeleton<TInput, TOutput>` 统一了这两种骨架：

```
ISkeleton<TInput, TOutput> = 一个"算法骨架"
  ├── TInput  = 骨架的输入形状
  ├── TOutput = 骨架的输出形状
  └── Execute = 骨架的填充逻辑
```

### 1.2 从字段到算法的升华

```
传统编程：    字段（数据） → 算法（函数） → 结果
SkeletonFlow：字段骨架 → 算法骨架 → 组合骨架 → 执行

字段骨架：    定义"数据应该长什么样"
算法骨架：    定义"计算应该怎么走"
组合骨架：    定义"多个算法如何连接"
```

### 1.3 骨架的数学本质

```
一个骨架 ISkeleton<TInput, TOutput> 在数学上等价于：

  f : TInput → TOutput

即：从输入类型到输出类型的映射。

骨架的组合（Then）等价于函数的复合：
  Then : (A → B) × (B → C) → (A → C)
```

### 1.4 骨架的三大原则

```
原则一：每个骨架只做一件事
  ISkeleton<TInput, TOutput> 只封装一个变换
  输入类型 TInput 和输出类型 TOutput 定义了变换的边界

原则二：骨架可以组合
  小骨架 → Then → 大骨架 → Then → 更大骨架
  组合后的骨架仍然是 ISkeleton<,>

原则三：骨架是类型安全的
  编译期检查输入输出类型是否匹配
  类型不匹配的骨架无法组合
```

## 2. 核心接口

### 2.1 ISkeleton 接口

```csharp
// ── 核心接口 ──
// ISkeleton<TInput, TOutput> 是一个"算法骨架"
// 它封装了一个从 TInput 到 TOutput 的变换

public interface ISkeleton<in TInput, TOutput> : ISkeleton
{
    string Name { get; }                                    // 骨架名称
    string Description { get; }                             // 骨架描述
    TOutput Execute(TInput input, SkeletonContext context = null);  // 同步执行
    Task<TOutput> ExecuteAsync(TInput input, SkeletonContext context = null); // 异步执行
}
```

### 2.2 基类 SkeletonBase

```csharp
// ── 骨架基类 ──
// 提供 Execute/ExecuteAsync 的默认实现
// 子类只需重写 ExecuteCore

public abstract class SkeletonBase<TInput, TOutput> : ISkeleton<TInput, TOutput>
{
    public string Name { get; }
    public string Description { get; }
    
    protected SkeletonBase(string name, string description = "")
    {
        Name = name;
        Description = description;
    }
    
    // 子类重写此方法实现核心逻辑
    protected abstract TOutput ExecuteCore(TInput input, SkeletonContext ctx);
    
    // 可选重写异步版本
    protected virtual Task<TOutput> ExecuteCoreAsync(TInput input, SkeletonContext ctx)
    {
        return Task.Run(() => ExecuteCore(input, ctx), ctx?.CancellationToken ?? CancellationToken.None);
    }
    
    // Execute 调用 ExecuteCore
    public TOutput Execute(TInput input, SkeletonContext context = null)
    {
        return ExecuteCore(input, context ?? new SkeletonContext());
    }
    
    public Task<TOutput> ExecuteAsync(TInput input, SkeletonContext context = null)
    {
        return ExecuteCoreAsync(input, context ?? new SkeletonContext());
    }
}
```

## 3. 执行上下文

### 3.1 SkeletonContext

```csharp
// ── 执行上下文 ──
// SkeletonContext 是骨架执行的"环境"
// 骨架之间通过 Context 共享数据（包括 ε 参数）

public class SkeletonContext : IDisposable
{
    public CancellationToken CancellationToken { get; set; }  // 取消令牌
    public IDictionary<string, object> Items { get; }         // 共享数据字典
    public IServiceProvider ServiceProvider { get; set; }     // 依赖注入
    
    // 物理 ε 参数（体素固有属性，收敛过程中不变）
    public EpsilonSet Epsilon { get; set; }
    
    public SkeletonContext()
    {
        Items = new Dictionary<string, object>();
    }
    
    // 泛型数据存取
    public void SetData<T>(T data, string key = null)
    {
        key ??= typeof(T).FullName;
        Items[key] = data;
    }
    
    public T GetData<T>(string key = null)
    {
        key ??= typeof(T).FullName;
        return (T)Items[key];
    }
    
    public bool TryGetData<T>(out T data, string key = null)
    {
        key ??= typeof(T).FullName;
        if (Items.TryGetValue(key, out var obj) && obj is T typed)
        {
            data = typed;
            return true;
        }
        data = default;
        return false;
    }
    
    public void Dispose()
    {
        Items.Clear();
    }
}
```

### 3.2 上下文的作用

```
SkeletonContext = 骨架执行的"环境"
  ├── CancellationToken  — 取消令牌
  ├── Items              — 共享数据字典（传递 ε 参数、邻居体素等）
  ├── ServiceProvider    — 依赖注入
  └── Epsilon            — 物理 ε 参数

这意味着：骨架之间可以通过上下文传递信息
这是"连续联系"的运行时基础。
```

## 4. 五种组合子

### 4.1 Then — 顺序组合

**数学对应**：算子复合 𝒜 ∘ ℬ

```csharp
// Then : (A → B) × (B → C) → (A → C)
public static ISkeleton<TInput, TOutput> Then<TInput, TIntermediate, TOutput>(
    this ISkeleton<TInput, TIntermediate> first,
    ISkeleton<TIntermediate, TOutput> next)
{
    return new DelegateSkeleton<TInput, TOutput>(
        $"{first.Name}.Then({next.Name})",
        sync: input => {
            var intermediate = first.Execute(input);
            return next.Execute(intermediate);
        },
        async: async input => {
            var intermediate = await first.ExecuteAsync(input);
            return await next.ExecuteAsync(intermediate);
        });
}
```

### 4.2 Branch — 条件分支

**数学对应**：条件选择 if ε then 𝒜 else ℬ

```csharp
// Branch : (A → bool) × (A → B) × (A → B) → (A → B)
public static ISkeleton<TInput, TOutput> Branch<TInput, TOutput>(
    this ISkeleton<TInput, bool> condSkel,
    ISkeleton<TInput, TOutput> trueBranch,
    ISkeleton<TInput, TOutput> falseBranch)
{
    return new DelegateSkeleton<TInput, TOutput>(
        $"Branch({condSkel.Name})",
        sync: input => condSkel.Execute(input) 
            ? trueBranch.Execute(input) 
            : falseBranch.Execute(input));
}
```

### 4.3 Loop — 迭代循环

**数学对应**：极限逼近 lim_{ε→0}

```csharp
// Loop : (A → bool) × (A → A) → (A → A)
public static ISkeleton<TInput, TInput> Loop<TInput>(
    this ISkeleton<TInput, bool> condSkel,
    ISkeleton<TInput, TInput> body)
{
    return new DelegateSkeleton<TInput, TInput>(
        $"Loop({condSkel.Name})",
        sync: input => {
            var current = input;
            while (condSkel.Execute(current))
            {
                current = body.Execute(current);
            }
            return current;
        });
}
```

### 4.4 Parallel — 并行执行

**数学对应**：并行映射 (𝒜, ℬ)

```csharp
// Parallel : (A → B) × (A → C) → (A → (B, C))
public static ISkeleton<TInput, (TOutput1, TOutput2)> Parallel<TInput, TOutput1, TOutput2>(
    this ISkeleton<TInput, TOutput1> s1,
    ISkeleton<TInput, TOutput2> s2)
{
    return new DelegateSkeleton<TInput, (TOutput1, TOutput2)>(
        $"Parallel({s1.Name}, {s2.Name})",
        sync: input => (s1.Execute(input), s2.Execute(input)),
        async: async input => {
            var task1 = s1.ExecuteAsync(input);
            var task2 = s2.ExecuteAsync(input);
            await Task.WhenAll(task1, task2);
            return (task1.Result, task2.Result);
        });
}
```

### 4.5 ForEach — 集合提升

**数学对应**：集合映射 𝒜[ℱ₁, ℱ₂, ...]

```csharp
// ForEach : (A → B) → (IEnumerable<A> → IEnumerable<B>)
public static ISkeleton<IEnumerable<TInput>, IEnumerable<TOutput>> ForEach<TInput, TOutput>(
    this ISkeleton<TInput, TOutput> element)
{
    return new DelegateSkeleton<IEnumerable<TInput>, IEnumerable<TOutput>>(
        $"ForEach({element.Name})",
        sync: inputs => inputs.Select(i => element.Execute(i)).ToList(),
        async: async inputs => {
            var tasks = inputs.Select(i => element.ExecuteAsync(i));
            return await Task.WhenAll(tasks);
        });
}
```

## 5. 快速创建骨架

### 5.1 DelegateSkeleton

```csharp
// ── 委托骨架 ──
// 使用委托快速创建骨架（无需定义新类）

public class DelegateSkeleton<TInput, TOutput> : SkeletonBase<TInput, TOutput>
{
    private readonly Func<TInput, SkeletonContext, TOutput> _syncFunc;
    private readonly Func<TInput, SkeletonContext, Task<TOutput>> _asyncFunc;
    
    public DelegateSkeleton(
        string name, 
        Func<TInput, TOutput> sync = null,
        Func<TInput, Task<TOutput>> async = null,
        string description = "")
        : base(name, description)
    {
        if (sync != null)
            _syncFunc = (input, ctx) => sync(input);
        if (async != null)
            _asyncFunc = (input, ctx) => async(input);
    }
    
    public DelegateSkeleton(
        string name,
        Func<TInput, SkeletonContext, TOutput> syncWithCtx = null,
        Func<TInput, SkeletonContext, Task<TOutput>> asyncWithCtx = null,
        string description = "")
        : base(name, description)
    {
        _syncFunc = syncWithCtx;
        _asyncFunc = asyncWithCtx;
    }
    
    protected override TOutput ExecuteCore(TInput input, SkeletonContext ctx)
    {
        return _syncFunc != null 
            ? _syncFunc(input, ctx) 
            : throw new NotSupportedException("同步执行未实现");
    }
    
    protected override Task<TOutput> ExecuteCoreAsync(TInput input, SkeletonContext ctx)
    {
        return _asyncFunc != null 
            ? _asyncFunc(input, ctx) 
            : Task.Run(() => ExecuteCore(input, ctx), ctx.CancellationToken);
    }
}
```

### 5.2 Flow 构建器

```csharp
// ── Flow 构建器 ──
// 提供流畅的链式调用语法

public static class Flow
{
    public static Flow<TInput, TInput> Start<TInput>()
    {
        return new Flow<TInput, TInput>(new IdentitySkeleton<TInput>());
    }
}

public class Flow<TInput, TOutput>
{
    private readonly ISkeleton<TInput, TOutput> _skeleton;
    
    internal Flow(ISkeleton<TInput, TOutput> skeleton)
    {
        _skeleton = skeleton;
    }
    
    public Flow<TInput, TNewOutput> Then<TNewOutput>(
        ISkeleton<TOutput, TNewOutput> next)
    {
        return new Flow<TInput, TNewOutput>(_skeleton.Then(next));
    }
    
    public TOutput Execute(TInput input, SkeletonContext ctx = null)
    {
        return _skeleton.Execute(input, ctx);
    }
    
    public Task<TOutput> ExecuteAsync(TInput input, SkeletonContext ctx = null)
    {
        return _skeleton.ExecuteAsync(input, ctx);
    }
    
    // 隐式转换为 ISkeleton
    public static implicit operator ISkeleton<TInput, TOutput>(Flow<TInput, TOutput> flow)
    {
        return flow._skeleton;
    }
}

// ── 单位元骨架 ──
public class IdentitySkeleton<T> : SkeletonBase<T, T>
{
    public IdentitySkeleton() : base("Identity", "单位元骨架：输入等于输出") { }
    protected override T ExecuteCore(T input, SkeletonContext ctx) => input;
}
```

## 7. 微观状态骨架

### 7.1 数学

```
ℱ_micro : ℝ³ → 𝕄
ℱ_micro(x) = (M(x), B(x), F(x), V(x))
```

### 7.2 编程实现

```csharp
// ── 算法骨架：微观状态 ──
// 数学：ℱ_micro : ℝ³ → 𝕄
// 输入：空间位置 Vector3
// 输出：MicroState (M, B, F, V)

public class MicroStateSkeleton : SkeletonBase<Vector3, MicroState>
{
    public MicroStateSkeleton() : base("MicroState", "从空间位置计算微观状态 ℱ_micro(x)") { }
    
    protected override MicroState ExecuteCore(Vector3 position, SkeletonContext ctx)
    {
        // 从位置 x 计算 M:B:F:V 四维粒子计数
        // 这里使用噪声函数生成示例数据
        // 实际实现中，可以从地形生成器、体素数据源等获取
        
        float noise = PerlinNoise(position.X * 0.1f, position.Y * 0.1f, position.Z * 0.1f);
        float noise2 = PerlinNoise(position.X * 0.05f + 100, position.Y * 0.05f, position.Z * 0.05f);
        
        return new MicroState
        {
            M = (int)(noise * 100 + 50),      // 质量粒子
            B = (int)(noise2 * 80 + 20),      // 键合粒子
            F = (int)((1 - noise) * 30 + 5),  // 自由粒子
            V = (int)((1 - noise2) * 20 + 2), // 空隙粒子
        };
    }
    
    protected override Task<MicroState> ExecuteCoreAsync(Vector3 input, SkeletonContext ctx)
    {
        return Task.Run(() => ExecuteCore(input, ctx), ctx.CancellationToken);
    }
    
    // 辅助：Perlin 噪声（简化版）
    private static float PerlinNoise(float x, float y, float z)
    {
        return (MathF.Sin(x * 1.5f) * MathF.Cos(y * 2.3f) * MathF.Sin(z * 1.8f) + 1f) * 0.5f;
    }
}
```

## 8. 理想状态算子骨架

### 8.1 数学

```
𝒜_0 = lim_{ε→0} 𝒜_ε : 𝕄 → 𝕄𝕒𝕔

在 ε=0 处，算子退化为线性响应矩阵：
  𝒜_0[ℱ_micro] = R₀ · [r_M, r_B, r_F, r_V]ᵀ
```

### 8.2 编程实现

```csharp
// ── 算法骨架：理想状态 ──

// 使用通用响应矩阵 R₀，无魔法数字

public class IdealStateSkeleton : SkeletonBase<MicroState, MacroState>

    protected override Task<MacroState> ExecuteCoreAsync(MicroState input, SkeletonContext ctx)
    {
        return Task.Run(() => ExecuteCore(input, ctx), ctx.CancellationToken);
    }
}
```

## 9. 线性响应算子骨架

### 9.1 数学

```
(∂𝒜/∂ε_i)|₀ : 𝕄 → 𝕄𝕒𝕔

每个 ε 参数对应一个响应矩阵 R_i（19×4）：
  (∂𝒜/∂ε_i)|₀[ℱ_micro] = R_i · [r_M, r_B, r_F, r_V]ᵀ
```

### 9.2 编程实现

```csharp
// ── 算法骨架：线性响应 ──
// 数学：(∂𝒜/∂ε_i)|₀ : 𝕄 → 𝕄𝕒𝕔
// 使用通用响应矩阵 R_i，无 switch-case

public class LinearResponseSkeleton : SkeletonBase<MicroState, MacroState>
{
    private readonly int _epsilonIndex;  // 第 i 个 ε 参数

    protected override Task<MacroState> ExecuteCoreAsync(MicroState input, SkeletonContext ctx)
    {
        return Task.Run(() => ExecuteCore(input, ctx), ctx.CancellationToken);
    }
}
```

## 10. 泰勒展开管道

### 10.1 数学

```
𝒜_ε[ℱ] = 𝒜_0[ℱ] + Σ ε_i · (∂𝒜/∂ε_i)|₀[ℱ]
```

### 10.2 编程实现

```csharp
// ── 算法骨架：泰勒展开 ──
// 数学：𝒜_ε[ℱ] = 𝒜_0[ℱ] + Σ ε_i · (∂𝒜/∂ε_i)|₀[ℱ]

public class TaylorExpansionSkeleton : SkeletonBase<MicroState, MacroState>
{
    private readonly IdealStateSkeleton _ideal = new();
    private readonly List<LinearResponseSkeleton> _responses;
    
    public TaylorExpansionSkeleton(int epsilonCount = 9) 
        : base("TaylorExpansion", "泰勒展开：𝒜₀ + Σ ε_i · (∂𝒜/∂ε_i)|₀")
    {
        _responses = Enumerable.Range(0, epsilonCount)
            .Select(i => new LinearResponseSkeleton(i))
            .ToList();
    }
    
    protected override MacroState ExecuteCore(MicroState micro, SkeletonContext ctx)
    {
        var eps = EpsilonSet.From(ctx);
        var epsArray = eps.ToArray();
        
        // 零阶项：𝒜₀[ℱ_micro]
        var result = _ideal.Execute(micro, ctx);
        
        // 一阶修正：Σ ε_i · (∂𝒜/∂ε_i)|₀ [ℱ_micro]
        for (int i = 0; i < epsArray.Length && i < _responses.Count; i++)
        {
            if (MathF.Abs(epsArray[i]) < 0.0001f) continue;
            
            var correction = _responses[i].Execute(micro, ctx);
            result = result + epsArray[i] * correction;
        }
        
        return result;
    }
    
    protected override Task<MacroState> ExecuteCoreAsync(MicroState input, SkeletonContext ctx)
    {
```

## 11. 收敛逼近 lim_{ε→0}

### 11.1 数学

```
lim_{ε→0} 𝒜_ε[ℱ_micro]

算法：ε 二分法逼近
  1. ε = 1.0
  2. V_curr = 𝒜_ε[ℱ_micro]
  3. ε ← ε/2, V_next = 𝒜_ε[ℱ_micro]
  4. 如果 ||V_next - V_curr|| < δ，返回 V_next
  5. 重复步骤 3-4

注意：这里的 ε 是算子族的索引参数，二分逼近的是 ε→0 的极限。
物理 ε 参数（孔隙率、风化度等）通过泰勒展开的一阶修正引入，不参与收敛逼近。
```

### 11.2 编程实现

```csharp
// ── 算法骨架：收敛逼近 ──
// 数学：lim_{ε→0} 𝒜_ε[ℱ_micro]
// ε 从 1.0 开始二分逼近 0，物理 ε 参数保持不变

public class ConvergenceSkeleton : SkeletonBase<MicroState, MacroState>
{
    private readonly float _threshold;  // 收敛阈值 δ
    private readonly int _maxSteps;     // 最大步数
    
    public ConvergenceSkeleton(float threshold = 0.001f, int maxSteps = 100) 
        : base("Convergence", $"收敛逼近 lim_ε→0 (δ={threshold}, max={maxSteps})")
    {
        _threshold = threshold;
        _maxSteps = maxSteps;
    }
    
    protected override MacroState ExecuteCore(MicroState micro, SkeletonContext ctx)
    {
        // 保存物理 ε 参数（收敛过程中不变）
        var physicalEpsilon = ctx.Epsilon;
        
        // 收敛逼近的 ε 从 1.0 开始二分
        float epsilon = 1.0f;
        
        // 构建泰勒展开骨架（使用物理 ε 参数）
        var taylor = new TaylorExpansionSkeleton();
        
        // 初始计算：ε = 1.0
        // 注意：TaylorExpansionSkeleton 内部使用 ctx.Epsilon（物理 ε），
        // 收敛逼近的 ε 通过修改 ctx.Epsilon 来实现
        ctx.Epsilon = new EpsilonSet { DensityFactor = epsilon };
        var current = taylor.Execute(micro, ctx);
        
        for (int step = 0; step < _maxSteps; step++)
        {
            epsilon /= 2f;
            
            // 更新 ctx.Epsilon 中的收敛参数
            ctx.Epsilon = new EpsilonSet { DensityFactor = epsilon };
            
            // 计算新值（物理 ε 参数不变，仅收敛 ε 变化）
            var next = taylor.Execute(micro, ctx);
            
            // 检查收敛
            float diff = current.DiffNorm(next);
            if (diff < _threshold)
            {
                // 恢复物理 ε
                ctx.Epsilon = physicalEpsilon;
                return next;
            }
            
            current = next;
        }
        
        // 恢复物理 ε
        ctx.Epsilon = physicalEpsilon;
        return current;
    }
    
    protected override Task<MacroState> ExecuteCoreAsync(MicroState input, SkeletonContext ctx)
    {
        return Task.Run(() => ExecuteCore(input, ctx), ctx.CancellationToken);
    }
}
```

> **修复说明**：原 v3.0 中 ConvergenceSkeleton 设置了 `ctx.Eta` 但从未使用，且 TaylorExpansionSkeleton 内部使用的是物理 ε。
> 现修正为：收敛逼近的 ε 通过修改 `ctx.Epsilon.DensityFactor` 实现，物理 ε 参数在收敛过程中保持不变。
> 注意：这是一个简化实现，实际中收敛 ε 应作为独立的参数维度与物理 ε 分离。

## 13. 联系矩阵

### 13.1 从基础公式推导

联系矩阵不是独立定义的，而是从核心公式 `ℱ_macro = lim_{ε→0} 𝒜_ε[ℱ_micro]` 推导：

```
基础公式：ℱ_macro(x) = lim_{ε→0} 𝒜_ε [ ℱ_micro(x) ]

展开为分量形式：
  P_i(x) = lim_{ε→0} ⟨𝒜_ε [ ℱ_micro(x) ], e_i ⟩
  P_j(x) = lim_{ε→0} ⟨𝒜_ε [ ℱ_micro(x) ], e_j ⟩

由于 P_i 和 P_j 共享同一个 ℱ_micro 和同一个 𝒜_ε，它们之间存在函数关系：
  P_j = F_ij(P_i, ε, ∇ℱ_micro, ...)

联系矩阵 C_ij = ∂P_j / ∂P_i 从响应矩阵 R₀ 推导：
  C_ij = ∂P_j / ∂P_i = Σ_k (∂P_j / ∂r_k) · (∂r_k / ∂P_i)
  
其中：
  ∂P_j / ∂r_k = R₀[j, k]  （响应矩阵的第 j 行）
  ∂r_k / ∂P_i = (R₀⁺)[k, i]  （伪逆的第 i 列）

因此：
  C = R₀ · R₀⁺
  
  其中 R₀ 是 19×4 的响应矩阵
  R₀⁺ 是 R₀ 的 Moore-Penrose 伪逆（4×19）
  C 是 19×19 的联系矩阵
```

### 13.2 编程实现

```csharp
// ── 联系矩阵 ──
// 从响应矩阵 R 推导宏观属性之间的联系

public static class ContactMatrix
{
    // 从响应矩阵推导联系矩阵
    // 数学：C = R · R⁺
    public static float[,] DeriveFrom(float[,] responseMatrix)
    {
        int rows = responseMatrix.GetLength(0);  // 19
        int cols = responseMatrix.GetLength(1);  // 4
        
        // 计算伪逆 R⁺
        var pseudoInverse = ComputePseudoInverse(responseMatrix);
        
        // C = R · R⁺
        var contact = new float[rows, rows];
        for (int i = 0; i < rows; i++)
        for (int j = 0; j < rows; j++)
        {
            contact[i, j] = 0f;
            for (int k = 0; k < cols; k++)
                contact[i, j] += responseMatrix[i, k] * pseudoInverse[k, j];
        }
        
        return contact;
    }
    
    // Moore-Penrose 伪逆（简化版）
    private static float[,] ComputePseudoInverse(float[,] matrix)
    {
        int rows = matrix.GetLength(0);
        int cols = matrix.GetLength(1);
        
        // 对于 19×4 矩阵，伪逆是 4×19
        // 使用公式 R⁺ = (RᵀR)⁻¹Rᵀ
        // 这里简化实现，实际应使用 SVD 分解
        
        var result = new float[cols, rows];
        // ... 伪逆计算（略）
        return result;
    }
    
    // 查询两个属性之间的联系系数
    public static float GetCoefficient(float[,] contactMatrix, int fromIndex, int toIndex)
    {
        return contactMatrix[fromIndex, toIndex];
    }
}
```

```csharp
// ── 算法骨架：源项 ──
// 数学：S[ℱ_micro, ε] = K · ℱ_micro + Σ ε_i · C_i · ℱ_micro

public class SourceTermSkeleton : SkeletonBase<Vector3, MicroState>
{
    private readonly IVoxelWorld _world;

        }
        
        return new MicroState

            B = (int)(reaction[1] + coupling[1]),
```

```csharp
            "TimeStepCondition",
            sync: state => state.step < _totalSteps);
        
        var bodySkel = new DelegateSkeleton<(Vector3, int), (Vector3, int)>(
            "TimeStepBody",
            sync: state => {
                var (pos, step) = state;
                
                // 获取当前微观状态
                var micro = _world.GetMicroState(pos);
                
                // 计算拉普拉斯
                var laplacian = new LaplacianSkeleton(_world).Execute(pos, ctx);
                var laplacianArray = new float[] { laplacian.M, laplacian.B, laplacian.F, laplacian.V };
                
                // 扩散项：D · ∇²ℱ_micro
                var diffusionArray = ReactionMatrix.Multiply(DiffusionTensor.Default, laplacianArray);
                
                // 源项：S[ℱ_micro, ε]
                var source = new SourceTermSkeleton(_world).Execute(pos, ctx);
                
                // 更新微观状态
                var newMicro = new MicroState
                {
                    M = micro.M + (int)((diffusionArray[0] + source.M) * _deltaTime),
                    B = micro.B + (int)((diffusionArray[1] + source.B) * _deltaTime),
                    F = micro.F + (int)((diffusionArray[2] + source.F) * _deltaTime),
                    V = micro.V + (int)((diffusionArray[3] + source.V) * _deltaTime),
                };
                
                // 确保非负
                newMicro.M = Math.Max(0, newMicro.M);
                newMicro.B = Math.Max(0, newMicro.B);
                newMicro.F = Math.Max(0, newMicro.F);
                newMicro.V = Math.Max(0, newMicro.V);
                
                // 写回体素世界
                _world.SetMicroState(pos, newMicro);
                
                return (pos, step + 1);
            });
        
        // 执行 Loop
        var finalState = condSkel.Loop(bodySkel).Execute(initialState);
        
        // 计算最终宏观状态
        var finalMicro = _world.GetMicroState(finalState.position);
        return new IdealStateSkeleton().Execute(finalMicro, ctx);
    }
}
```

> **修复说明**：原 v3.0 中 TimeEvolution.Build 的循环条件为 `step < totalSteps`，但第一次进入循环时 step=0 满足条件，
> 执行 body 后 step 变为 1，然后检查条件 step < totalSteps。如果 totalSteps=1，则执行一次后退出，这是正确的。
> 原 bug 描述"第一次退出"实际是误解，但原代码中 body 内部没有更新 step 导致无限循环。
> 现修正为：body 内部正确更新 step，且使用 Loop 组合子实现。

## 22. 脏标记系统

### 22.1 数学

```
脏标记 = 体素是否需要在下一帧重新计算

脏标记的传播：
  体素 x 变脏 → 邻居 x±1 也变脏（扩散影响）
  脏标记衰减：每帧衰减 0.5，低于阈值清除
```

### 22.2 编程实现

```csharp
// ── 脏标记系统 ──
// 标记需要重新计算的体素

public class DirtyFlagSystem
{
    private readonly HashSet<Vector3Int> _dirtySet = new();
    private readonly Dictionary<Vector3Int, float> _dirtyValues = new();
    private readonly float _decayRate = 0.5f;
    private readonly float _threshold = 0.01f;
    
    // 标记体素为脏
    public void MarkDirty(Vector3Int pos, float intensity = 1.0f)
    {
        _dirtySet.Add(pos);
        _dirtyValues[pos] = Math.Max(intensity, _dirtyValues.GetValueOrDefault(pos, 0f));
        
        // 传播到邻居
        foreach (var offset in NeighborOffsets)
        {
            var neighbor = pos + offset;
            float neighborIntensity = intensity * 0.5f;
            if (neighborIntensity > _threshold)
            {
                _dirtySet.Add(neighbor);
                _dirtyValues[neighbor] = Math.Max(neighborIntensity, 
                    _dirtyValues.GetValueOrDefault(neighbor, 0f));
            }
        }
    }
    
    // 检查体素是否脏
    public bool IsDirty(Vector3Int pos) => _dirtySet.Contains(pos);
    
    // 获取脏值
    public float GetDirtyValue(Vector3Int pos) => _dirtyValues.GetValueOrDefault(pos, 0f);
    
    // 清除脏标记
    public void ClearDirty(Vector3Int pos)
    {
        _dirtySet.Remove(pos);
        _dirtyValues.Remove(pos);
    }
    
    // 每帧衰减
    public void Decay()
    {
        var toRemove = new List<Vector3Int>();
        foreach (var (pos, value) in _dirtyValues)
        {
            float newValue = value * _decayRate;
            if (newValue < _threshold)
                toRemove.Add(pos);
            else
                _dirtyValues[pos] = newValue;
        }
        foreach (var pos in toRemove)
        {
            _dirtySet.Remove(pos);
            _dirtyValues.Remove(pos);
        }
    }
    
    // 获取所有脏体素
    public IEnumerable<Vector3Int> GetDirtyVoxels() => _dirtySet;
    
    private static readonly Vector3Int[] NeighborOffsets = new[]
    {
        new Vector3Int(1, 0, 0), new Vector3Int(-1, 0, 0),
        new Vector3Int(0, 1, 0), new Vector3Int(0, -1, 0),
        new Vector3Int(0, 0, 1), new Vector3Int(0, 0, -1),
    };
}
```

## 23. 增量更新管线

### 23.1 数学

```
增量更新 = 只重新计算脏体素

每帧：
  1. 收集脏体素列表
  2. 对每个脏体素执行完整更新
  3. 清除脏标记
  4. 衰减脏标记
```

### 23.2 编程实现

```csharp
// ── 增量更新管线 ──
// 只重新计算脏体素

public class IncrementalUpdatePipeline
{
    private readonly IVoxelWorld _world;
    private readonly DirtyFlagSystem _dirtyFlags;
    private readonly FullUpdateLoopSkeleton _fullUpdate;
    
    public IncrementalUpdatePipeline(IVoxelWorld world)
    {
        _world = world;
        _dirtyFlags = new DirtyFlagSystem();
        _fullUpdate = new FullUpdateLoopSkeleton(world);
    }
    
    // 标记体素为脏（外部调用）
    public void MarkDirty(Vector3Int pos, float intensity = 1.0f)
    {
        _dirtyFlags.MarkDirty(pos, intensity);
    }
    
    // 执行增量更新
    public void Update(SkeletonContext ctx)
    {
        var dirtyVoxels = _dirtyFlags.GetDirtyVoxels().ToList();
        
        foreach (var pos in dirtyVoxels)
        {
            var position = new Vector3(pos.X, pos.Y, pos.Z);
            _fullUpdate.Execute(position, ctx);
            _dirtyFlags.ClearDirty(pos);
        }
        
        // 衰减脏标记
        _dirtyFlags.Decay();
    }
    
    // 全量更新（所有体素）
    public void FullUpdate(IEnumerable<Vector3Int> allPositions, SkeletonContext ctx)
    {
        foreach (var pos in allPositions)
        {
            var position = new Vector3(pos.X, pos.Y, pos.Z);
            _fullUpdate.Execute(position, ctx);
        }
    }
}
```

```csharp
    PropertyChanged,    // 宏观属性变化
}

public class VoxelEvent
{
    public VoxelEventType Type { get; }
    public Vector3Int Position { get; }
    public object OldValue { get; }
    public object NewValue { get; }
    
    public VoxelEvent(VoxelEventType type, Vector3Int pos, object oldVal, object newVal)
    {
        Type = type;
        Position = pos;
        OldValue = oldVal;
        NewValue = newVal;
    }
}

public class VoxelEventSystem
{
    private readonly Dictionary<VoxelEventType, List<Action<VoxelEvent>>> _handlers = new();
    
    public void Subscribe(VoxelEventType type, Action<VoxelEvent> handler)
    {
        if (!_handlers.ContainsKey(type))
            _handlers[type] = new List<Action<VoxelEvent>>();
        _handlers[type].Add(handler);
    }
    
    public void Unsubscribe(VoxelEventType type, Action<VoxelEvent> handler)
    {
        if (_handlers.TryGetValue(type, out var handlers))
            handlers.Remove(handler);
    }
    
    public void Publish(VoxelEvent evt)
    {
        if (_handlers.TryGetValue(evt.Type, out var handlers))
        {
            foreach (var handler in handlers)
                handler(evt);
        }
    }
}
```

```csharp
// ── 性能分析器 ──
// 监控骨架执行性能

public class PerformanceAnalyzer
{
    private readonly Dictionary<string, List<double>> _executionTimes = new();
    private readonly Dictionary<string, int> _executionCounts = new();
    
    public IDisposable Measure(string skeletonName)
    {
        return new PerformanceMeasurement(this, skeletonName);
    }
    
    private class PerformanceMeasurement : IDisposable
    {
        private readonly PerformanceAnalyzer _analyzer;
        private readonly string _name;
        private readonly Stopwatch _stopwatch;
        
        public PerformanceMeasurement(PerformanceAnalyzer analyzer, string name)
        {
            _analyzer = analyzer;
            _name = name;
            _stopwatch = Stopwatch.StartNew();
        }
        
        public void Dispose()
        {
            _stopwatch.Stop();
            _analyzer.Record(_name, _stopwatch.Elapsed.TotalMilliseconds);
        }
    }
    
    private void Record(string name, double timeMs)
    {
        if (!_executionTimes.ContainsKey(name))
            _executionTimes[name] = new List<double>();
        _executionTimes[name].Add(timeMs);
        _executionCounts[name] = _executionCounts.GetValueOrDefault(name, 0) + 1;
    }
    
    public double GetAverageTime(string name)
    {
        if (_executionTimes.TryGetValue(name, out var times) && times.Count > 0)
            return times.Average();
        return 0;
    }
    
    public int GetExecutionCount(string name)
    {
        return _executionCounts.GetValueOrDefault(name, 0);
    }
    
    public void PrintReport()
    {
        foreach (var (name, times) in _executionTimes)
        {
            double avg = times.Average();
            double max = times.Max();
            double min = times.Min();
            int count = times.Count;
            Console.WriteLine($"{name}: avg={avg:F3}ms, max={max:F3}ms, min={min:F3}ms, count={count}");
        }
    }
}
```
