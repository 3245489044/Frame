# 综合方案：四模块协同作为世界构建第一步

> 将空间离散化、地形生成骨架、体素块组织、完整管线整合为一个统一方案
> 四模块按依赖关系分层实现，整体作为"世界构建"的第一步

---

## 1. 方案概述

### 1.1 核心理念

**不是"选一个作为第一步"，而是"四个模块作为一个整体，按依赖关系分层实现"。**

四个模块不是互斥的候选，而是**同一件事的不同侧面**：

```
世界构建第一步 = {
    模块A：空间离散化  ← 基础设施（ℝ³ → ℤ³ 映射）
    模块B：地形生成    ← 核心逻辑（ℱ_micro 实例化）
    模块C：块组织      ← 存储结构（Chunk/Region 层次）
    模块D：管线组装    ← 集成框架（Flow 组合）
}
```

### 1.2 四模块的依赖关系

```
模块A：空间离散化（VoxelIndex）
    │
    ├──→ 模块C：体素块组织（ChunkMath）← 依赖 VoxelIndex
    │
    ├──→ 模块B：地形生成骨架（TerrainGenerationSkeleton）
    │         │
    │         └──→ 依赖 VoxelIndex + MicroState
    │
    └──→ 模块D：管线组装（Flow）
              │
              └──→ 依赖 A + B + C
```

### 1.3 实现顺序

```
第1层：模块A（空间离散化）→ 无依赖，最先实现
    ↓
第2层：模块C（体素块组织）→ 依赖 A，与 B 并列
    ↓
第2层：模块B（地形生成骨架）→ 依赖 A，与 C 并列
    ↓
第3层：模块D（管线组装）→ 依赖 A+B+C，最后组装
```

## 2. 模块A：空间离散化

### 2.1 职责

提供 `ℝ³ → ℤ³` 的映射，是所有体素操作的基础。

### 2.2 核心代码

```csharp
// ── 空间离散化 ──
// 连续 ℝ³ ↔ 离散 ℤ³ 的映射

public readonly struct VoxelIndex : IEquatable<VoxelIndex>
{
    public readonly int X, Y, Z;
    
    public VoxelIndex(int x, int y, int z) { X = x; Y = y; Z = z; }
    
    // 从物理坐标计算体素索引
    public static VoxelIndex FromWorld(Vector3 worldPos, float resolution)
    {
        return new VoxelIndex(
            (int)MathF.Floor(worldPos.X / resolution),
            (int)MathF.Floor(worldPos.Y / resolution),
            (int)MathF.Floor(worldPos.Z / resolution)
        );
    }
    
    // 从体素索引计算体素中心的世界坐标
    public Vector3 ToWorldCenter(float resolution)
    {
        return new Vector3(
            (X + 0.5f) * resolution,
            (Y + 0.5f) * resolution,
            (Z + 0.5f) * resolution
        );
    }
    
    // 体素边界（AABB）
    public Aabb ToWorldAabb(float resolution)
    {
        var min = new Vector3(X * resolution, Y * resolution, Z * resolution);
        var max = new Vector3((X + 1) * resolution, (Y + 1) * resolution, (Z + 1) * resolution);
        return new Aabb(min, max - min);
    }
    
    // ── IEquatable ──
    public bool Equals(VoxelIndex other) => X == other.X && Y == other.Y && Z == other.Z;
    public override bool Equals(object obj) => obj is VoxelIndex other && Equals(other);
    public override int GetHashCode() => HashCode.Combine(X, Y, Z);
    public static bool operator ==(VoxelIndex a, VoxelIndex b) => a.Equals(b);
    public static bool operator !=(VoxelIndex a, VoxelIndex b) => !a.Equals(b);
}
```

### 3.3 核心代码

```csharp
// ── 地形生成骨架 ──
// 用 ℱ_micro 表达地形

public class TerrainGenerationSkeleton : SkeletonBase<WorldGenContext, WorldGenContext>
{
    public TerrainGenerationSkeleton()
        : base("TerrainGeneration", "地形生成：用 ℱ_micro 表达地形") { }
    
    protected override WorldGenContext ExecuteCore(WorldGenContext ctx, SkeletonContext skelCtx)
    {
        var config = ctx.Config;
        var noise = new NoiseGenerator(config.Seed);
        
        for (int x = 0; x < 32; x++)
        {
            for (int z = 0; z < 32; z++)
            {
                float heightVal = noise.OctaveNoise(
                    x, z, config.Frequency, config.Octaves, 
                    config.Lacunarity, config.Gain);
                int height = (int)((heightVal + 1f) * 15f) + 30;
                height = Math.Max(4, Math.Min(config.WorldHeight - 1, height));
                
                for (int y = 0; y < config.WorldHeight; y++)
                {
                    var index = new VoxelIndex(x, y, z);
                    
                    MicroState micro;
                    if (y == 0)
                        micro = new MicroState { M = 200, B = 150, F = 10, V = 5 };   // 基岩
                    else if (y < height - 4)
                        micro = new MicroState { M = 150, B = 120, F = 20, V = 10 };  // 石头
                    else if (y < height - 1)
                        micro = new MicroState { M = 80, B = 60, F = 40, V = 20 };    // 泥土
                    else if (y == height - 1)
                        micro = new MicroState { M = 60, B = 100, F = 15, V = 5 };    // 草方块
                    else
                        micro = new MicroState { M = 0, B = 0, F = 0, V = 0 };        // 空气
                    
                    ctx.MicroStates[index] = micro;
                }
            }
        }
        
        return ctx;
    }
}

// ── 噪声生成器 ──
public class NoiseGenerator
{
    private readonly int _seed;
    public NoiseGenerator(int seed) { _seed = seed; }
    
    public float OctaveNoise(float x, float z, float frequency, int octaves, 
        float lacunarity, float gain)
    {
        float value = 0;
        float amplitude = 1;
        float maxValue = 0;
        float freq = frequency;
        
        for (int i = 0; i < octaves; i++)
        {
            int n = (int)(x * freq * 374761393 + z * freq * 668265263 + 
                         (_seed + i * 1000) * 2246822519);
            n = (n ^ (n >> 13)) * 1274126177;
            n = n ^ (n >> 16);
            float noise = (2.0f * ((n & 0x7FFFFFFF) / (float)0x7FFFFFFF)) - 1.0f;
            value += noise * amplitude;
            maxValue += amplitude;
            amplitude *= gain;
            freq *= lacunarity;
        }
        
        return value / maxValue;
    }
}
```

## 4. 模块C：体素块组织

### 4.1 职责

定义体素如何分块存储——SubChunk → Chunk → Region 的层次结构。

### 4.2 核心代码

```csharp
// ── 体素块组织 ──
// Chunk/Region 层次结构

public static class ChunkMath
{
    // 体素坐标 → Chunk 坐标
    public static int ToChunkCoord(int voxelCoord, int chunkSize)
    {
        return voxelCoord >= 0 
            ? voxelCoord / chunkSize 
            : (voxelCoord - chunkSize + 1) / chunkSize;
    }
    
    // 体素坐标 → Chunk 内局部坐标
    public static int ToLocalCoord(int voxelCoord, int chunkSize)
    {
        int c = ToChunkCoord(voxelCoord, chunkSize);
        return voxelCoord - c * chunkSize;
    }
    
    // Chunk 坐标 → Region 坐标
    public static int ToRegionCoord(int chunkCoord, int chunksPerDim)
    {
        return chunkCoord >= 0
            ? chunkCoord / chunksPerDim
            : (chunkCoord - chunksPerDim + 1) / chunksPerDim;
    }
}

// ── 体素块组织骨架 ──
public class ChunkOrganizationSkeleton : SkeletonBase<VoxelIndex, (int, int, int)>
{
    private readonly int _chunkSizeX, _chunkSizeY, _chunkSizeZ;
    
    public ChunkOrganizationSkeleton(
        int chunkSizeX = 32, int chunkSizeY = 64, int chunkSizeZ = 32)
        : base("ChunkOrganization", "体素 → Chunk 坐标映射")
    {
        _chunkSizeX = chunkSizeX;
        _chunkSizeY = chunkSizeY;
        _chunkSizeZ = chunkSizeZ;
    }
    
    protected override (int, int, int) ExecuteCore(VoxelIndex voxel, SkeletonContext ctx)
    {
        return (
            ChunkMath.ToChunkCoord(voxel.X, _chunkSizeX),
            ChunkMath.ToChunkCoord(voxel.Y, _chunkSizeY),
            ChunkMath.ToChunkCoord(voxel.Z, _chunkSizeZ)
        );
    }
}
```

### 4.3 区块化骨架（将 MicroState 分块存储）

```csharp
// ── 区块化骨架 ──
// 将体素数据分块存储到 HighResChunk

public class ChunkingSkeleton : SkeletonBase<WorldGenContext, HighResChunk[]>
{
    private readonly int _chunkSizeX = 32;
    private readonly int _chunkSizeY = 64;
    private readonly int _chunkSizeZ = 32;
    
    public ChunkingSkeleton()
        : base("Chunking", "区块化：将体素数据分块存储") { }
    
    protected override HighResChunk[] ExecuteCore(WorldGenContext ctx, SkeletonContext skelCtx)
    {
        // 按 Chunk 坐标分组
        var chunkGroups = new Dictionary<(int, int, int), List<(VoxelIndex, MicroState)>>();
        
        foreach (var (index, micro) in ctx.MicroStates)
        {
            int cx = ChunkMath.ToChunkCoord(index.X, _chunkSizeX);
            int cy = ChunkMath.ToChunkCoord(index.Y, _chunkSizeY);
            int cz = ChunkMath.ToChunkCoord(index.Z, _chunkSizeZ);
            var key = (cx, cy, cz);
            
            if (!chunkGroups.ContainsKey(key))
                chunkGroups[key] = new List<(VoxelIndex, MicroState)>();
            chunkGroups[key].Add((index, micro));
        }
        
        var chunks = new List<HighResChunk>();
        foreach (var ((cx, cy, cz), voxels) in chunkGroups)
        {
            var chunk = new HighResChunk(cx, cy, cz);
            
            foreach (var (index, micro) in voxels)
            {
                int lx = ChunkMath.ToLocalCoord(index.X, _chunkSizeX);
                int ly = ChunkMath.ToLocalCoord(index.Y, _chunkSizeY);
                int lz = ChunkMath.ToLocalCoord(index.Z, _chunkSizeZ);
                
                var voxel = MicroStateToVoxel(micro);
                chunk.SetVoxel(lx, ly, lz, voxel);
            }
            
            chunk.NeedsLODUpdate = true;
            chunk.NeedsMeshBuild = true;
            chunks.Add(chunk);
        }
        
        return chunks.ToArray();
    }
    
    // MicroState → Voxel 转换
    private static Voxel MicroStateToVoxel(MicroState micro)
    {
        if (micro.IsEmpty)
            return Voxel.Empty;
        
        BlockID block;
        if (micro.M > 150) block = BlockID.Stone;
        else if (micro.B > 80) block = BlockID.Grass;
        else if (micro.M > 50) block = BlockID.Dirt;
        else block = BlockID.Air;
        
        return new Voxel(block, MaterialID.Default);
    }
}
```

## 5. 模块D：管线组装

### 5.1 职责

将模块A、B、C组装为完整的 Flow 管线，作为世界构建的统一入口。

### 5.2 核心代码

```csharp
// ── 完整世界构建管线 ──
// 将四个模块组装为 Flow

public static class WorldBuildPipeline
{
    // 构建世界生成管线（从配置到 Chunk）
    public static Flow<WorldGenContext, HighResChunk[]> Build()
    {
        return Flow.Start<WorldGenContext>()
            .Then(new TerrainGenerationSkeleton())     // 模块B：地形生成
            .Then(new ChunkingSkeleton());              // 模块C：区块化
    }
    
    // 构建完整游戏管线（包含运行时管理）
    public static Flow<VoxelGameContext, VoxelGameContext> BuildGameFlow()
    {
        return Flow.Start<VoxelGameContext>()
            .Then(new VoxelInputPhaseSkeleton())        // 输入
            .Then(new WorldRuntimeSkeleton())           // 世界管理
            .Then(new LodBuildSkeleton())               // LOD
            .Then(new ChunkMeshBuildSkeleton())         // 网格
            .Then(new VoxelRenderPhaseSkeleton())       // 渲染
            .Then(new VoxelUIPhaseSkeleton());          // UI
    }
}
```

### 5.3 使用示例

```csharp
// ── 使用示例 ──
public class WorldBuildingDemo
{
    public void Run()
    {
        // 1. 创建世界配置
        var config = WorldConfig.Default(12345);
        config.Resolution = 0.01f;  // 1cm³ 体素
        
        // 2. 创建世界生成上下文
        var genCtx = new WorldGenContext(config);
        
        // 3. 执行世界生成管线（模块B + 模块C）
        var pipeline = WorldBuildPipeline.Build();
        var chunks = pipeline.Execute(genCtx);
        
        // 4. 将 Chunk 添加到世界管理器
        var worldManager = new HighResWorldManager(config.Seed, (int)(1f / config.Resolution));
        foreach (var chunk in chunks)
        {
            worldManager.AddChunk(chunk);
        }
        
        // 5. 在游戏循环中使用完整管线
        var gameCtx = new VoxelGameContext(new EcsContext());
        gameCtx.WorldManager = worldManager;
        
        var gameFlow = WorldBuildPipeline.BuildGameFlow();
        while (true)
        {
            gameCtx = gameFlow.Execute(gameCtx);
        }
    }
}
```

```csharp
        Debug.Assert(idx1 == new VoxelIndex(1, 2, 3), "A1: 正坐标转换");
        Console.WriteLine("  ✅ A1: 正坐标转换");
        
        var idx2 = VoxelIndex.FromWorld(new Vector3(-0.5f, -1.3f, -2.8f), 1.0f);
        Debug.Assert(idx2 == new VoxelIndex(-1, -2, -3), "A2: 负坐标 floor");
        Console.WriteLine("  ✅ A2: 负坐标 floor");
        
        var center = new VoxelIndex(1, 2, 3).ToWorldCenter(0.1f);
        Debug.Assert(center == new Vector3(0.15f, 0.25f, 0.35f), "A3: 体素中心");
        Console.WriteLine("  ✅ A3: 体素中心");
        
        // 模块C：体素块组织
        Console.WriteLine("\n--- 模块C：体素块组织 ---");
        Debug.Assert(ChunkMath.ToChunkCoord(0, 32) == 0, "C1: Chunk 坐标");
        Debug.Assert(ChunkMath.ToChunkCoord(32, 32) == 1, "C2: Chunk 边界");
        Debug.Assert(ChunkMath.ToChunkCoord(-1, 32) == -1, "C3: 负 Chunk 坐标");
        Debug.Assert(ChunkMath.ToLocalCoord(31, 32) == 31, "C4: 局部坐标");
        Debug.Assert(ChunkMath.ToLocalCoord(32, 32) == 0, "C5: 局部坐标边界");
        Console.WriteLine("  ✅ C1-C5: ChunkMath");
        
        // 模块B：地形生成
        Console.WriteLine("\n--- 模块B：地形生成 ---");
        var config = WorldConfig.Default(42);
        var ctx = new WorldGenContext(config);
        new TerrainGenerationSkeleton().Execute(ctx, new SkeletonContext());
        
        Debug.Assert(ctx.MicroStates.Count > 0, "B1: 非空");
        Console.WriteLine($"  ✅ B1: 生成了 {ctx.MicroStates.Count} 个体素");
        
        int bedrock = ctx.MicroStates.Values.Count(m => m.M == 200);
        Debug.Assert(bedrock > 0, "B2: 基岩层");
        Console.WriteLine($"  ✅ B2: 基岩层 {bedrock} 个体素");
        
        int grass = ctx.MicroStates.Values.Count(m => m.M == 60 && m.B == 100);
        Debug.Assert(grass > 0, "B3: 草方块");
        Console.WriteLine($"  ✅ B3: 草方块 {grass} 个体素");
        
        // 模块D：管线组装
        Console.WriteLine("\n--- 模块D：管线组装 ---");
        var pipeline = WorldBuildPipeline.Build();
        var chunks = pipeline.Execute(new WorldGenContext(WorldConfig.Default(42)));
        Debug.Assert(chunks.Length > 0, "D1: 生成 Chunk");
        Console.WriteLine($"  ✅ D1: 生成了 {chunks.Length} 个 Chunk");
        
        int solid = 0;
        foreach (var chunk in chunks)
        for (int x = 0; x < 32; x++)
        for (int y = 0; y < 64; y++)
        for (int z = 0; z < 32; z++)
            if (!chunk.GetVoxel(x, y, z).IsEmpty) solid++;
        Debug.Assert(solid > 0, "D2: 非空气体素");
        Console.WriteLine($"  ✅ D2: {solid} 个非空气体素");
        
        Console.WriteLine($"\n=== 全部通过！===");
    }
}
```

### 8.2 各模块评分

| 模块 | 基础性 | 可验证性 | 实现难度 | 直观反馈 | 推荐度 |
|------|--------|---------|---------|---------|-------|
| A：空间离散化 | ★★★ | ★★★ | ★ | ★ | 基础设施，必须实现 |
| B：地形生成 | ★★★ | ★★★ | ★★ | ★★★ | 核心逻辑，重点实现 |
| C：体素块组织 | ★★ | ★★★ | ★ | ★★ | 存储结构，必须实现 |
| D：管线组装 | ★★ | ★★ | ★★ | ★★★ | 集成框架，最后组装 |

### 8.3 最终结论

**世界构建的第一步不是"选一个模块"，而是"四个模块作为一个整体，按依赖关系分层实现"：**

1. **先打地基**：模块A（空间离散化）→ 提供 VoxelIndex
2. **再搭框架**：模块C（体素块组织）→ 提供 Chunk 结构
3. **再填内容**：模块B（地形生成）→ 填充 ℱ_micro 数据
4. **最后组装**：模块D（管线组装）→ 组合为 Flow

这种分层方式确保：
- **每一步都可验证**：每个模块都有独立的单元测试
- **每一步都有意义**：每个模块都是世界构建的必要组成部分
- **最终自然集成**：四个模块组合为完整的管线
- **与框架理论一致**：从 ℝ³ → ℤ³（A）到 ℱ_micro（B）到 Chunk（C）到 Flow（D）
