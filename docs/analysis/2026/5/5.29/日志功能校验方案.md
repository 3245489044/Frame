# 日志功能校验方案

## 概述

本文档规划了对 `交互启动.bat` 中日志功能的完整校验方案。方案分为两个阶段：

1. **阶段一：单元测试** — 在现有测试框架中补充缺失的集成测试
2. **阶段二：实际运行验证** — 通过实际执行验证完整链路

---

## 一、背景分析

### 1.1 交互启动.bat 的日志链路

```
交互启动.bat
  │
  ├── 设置环境变量:
  │     FILEDRIVEN_BATCH_ID    = Run_{timestamp}
  │     FILEDRIVEN_BATCH_NAME  = 交互启动 {date} {time}
  │     FILEDRIVEN_BATCH_SOURCE = 交互启动.bat
  │     FILEDRIVEN_BATCH_DESC  = GUI 模式测试运行
  │
  └── 调用 PowerShell → 最终调用 FileDriven.Launcher.exe
        │
        ├── Program.Main()
        │     ├── LoggingSetup.Initialize(options.LogCategories)
        │     ├── Logger 写入日志（自动关联批次）
        │     ├── FrameworkInitializer.Shutdown()
        │     └── ExecuteLogPipeline()
        │           ├── 读取环境变量
        │           ├── BatchLoggerBridge.RegisterBatch()
        │           ├── LogPipeline.ExecuteWithExceptionHandling()
        │           │     ├── LogCollectSkeleton    → 注册批次
        │           │     ├── LogTryExecuteSkeleton  → 异常捕获
        │           │     │     ├── 主路径: LogFlushSkeleton → LogExportSkeleton
        │           │     │     └── 降级路径: LogEmergencyDumpSkeleton
        │           │     └── 结果输出到 Console
        │           └── EmergencyFileDump()  ← 最外层兜底
        │
        └── 导出的 JSON 文件 → PowerShell LogViewer.ps1 读取
```

### 1.3 缺失的测试环节

| 缺失环节 | 说明 | 重要性 |
|---|---|---|
| **环境变量 → BatchLoggerBridge 集成** | 没有测试 bat 设置的环境变量能否被 C# 端正确读取 | 🔴 高 |
| **LogPipeline 完整管线** | 没有测试 Collect → Flush → Export 的完整流程 | 🔴 高 |
| **异常降级路径** | 没有测试主路径失败时 EmergencyDump 是否生效 | 🔴 高 |
| **JSON 文件格式兼容性** | 没有测试导出的 JSON 格式是否与 LogViewer.ps1 兼容 | 🟡 中 |
| **完整端到端链路** | 没有从"设置环境变量"到"JSON 文件落地"的完整链路测试 | 🔴 高 |
| **LogFileExporter 文件清理** | 没有测试 CleanupOldBatchFiles 的清理逻辑 | 🟡 中 |
| **LogRepository TrimExcess** | 没有测试超出上限时的自动清理和索引重建 | 🟡 中 |
| **Logger 多目标输出** | 没有测试 Console/Debug/UI/Repository 四种目标的组合 | 🟡 中 |

#### 2.2.3 导出器测试 (`LogFileExporterTests.cs`)

```csharp
[TestClass]
public class LogFileExporterTests : BatchTestBase
{
    private string _testOutputDir = null!;

    [TestInitialize]
    public void Init()
    {
        _testOutputDir = Path.Combine(Path.GetTempPath(), "LogFileExporterTests", Guid.NewGuid().ToString());
        Directory.CreateDirectory(_testOutputDir);
    }

    [TestCleanup]
    public void Cleanup()
    {
        if (Directory.Exists(_testOutputDir))
            Directory.Delete(_testOutputDir, true);
    }

    // 测试 1: 导出 JSON 格式正确
    [TestMethod]
    public void Test_Export_JsonFormat()
    {
        // Arrange: 注册批次并写入日志
        BatchRouter.Instance.RegisterBatch("test_export", new BatchMetadata { Name = "ExportTest" });
        LogRepository.Write(new LogEntry
        {
            Timestamp = DateTime.Now,
            Level = "INFO",
            Category = LogCategory.System,
            Module = "Test",
            Message = "Test message"
        });
        BatchRouter.Instance.FlushToIsolatedStorage("test_export");

        // Act: 导出
        var files = LogFileExporter.ExportBatch("test_export", _testOutputDir);

        // Assert: 文件存在
        Assert.IsTrue(files.Count > 0);
        var latestFile = files.FirstOrDefault(f => f.Contains("_latest"));
        Assert.IsNotNull(latestFile);
        Assert.IsTrue(File.Exists(latestFile));

        // Assert: JSON 格式正确
        var json = File.ReadAllText(latestFile);
        var data = System.Text.Json.JsonSerializer.Deserialize<JsonElement>(json);

        Assert.IsTrue(data.TryGetProperty("batchId", out var batchIdProp));
        Assert.AreEqual("test_export", batchIdProp.GetString());

        Assert.IsTrue(data.TryGetProperty("totalCount", out var countProp));
        Assert.IsTrue(countProp.GetInt32() > 0);

        Assert.IsTrue(data.TryGetProperty("entries", out var entriesProp));
        Assert.IsTrue(entriesProp.GetArrayLength() > 0);

        // Assert: 与 LogViewer.ps1 兼容的字段
        var firstEntry = entriesProp[0];
        Assert.IsTrue(firstEntry.TryGetProperty("timestamp", out _));
        Assert.IsTrue(firstEntry.TryGetProperty("level", out _));
        Assert.IsTrue(firstEntry.TryGetProperty("category", out _));
        Assert.IsTrue(firstEntry.TryGetProperty("module", out _));
        Assert.IsTrue(firstEntry.TryGetProperty("message", out _));
    }

    // 测试 2: 空批次导出
    [TestMethod]
    public void Test_Export_EmptyBatch()
    {
        BatchRouter.Instance.RegisterBatch("test_empty", new BatchMetadata { Name = "Empty" });
        var files = LogFileExporter.ExportBatch("test_empty", _testOutputDir);
        Assert.AreEqual(0, files.Count);
    }

    // 测试 3: 文件清理逻辑
    [TestMethod]
    public void Test_Export_CleanupOldFiles()
    {
        // 创建大量旧文件
        for (int i = 0; i < 60; i++)
        {
            File.WriteAllText(Path.Combine(_testOutputDir, $"batch_old_{i:D3}_latest.json"), "{}");
        }

        // 导出新批次（触发清理）
        BatchRouter.Instance.RegisterBatch("test_cleanup", new BatchMetadata { Name = "Cleanup" });
        LogRepository.Write(new LogEntry
        {
            Timestamp = DateTime.Now,
            Level = "INFO",
            Category = LogCategory.System,
            Module = "Test",
            Message = "Cleanup test"
        });
        BatchRouter.Instance.FlushToIsolatedStorage("test_cleanup");
        LogFileExporter.ExportBatch("test_cleanup", _testOutputDir);

        // 验证旧文件被清理（最多保留 50 个）
        var remainingFiles = Directory.GetFiles(_testOutputDir, "batch_*.json");
        Assert.IsTrue(remainingFiles.Length <= 51); // 50 旧 + 1 新
    }
}
```

#### 2.2.5 LogRepository 高级测试 (`LogRepositoryAdvancedTests.cs`)

```csharp
[TestClass]
public class LogRepositoryAdvancedTests : TestBase
{
    [TestCleanup]
    public void Cleanup() => LogRepository.Clear();

    // 测试 1: TrimExcess 自动清理
    [TestMethod]
    public void Test_Repository_TrimExcess()
    {
        // Arrange: 设置较小的上限
        LogRepository.MaxEntries = 100;

        // Act: 写入 200 条日志
        for (int i = 0; i < 200; i++)
        {
            LogRepository.Write(new LogEntry
            {
                Timestamp = DateTime.Now,
                Level = "INFO",
                Category = LogCategory.System,
                Module = "Test",
                Message = $"Log #{i}"
            });
        }

        // Assert: 应只保留 100 条
        Assert.AreEqual(100, LogRepository.Count);

        // Assert: 索引应正确重建
        var allLogs = LogRepository.GetAll().ToList();
        Assert.AreEqual(100, allLogs.Count);
        // 应保留最新的 100 条（序号 101-200）
        Assert.AreEqual(101, allLogs.First().SequenceNumber);
        Assert.AreEqual(200, allLogs.Last().SequenceNumber);
    }

    // 测试 2: SequenceNumber 单调递增
    [TestMethod]
    public void Test_Repository_SequenceNumber()
    {
        // Act: 写入 5 条日志
        for (int i = 0; i < 5; i++)
        {
            LogRepository.Write(new LogEntry
            {
                Timestamp = DateTime.Now,
                Level = "INFO",
                Category = LogCategory.System,
                Module = "Test",
                Message = $"Seq #{i}"
            });
        }

        // Assert: SequenceNumber 从 1 开始单调递增
        var logs = LogRepository.GetAll().ToList();
        for (int i = 0; i < logs.Count; i++)
        {
            Assert.AreEqual(i + 1, logs[i].SequenceNumber);
        }
    }

    // 测试 3: GetNewerThan 增量读取
    [TestMethod]
    public void Test_Repository_GetNewerThan()
    {
        // 写入 3 条
        for (int i = 0; i < 3; i++)
            LogRepository.Write(new LogEntry { Timestamp = DateTime.Now, Level = "INFO", Category = LogCategory.System, Module = "Test", Message = $"Log #{i}" });

        var lastSeq = LogRepository.GetMaxSequence();

        // 再写入 2 条
        for (int i = 3; i < 5; i++)
            LogRepository.Write(new LogEntry { Timestamp = DateTime.Now, Level = "INFO", Category = LogCategory.System, Module = "Test", Message = $"Log #{i}" });

        // 只获取新增的
        var newer = LogRepository.GetNewerThan(lastSeq).ToList();
        Assert.AreEqual(2, newer.Count);
        Assert.AreEqual(4, newer[0].SequenceNumber);
        Assert.AreEqual(5, newer[1].SequenceNumber);
    }

    // 测试 4: 分类索引查询
    [TestMethod]
    public void Test_Repository_CategoryIndex()
    {
        LogRepository.Write(new LogEntry { Timestamp = DateTime.Now, Level = "INFO", Category = LogCategory.WdUI_Layout, Module = "WdUI", Message = "Layout" });
        LogRepository.Write(new LogEntry { Timestamp = DateTime.Now, Level = "INFO", Category = LogCategory.WdUI_Render, Module = "WdUI", Message = "Render" });
        LogRepository.Write(new LogEntry { Timestamp = DateTime.Now, Level = "INFO", Category = LogCategory.FileDriven_General, Module = "FileDriven", Message = "File" });

        // 查询 WdUI 所有分类
        var wduiLogs = LogRepository.GetByCategory(LogCategory.WdUI_All).ToList();
        Assert.AreEqual(2, wduiLogs.Count);

        // 查询 FileDriven
        var fdLogs = LogRepository.GetByCategory(LogCategory.FileDriven_All).ToList();
        Assert.AreEqual(1, fdLogs.Count);
    }
}
```

## 五、总结

本方案通过 **单元测试 + 实际运行验证** 两个阶段，全面覆盖 `交互启动.bat` 的日志功能：

- **单元测试**（阶段一）：在现有测试框架中补充 5 个测试文件，覆盖管线、导出、环境变量、高级仓库功能
- **实际运行验证**（阶段二）：创建一个独立的验证程序，模拟完整链路，9 个阶段逐层验证

两个阶段互为补充：单元测试精确定位问题，实际运行验证确认链路完整性。
