# 管线简化重构方案

## 1. 当前问题

### 1.1 两个错误现象

| 模式 | 错误日志 | 阶段 |
|------|---------|------|
| 自动执行 | `click addButton: Plus 执行失败: 参数 a,b not matched` | ExecuteFunctionStage |
| GUI 交互 | `valueATextBox.textchanged: No binding found` | FindBindingStage |

### 1.2 根因

两个错误是**同一个根因**：当前管线有 4 个阶段（FindBinding → ExtractValues → ExecuteFunction → WriteResult），阶段之间通过 `CommandContext` 的中间状态（`BoundFunctionName`/`BoundInputs`/`ExtractedValues`）传递数据，导致：

1. **FindBindingStage** 查找事件绑定时，自动模式和 GUI 模式走了不同的查找路径（`PipelineEntry.FindBinding` vs `EventBindingResolver.FindEventBinding`），行为不一致
2. **ExecuteFunctionStage** 接收的参数经过多次转换（BoundInputs → ExtractedValues → parameters），类型信息丢失，`string[]` 无法匹配 `(double, double)` 参数

### 1.3 管线复杂度现状

```
当前事件命令管线（4 阶段）：
  ParseCommand
    → CommandRouter（判断事件/非事件）
      → FindBinding（查找绑定，填充 BoundFunctionName/BoundInputs）
        → ExtractValues（提取值，填充 ExtractedValues）
          → ExecuteFunction（从 ExtractedValues 构建参数，执行函数）
            → WriteResult（写回结果）

当前非事件命令管线（1 阶段）：
  ParseCommand
    → CommandRouter（判断事件/非事件）
      → NonEventExecute（直接执行）
```

问题：事件命令的 4 个阶段中，**FindBinding 和 ExtractValues 只是为 ExecuteFunction 准备数据**，完全可以合并。

---

## 2. 重构方案：合并为 2 阶段

### 2.1 新管线结构

```
统一命令管线（2 阶段）：
  ParseCommand（解析命令）
    → ExecuteCommand（执行命令，内部处理所有逻辑）
```

### 2.2 阶段职责

| 阶段 | 职责 |
|------|------|
| **ParseCommand** | 解析命令字符串 → `{ action, target, value }` |
| **ExecuteCommand** | 根据 action 执行对应逻辑，内部处理：值提取、函数调用、结果写入 |

### 2.3 ExecuteCommand 内部逻辑

```
ExecuteCommand(action, target, value):
  if action == "set":
    if GUI模式: 设置真实控件值，触发 TextChanged 事件
    if CLI模式: 写入虚拟存储
    return OK

  if action == "click":
    binding = 查找控件配置中的 click 绑定  ← 统一查找路径
    if binding == null: return 错误
    values = 从 UI/虚拟存储提取 binding.Inputs 的值
    result = FunctionExecutor.Execute(binding.FunctionName, values)
    if binding.Output != null: 写回结果到 UI/虚拟存储
    return result

  if action == "sideload":
    加载配置到侧边容器
    return OK

  if action == "sleep":
    Thread.Sleep(value)
    return OK

  if action == "close":
    关闭窗口
    return OK

  if action == "exit":
    退出应用
    return OK

  // 其他非事件命令同理
```

### 2.4 关键变化

| 变化 | 说明 |
|------|------|
| **去掉 FindBindingStage** | 绑定查找逻辑内聚到 ExecuteCommand 的 click 分支中 |
| **去掉 ExtractValuesStage** | 值提取逻辑内聚到 ExecuteCommand 的 click 分支中 |
| **去掉 WriteResultStage** | 结果写入逻辑内聚到 ExecuteCommand 的 click 分支中 |
| **去掉 CommandRouterStage** | 不再区分事件/非事件命令，统一由 ExecuteCommand 处理 |
| **去掉 BoundFunctionName/BoundInputs/BoundOutputTarget** | 不再需要跨阶段传递的中间状态 |
| **统一绑定查找路径** | 自动模式和 GUI 模式使用同一个查找方法 |

## 4. ExecuteCommandStage 核心代码设计

```csharp
public class ExecuteCommandStage : CommandStageBase
{
    private readonly IFunctionExecutor? _functionExecutor;
    private readonly IWinFormsEventTrigger? _winFormsEventTrigger;
    // 绑定查找器：统一自动模式和 GUI 模式的绑定查找
    private readonly Func<string, string, IEventBindingInfo?>? _bindingFinder;

    protected override async Task ExecuteCoreAsync(CommandContext context, CancellationToken ct)
    {
        var action = context.ParsedCommand?.Action?.ToLowerInvariant();
        var target = context.ParsedCommand?.Target;
        var value = context.ParsedCommand?.Value;

        switch (action)
        {
            case "set":
                await HandleSet(context, target, value);
                break;

            case "click":
                await HandleClick(context, target);
                break;

            // 非事件命令
            case "sideload":
            case "sleep":
            case "close":
            case "exit":
            case "echo":
            case "load":
            case "show":
            case "list":
                await HandleNonEvent(context, action, target, value);
                break;

            default:
                context.SetStageResult(Name, false, $"Unknown command: {action}");
                break;
        }
    }

    private async Task HandleSet(CommandContext context, string? target, string? value)
    {
        if (string.IsNullOrEmpty(target) || value == null)
        {
            context.SetStageResult(Name, false, "set requires target and value");
            return;
        }

        // GUI 模式：设置真实控件值
        if (context.IsGuiMode && context.TargetForm != null)
        {
            var trigger = GetWinFormsEventTrigger(context);
            trigger?.SetControlTextAndTriggerEvent(context.TargetForm, target, value);
        }

        // CLI 模式：写入虚拟存储
        if (context.VirtualStore != null)
        {
            context.VirtualStore[target] = value;
        }

        context.SetStageResult(Name, true);
    }

    private async Task HandleClick(CommandContext context, string? target)
    {
        if (string.IsNullOrEmpty(target))
        {
            context.SetStageResult(Name, false, "click requires target");
            return;
        }

        // 1. 查找绑定（统一路径）
        var binding = FindBinding(target, "click");
        if (binding == null)
        {
            context.SetStageResult(Name, false,
                $"No click binding found for '{target}'");
            return;
        }

        // 2. 提取输入值
        var values = ExtractValues(context, binding.Inputs);
        if (values == null)
        {
            context.SetStageResult(Name, false,
                $"Failed to extract input values for '{target}'");
            return;
        }

        // 3. 执行函数
        var executor = GetFunctionExecutor(context);
        var result = await executor.ExecuteAsync(binding.FunctionName, values);

        if (!result.IsSuccess)
        {
            context.SetStageResult(Name, false,
                $"Function '{binding.FunctionName}' execution failed: {result.ErrorMessage}");
            return;
        }

        // 4. 写回结果
        if (binding.Output != null && result.Value != null)
        {
            WriteResult(context, binding.Output, result.Value.ToString());
        }

        context.FunctionResultValue = result.Value;
        context.SetStageResult(Name, true);
    }

    private async Task HandleNonEvent(CommandContext context, string action,
        string? target, string? value)
    {
        // 非事件命令直接处理，不再通过 NonEventCommandRegistry
        switch (action)
        {
            case "sideload":
                // 加载配置到侧边容器
                await SideloadConfig(context, target);
                break;
            case "sleep":
                if (int.TryParse(target ?? value, out var ms))
                    await Task.Delay(ms);
                break;
            case "close":
                // 关闭窗口
                CloseWindow(context, target);
                break;
            case "exit":
                Application.Exit();
                break;
            case "echo":
                Console.WriteLine(target ?? value);
                break;
            // ... 其他命令
        }
        context.SetStageResult(Name, true);
    }
}
```
