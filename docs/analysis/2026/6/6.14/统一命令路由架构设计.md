# 统一命令路由架构设计文档

## 1. 概述

### 1.1 背景

当前 FileDriven 框架存在**双轨制命令路由**问题：

- **事件命令**（set/click 等）：走 `ParseCommand → FindBinding → ExtractValues → ExecuteFunction → WriteResult` 五阶段管线
- **非事件命令**（sideload/sleep/close/exit 等）：走 `NonEventCommandRegistry` 独立路由

两套路由系统各自独立维护，导致：
1. 非事件命令注册不完整（`sideload`/`sleep`/`close`/`exit` 未注册）
2. 事件绑定查找与 UI 加载时序耦合（`sideload` 失败导致后续所有命令失败）
3. 错误信息不明确（无法区分"绑定不存在"和"UI 未加载"）
4. 扩展新命令类型需要修改多处代码

### 1.2 目标

设计一套**统一命令路由架构**，将所有命令纳入同一管线体系，消除双轨制。

### 2.1 当前管线阶段

```
命令字符串
    │
    ▼
┌─────────────────────────────────────────────────────────────┐
│  ParseCommandStage（解析 + 路由）                            │
│                                                             │
│  1. 解析命令字符串 → ParsedCommand                          │
```

### 2.2 当前非事件命令路由

```
ParseCommandStage 中：
  if (parsed.IsNonEventCommand)
  {
      if (_findNonEventHandler != null)
      {
          var handled = await _findNonEventHandler(action, context);
          if (handled) { ... return; }
      }
      // 未找到处理函数 → 报错
  }
```

`_findNonEventHandler` 委托在 `PipelineFactory.BuildCommandPipeline()` 中构造：

```csharp
findNonEventHandler = (action, context) =>
{
    var registry = FunctionStorageRegistry.NonEventRegistry;
    if (!registry.TryGetHandler(action, out var handler))
        return Task.FromResult(false);
    
    handler(context);
    return Task.FromResult(true);
};
```

## 3. 目标架构设计

### 3.1 核心原则

1. **统一路由**：所有命令（事件/非事件/Engine/适配器）都走同一管线
2. **阶段化**：每个命令类型对应一个独立的管线阶段
3. **可组合**：管线阶段可按需组合，支持 GUI/CLI 不同模式
4. **可观测**：每个阶段都有统一的执行时间、结果、错误记录

### 3.2 新管线架构

```
命令字符串
    │
    ▼
┌─────────────────────────────────────────────────────────────┐
│  ParseCommandStage（仅解析，不路由）                         │
│  输出: ParsedCommand（含 IsNonEventCommand 标记）            │
└─────────────────────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────────────────────┐
│  CommandRouterStage（命令路由阶段）★ 新增 ★                  │
│                                                             │
│  根据 ParsedCommand 类型路由到不同的子管线：                  │
│                                                             │
│  ┌─────────────────────┐  ┌──────────────────────────────┐  │
│  │ 非事件命令子管线     │  │ 事件命令子管线               │  │
│  │                     │  │                              │  │
│  │ NonEventExecuteStage │  │ FindBindingStage             │  │
```

### 3.3 核心组件设计

#### 3.3.1 CommandRouterStage

```csharp
/// <summary>
/// 命令路由阶段 — 根据命令类型路由到对应的子管线
/// </summary>
public class CommandRouterStage : CommandStageBase
{
    private readonly IReadOnlyDictionary<string, IPipelineStage<CommandContext>> _routes;

    public CommandRouterStage(
        IPipelineStage<CommandContext> nonEventPipeline,
        IPipelineStage<CommandContext> eventPipeline,
        IPipelineStage<CommandContext>? enginePipeline = null,
        IPipelineStage<CommandContext>? adapterPipeline = null)
    {
        _routes = new Dictionary<string, IPipelineStage<CommandContext>>
        {
            ["non-event"] = nonEventPipeline,
            ["event"] = eventPipeline,
            ["engine"] = enginePipeline ?? new NullStage("EngineRoute"),
            ["adapter"] = adapterPipeline ?? new NullStage("AdapterRoute"),
        };
    }

    protected override async Task ExecuteCoreAsync(CommandContext context, CancellationToken ct)
    {
        var routeKey = DetermineRoute(context.ParsedCommand);
        if (routeKey == null)
        {
            context.SetStageResult(Name, false, "Unable to determine command route");
            return;
        }

        var stage = _routes[routeKey];
        await stage.ExecuteAsync(context, ct);
        
        // 传播子管线的执行结果
        var stageResult = context.GetStageResult(stage.Name);
        context.SetStageResult(Name, stageResult?.IsSuccess ?? false, 
            stageResult?.ErrorMessage);
    }

    private string? DetermineRoute(ParsedCommand? parsed)
    {
        if (parsed?.IsNonEventCommand == true) return "non-event";
        if (parsed?.Verb != null && IsEngineCommand(parsed.Verb)) return "engine";
        if (parsed?.Verb != null && IsAdapterCommand(parsed.Verb)) return "adapter";
        if (parsed?.IsSuccess == true) return "event";
        return null;
    }
}
```

#### 3.3.2 NonEventExecuteStage

```csharp
/// <summary>
/// 非事件命令执行阶段 — 直接执行非事件命令的处理函数
/// </summary>
public class NonEventExecuteStage : CommandStageBase
{
    private readonly INonEventCommandRegistry _registry;

    public NonEventExecuteStage(INonEventCommandRegistry registry)
        : base("NonEventExecute", "Execute non-event commands")
    {
        _registry = registry;
    }

    protected override Task ExecuteCoreAsync(CommandContext context, CancellationToken ct)
    {
        var action = context.ParsedCommand?.Action ?? context.ParsedCommand?.Verb;
        if (string.IsNullOrEmpty(action))
        {
            context.SetStageResult(Name, false, "Non-event command action is empty");
            return Task.CompletedTask;
        }

        if (!_registry.TryGetHandler(action, out var handler))
        {
            context.SetStageResult(Name, false,
                $"Non-event command '{action}' not registered. " +
                $"Available: {string.Join(", ", _registry.GetRegisteredCommands())}");
            return Task.CompletedTask;
        }

        try
        {
            var sw = Stopwatch.StartNew();
            handler(context);
            sw.Stop();

            context.FunctionExecutionTime = sw.Elapsed;
            context.FunctionResultValue = context.FunctionResultValue ?? "OK";
            context.SetStageResult(Name, true);
        }
        catch (Exception ex)
        {
            context.SetStageResult(Name, false,
                $"Non-event command '{action}' execution error: {ex.Message}");
        }

        return Task.CompletedTask;
    }
}
```

#### 3.3.3 ResultCollectStage

```csharp
/// <summary>
/// 结果收集阶段 — 收集所有阶段的执行结果，生成统一报告
/// </summary>
public class ResultCollectStage : CommandStageBase
{
    public ResultCollectStage()
        : base("ResultCollect", "Collect execution results from all stages")
    { }

    protected override Task ExecuteCoreAsync(CommandContext context, CancellationToken ct)
    {
        var report = new CommandExecutionReport
        {
            Command = context.CurrentCommand,
            LineNumber = context.CurrentCommandLineNumber,
            IsNonEvent = context.ParsedCommand?.IsNonEventCommand ?? false,
            Stages = GetStageResults(context),
            TotalDuration = CalculateTotalDuration(context),
            IsSuccess = !context.HasError,
            ErrorMessage = context.GetErrorMessage()
        };

        context.ExecutionReport = report;
        context.SetStageResult(Name, true);
        return Task.CompletedTask;
    }
}
```

## 5. 注册机制设计

### 5.1 统一命令注册入口

```csharp
/// <summary>
/// 统一命令注册中心 — 所有命令（事件/非事件）统一注册
/// </summary>
public static class UnifiedCommandRegistry
{
    private static readonly ConcurrentDictionary<string, CommandRegistration> _commands = new();
    
    /// <summary>注册命令</summary>
    public static void Register(string name, CommandRegistration registration)
    {
        _commands[name] = registration;
        
        // 自动同步到 NonEventCommandRegistry（如果是非事件命令）
        if (registration.Type == CommandType.NonEvent)
        {
            FunctionStorageRegistry.NonEventRegistry.Register(name, 
                registration.Handler!, registration.Criticality, registration.Description);
        }
        
        // 自动同步到 CommandParser 的非事件命令列表
        CommandParser.DefaultNonEventCommands.Add(name);
    }
    
    /// <summary>批量注册内置命令</summary>
    public static void RegisterBuiltIn()
    {
        Register("sideload", new CommandRegistration
        {
            Type = CommandType.NonEvent,
            Handler = OnSideload,
            Description = "Load UI config into side container"
        });
        Register("sleep", new CommandRegistration
        {
            Type = CommandType.NonEvent,
            Handler = OnSleep,
            Description = "Sleep for specified milliseconds"
        });
        Register("close", new CommandRegistration
        {
            Type = CommandType.NonEvent,
            Handler = OnClose,
            Description = "Close a window by title"
        });
        Register("exit", new CommandRegistration
        {
            Type = CommandType.NonEvent,
            Handler = OnExit,
            Description = "Exit the application"
        });
    }
}
```

### 5.2 自动同步机制

```
UnifiedCommandRegistry.Register("sideload", ...)

    ├──→ FunctionStorageRegistry.NonEventRegistry.Register("sideload", handler)

    │                       └──→ CommandParser.DefaultNonEventCommands.Add("sideload")
    │
    └──→ CommandParser.DefaultNonEventCommands.Add("sideload")
```

## 6. PipelineFactory 改造

### 6.1 新 PipelineFactory

```csharp
public static class PipelineFactory
{
    public static CentralPipeline<FileDrivenPipelineContext> CreateFileDrivenPipeline(
        CliOptions options,
        IEventBindingResolver? bindingResolver = null,
        IFunctionExecutor? functionExecutor = null)
    {
        var commandPipeline = BuildUnifiedCommandPipeline(bindingResolver, functionExecutor);

        return new PipelineBuilder<FileDrivenPipelineContext>("FileDrivenPipeline")
            .RegisterService<IFunctionExecutor>(functionExecutor)
            .RegisterService<IEventBindingResolver>(bindingResolver)
            .Register(PipelineStage.PreProcessing, new ScriptLoadSkeleton())
            .AddForEach(PipelineStage.Execution, /* ... */)
            .Build();
    }

    public static IPipeline<FileDrivenPipelineContext, FileDrivenPipelineContext> 
        BuildUnifiedCommandPipeline(
            IEventBindingResolver? bindingResolver,
            IFunctionExecutor? functionExecutor)
    {
        // 构建子管线
        var nonEventStage = new NonEventExecuteStage(
            FunctionStorageRegistry.NonEventRegistry);
            
        var eventPipeline = new StagePipeline<CommandContext>("EventPipeline");
        eventPipeline
            .Register(new FindBindingStage(bindingResolver?.ToFindBindingFunc()))
            .Register(new ExtractValuesStage())
            .Register(new ExecuteFunctionStage(functionExecutor))
            .Register(new WriteResultStage());

        // 路由阶段
        var routerStage = new CommandRouterStage(
            nonEventPipeline: nonEventStage,
            eventPipeline: eventPipeline);

        // 完整管线：解析 → 路由 → 收集
        var stagePipeline = new StagePipeline<CommandContext>("UnifiedCommandPipeline");
        stagePipeline
            .Register(new ParseCommandStage(new CommandParser()))
            .Register(routerStage)
            .Register(new ResultCollectStage());

        return new DelegatePipeline<FileDrivenPipelineContext, FileDrivenPipelineContext>(/* ... */);
    }
}
```

## 9. 数据流

### 9.1 事件命令数据流（click addButton）

```
命令: "click addButton"
    │
    ▼
ParseCommandStage
    ├── ParsedCommand: { Verb="do", Action="click", Target="addButton", IsNonEvent=false }
    └── SetStageResult(ParseCommand, true)
    │
    ▼
CommandRouterStage
    ├── DetermineRoute → "event"
    └── 委托给事件命令子管线
        │
        ▼
    FindBindingStage
        ├── findBindingFunc("addButton", "click")
        ├── → (FunctionName="Plus", Inputs=["valueATextBox","valueBTextBox"], Output="resultTextBox")
        ├── BoundFunctionName="Plus", BoundInputs=["valueATextBox","valueBTextBox"]
        └── SetStageResult(FindBinding, true)
        │
        ▼
    ExtractValuesStage
        ├── 从控件读取: valueATextBox="10", valueBTextBox="25"
        ├── ExtractedValues={"valueATextBox":"10", "valueBTextBox":"25"}
        └── SetStageResult(ExtractValues, true)
        │
        ▼
    ExecuteFunctionStage
        ├── parameters = ["10", "25"]  (按 BoundInputs 顺序)
        ├── FunctionExecutor.ExecuteAsync("Plus", ["10", "25"])
        │   └── ArgumentMatcherPipeline.BuildArguments
        │       ├── DictionaryExactMatcher: source is not IDictionary → skip
        │       ├── PositionalMatcher: source is IList → match
        │       │   ├── list[0]="10" → Convert("10", double) → 10.0 → match param a
        │       │   └── list[1]="25" → Convert("25", double) → 25.0 → match param b
        │       └── Result: Args=[10.0, 25.0], IsSuccess=true
        ├── result = Add(10.0, 25.0) → 35.0
        ├── FunctionResultValue=35.0
        └── SetStageResult(ExecuteFunction, true)
        │
        ▼
    WriteResultStage
        ├── BoundOutputTarget="resultTextBox"
        ├── 写入控件: resultTextBox.Text = "35"
        └── SetStageResult(WriteResult, true)
    │
    ▼
ResultCollectStage
    ├── 收集所有阶段结果
    ├── ExecutionReport = { IsSuccess=true, Stages=[...], TotalDuration=... }
    └── SetStageResult(ResultCollect, true)
```

## 10. 错误处理

### 10.1 错误类型与处理策略

| 错误类型 | 示例 | 处理策略 |
|----------|------|----------|
| 命令解析失败 | 语法错误 | `ParseCommandStage` 返回 false，管线终止 |
| 非事件命令未注册 | `sideload` 未注册 | `NonEventExecuteStage` 返回 false，列出可用命令 |
| 事件绑定未找到 | `addButton.click` 无绑定 | `FindBindingStage` 返回 false，明确提示 |
| 值提取失败 | 控件不存在 | `ExtractValuesStage` 返回 false |
| 函数执行失败 | 参数类型不匹配 | `ExecuteFunctionStage` 返回 false，包含详细错误 |
| 结果写入失败 | 输出控件不存在 | `WriteResultStage` 返回 false |

### 10.2 错误信息规范

```
格式: [阶段名称] 错误描述 | 建议修复

示例:
[FindBinding] No binding found for 'addButton.click' | 
  Check MathFunctions.json events configuration

[NonEventExecute] Non-event command 'sideload' not registered |
  Available: load, close, echo, sleep, show, exit

[ExecuteFunction] Function 'Plus' execution failed: 
  Parameter 'a' (Double) not matched; Parameter 'b' (Double) not matched |
  Check that ExtractedValues contains 'valueATextBox' and 'valueBTextBox'
```
