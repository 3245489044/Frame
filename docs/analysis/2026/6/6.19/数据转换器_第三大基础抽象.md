# 数据转换器：与图、状态机平级的第三大基础抽象

> **摘要**：图（Graph）以节点和边描述结构，状态机（State Machine）以状态和转移描述行为。本文提出，**数据转换器（Transformer）** 以函数映射描述数据的**变换**，是与图、状态机平级的第三大基础抽象。三者共同构成软件系统的完整描述：**结构 → 行为 → 变换**。

---

## 一、引言：软件系统的三个维度

任何软件系统都可以从三个维度来描述：

| 维度 | 问题 | 数学基础 | 核心抽象 | 代表框架 |
|------|------|---------|---------|---------|
| **结构** | 数据如何组织？ | 图论 | 节点 + 边 | `ICoreGraph<TKey,TNode,TEdge>` |
| **行为** | 流程如何流转？ | 自动机理论 | 状态 + 转移 | `IStateMachine<TState>` |
| **变换** | 数据如何转换？ | 函数论 | 输入 → 输出 | **本文提出** |

图描述了系统的**静态结构**，状态机描述了系统的**动态行为**，而数据转换器描述了数据的**变换过程**。三者缺一不可。

---

## 二、图：结构的基础抽象

图（Graph）的数学定义是二元组 `G = (V, E)`：
- `V` — 节点集合（Vertices）
- `E` — 边集合（Edges），`E ⊆ V × V`

图的核心操作：
- `AddNode(key, data)` — 添加节点
- `AddEdge(from, to, data)` — 添加边
- `Traverse(start, visitor)` — 遍历图

图不关心节点和边具体是什么类型——它只关心**结构关系**。无论社交网络、知识图谱、电路设计还是路径规划，图都是统一的抽象。

```csharp
// 图的核心抽象 — 不绑定任何领域
public interface ICoreGraph<TKey, TNodeData, TEdgeData>
{
    void AddNode(TKey key, TNodeData data);
    void AddEdge(TKey from, TKey to, TEdgeData data);
    IEnumerable<(TKey, TNodeData)> Traverse(TKey start);
}
```

## 三、状态机：行为的基础抽象

状态机（State Machine）的数学定义是五元组 `M = (S, Σ, δ, s₀, F)`：
- `S` — 状态集合（States）
- `Σ` — 事件集合（Events）
- `δ: S × Σ → S` — 转移函数
- `s₀` — 初始状态
- `F` — 终止状态集合

状态机的核心操作：
- `Permit(from, @event, to)` — 定义状态转移
- `Fire(@event)` — 触发事件
- `IsInState(state)` — 检查当前状态

状态机不关心状态具体是什么枚举值——它只关心**行为流转**。无论工作流、协议解析、游戏AI还是UI导航，状态机都是统一的抽象。

```csharp
// 状态机的核心抽象 — 不绑定任何领域
public interface IStateMachine<TState> where TState : struct, Enum
{
    void Permit(TState from, TState to, object @event);
    bool Fire(object @event);
    bool IsInState(TState state);
}
```

## 四、数据转换器：变换的基础抽象

### 4.1 数学基础

数据转换器（Transformer）的数学定义是函数 `f: A → B`：
- `A` — 输入类型（Input Type）
- `B` — 输出类型（Output Type）
- `f` — 映射规则（Mapping Rule）

函数 `f` 将输入集合中的每个元素映射为输出集合中的一个元素。

函数满足的基本性质：
- **确定性**：相同的输入总是产生相同的输出
- **恒等性**：存在恒等函数 `id(x) = x`

### 4.2 核心抽象

基于上述数学基础，可以定义唯一的核心抽象：

```csharp
/// <summary>
/// 转换器 — 将输入转换为输出
/// 数学基础：函数 f: A → B
/// </summary>
/// <typeparam name="TInput">输入类型</typeparam>
/// <typeparam name="TOutput">输出类型</typeparam>
public interface ITransformer<in TInput, out TOutput>
{
    /// <summary>转换名称</summary>
    string Name { get; }
    
    /// <summary>执行转换</summary>
    TOutput Transform(TInput input);
}
```

### 4.3 具体转换器类型

基于 `ITransformer<TInput, TOutput>`，可以派生出各种具体的转换器：

#### 映射器（Mapper）

```csharp
/// <summary>
/// 映射器 — 将输入集合中的每个元素映射为另一个值
/// 数学基础：f: T → U，对集合中每个元素应用
/// </summary>
public class Mapper<TInput, TOutput> : ITransformer<IEnumerable<TInput>, IEnumerable<TOutput>>
{
    private readonly Func<TInput, TOutput> _mapFunc;
    
    public string Name { get; }
    
    public Mapper(string name, Func<TInput, TOutput> mapFunc)
    {
        Name = name;
        _mapFunc = mapFunc;
    }
    
    public IEnumerable<TOutput> Transform(IEnumerable<TInput> input)
        => input.Select(_mapFunc);
}
```

#### 过滤器（Filter）

```csharp
/// <summary>
/// 过滤器 — 根据条件保留或移除元素
/// 数学基础：谓词函数 p: T → bool，保留满足条件的元素
/// </summary>
public class Filter<T> : ITransformer<IEnumerable<T>, IEnumerable<T>>
{
    private readonly Func<T, bool> _predicate;
    
    public string Name { get; }
    
    public Filter(string name, Func<T, bool> predicate)
    {
        Name = name;
        _predicate = predicate;
    }
    
    public IEnumerable<T> Transform(IEnumerable<T> input)
        => input.Where(_predicate);
}
```

#### 聚合器（Aggregator）

```csharp
/// <summary>
/// 聚合器 — 将集合聚合为单个值
/// 数学基础：f: T[] → R，将集合归约为一个结果
/// </summary>
public class Aggregator<TInput, TOutput> : ITransformer<IEnumerable<TInput>, TOutput>
{
    private readonly Func<IEnumerable<TInput>, TOutput> _aggregateFunc;
    
    public string Name { get; }
    
    public Aggregator(string name, Func<IEnumerable<TInput>, TOutput> aggregateFunc)
    {
        Name = name;
        _aggregateFunc = aggregateFunc;
    }
    
    public TOutput Transform(IEnumerable<TInput> input)
        => _aggregateFunc(input);
}
```

#### 验证器（Validator）

```csharp
/// <summary>
/// 验证器 — 检查数据是否满足约束
/// 数学基础：谓词函数 p: T → bool，返回验证结果
/// </summary>
public class Validator<T> : ITransformer<T, ValidationResult>
{
    private readonly Func<T, bool> _rule;
    
    public string Name { get; }
    public string ErrorMessage { get; }
    
    public Validator(string name, Func<T, bool> rule, string errorMessage = null)
    {
        Name = name;
        _rule = rule;
        ErrorMessage = errorMessage;
    }
    
    public ValidationResult Transform(T input)
        => _rule(input) 
            ? ValidationResult.Success 
            : ValidationResult.Fail(ErrorMessage ?? $"Validation failed: {Name}");
}

public class ValidationResult
{
    public bool IsValid { get; }
    public string Error { get; }
    
    public static ValidationResult Success => new(true, null);
    public static ValidationResult Fail(string error) => new(false, error);
    
    private ValidationResult(bool isValid, string error) 
        => (IsValid, Error) = (isValid, error);
}
```

#### 去重器（Deduplicator）

```csharp
/// <summary>
/// 去重器 — 基于等价关系去除重复元素
/// 数学基础：等价关系 ~ 将集合划分为等价类，从每个类中选代表元
/// </summary>
public class Deduplicator<T> : ITransformer<IEnumerable<T>, IEnumerable<T>>
{
    private readonly Func<T, object> _equivalenceKeyFunc;
    private readonly Func<T, T, T> _conflictResolver;
    
    public string Name { get; }
    
    public Deduplicator(string name, 
        Func<T, object> equivalenceKeyFunc,
        Func<T, T, T> conflictResolver = null)
    {
        Name = name;
        _equivalenceKeyFunc = equivalenceKeyFunc;
        _conflictResolver = conflictResolver ?? ((existing, _) => existing);
    }
    
    public IEnumerable<T> Transform(IEnumerable<T> input)
    {
        var map = new Dictionary<object, T>();
        foreach (var item in input)
        {
            var key = _equivalenceKeyFunc(item);
            if (map.TryGetValue(key, out var existing))
                map[key] = _conflictResolver(existing, item);
            else
                map[key] = item;
        }
        return map.Values;
    }
}
```

### 4.4 转换器不关心数据项的具体类型

转换器只关心**输入到输出的映射规则**：

```
映射：    f: T → U，将每个元素映射为另一个类型
过滤：    f: T → bool，保留满足条件的元素
聚合：    f: T[] → R，将集合归约为一个值
验证：    f: T → ValidationResult，检查约束
去重：    f: T → object，基于等价键去重
排序：    f: T → IComparable，按键排序
格式化：  f: T → string，格式化为字符串
解析：    f: string → T，从字符串解析
```

## 五、三者对比

| 维度 | **图 (Graph)** | **状态机 (State Machine)** | **数据转换器 (Transformer)** |
|------|---------------|--------------------------|---------------------------|
| **数学基础** | 图论 | 自动机理论 | **函数论** |
| **数学定义** | `G = (V, E)` | `M = (S, Σ, δ, s₀, F)` | **`f: A → B`** |
| **核心概念** | 节点 + 边 | 状态 + 转移 | **输入 → 输出** |
| **核心接口** | `ICoreGraph<TKey,TNode,TEdge>` | `IStateMachine<TState>` | **`ITransformer<TInput,TOutput>`** |
| **核心操作** | AddNode / AddEdge / Traverse | Permit / Fire / IsInState | **Transform** |
| **描述维度** | 结构 | 行为 | **变换** |
| **领域无关性** | ✅ 不关心节点/边类型 | ✅ 不关心状态枚举值 | ✅ **不关心输入/输出类型** |
| **通用场景** | 社交网络、知识图谱、路径规划 | 工作流、协议解析、游戏AI | **ETL、数据验证、格式化、解析** |

## 六、结论

图、状态机、数据转换器三者共同构成了软件系统的完整描述：

```
图（结构） + 状态机（行为） + 数据转换器（变换） = 完整的系统描述
```

- **图** 告诉我们数据如何组织
- **状态机** 告诉我们流程如何流转
- **数据转换器** 告诉我们数据如何变换

三者都是**领域无关的基础抽象**，都可以用**单一的泛型接口**来表达，都可以作为**独立的基础库**被任何项目复用。

正如图论和自动机理论已经深刻影响了软件工程，**函数映射 `f: A → B`** 这一数学基础同样值得被提升到基础抽象的高度。数据转换器不是图的一个子功能，也不是状态机的一个步骤——它是与图、状态机平级的**第三大基础抽象**。
