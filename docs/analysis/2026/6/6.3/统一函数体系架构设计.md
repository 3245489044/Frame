# 统一函数体系架构设计

## 1. 现状分析：两套函数体系

当前代码库中存在**两套完全独立的函数注册/执行体系**，互不互通，导致 UI 事件触发（click）无法正确执行已注册的数学函数。

### 体系 A：`FunctionStorage` → `UniversalWorkflowFramework.FunctionExecution`

| 环节 | 位置 | 说明 |
|------|------|------|
| 注册 | `Share/FunctionStorage/MathLibrary.cs` | `FunctionExecutionFramework.Register("Plus", (Func<double,double,double>)Add)` |
| 注册目标 | `UniversalWorkflowFramework.FunctionExecution.FunctionExecutionFramework` | 位于 `Share/UniversalReference/` 项目 |
| 执行 | `Share/FunctionStorage/WorkflowExecutionLayer.cs` | `FunctionExecutionFramework.ExecuteAsync("Plus", List<object?>)` |
| 参数 | `(double, double) → double` | 强类型参数 |
| 调用方 | 工作流引擎（WorkflowExecutionLayer） | JSON 工作流定义驱动 |

### 体系 B：`EventTriggerFramework` → `FunctionRegistry` + `FunctionExecutor`

| 环节 | 位置 | 说明 |
|------|------|------|
| 注册 | `Share/EventTriggerFramework/Core/FunctionRegistry.cs` | `registry.Register("name", Delegate function)` |
| 注册目标 | `EventTriggerFramework.Core.FunctionRegistry` | 本地 `ConcurrentDictionary` |
| 执行 | `Share/EventTriggerFramework/Core/FunctionExecutor.cs` | `executor.ExecuteAsync("name", parameters)` |
| 参数 | `Dictionary<string, string?>` → 按参数名匹配 | 通过 `BuildArguments()` 按名匹配 |
| 调用方 | UI 事件触发管线（click → FindBinding → ExtractValues → ExecuteFunction → WriteResult） | FileDriven 管线驱动 |

### 断裂点

```
click addButton
  → FindBindingSkeleton → 找到 functionName="Plus"
  → ExtractValuesSkeleton → 提取 {"valueATextBox":"10", "valueBTextBox":"25"}
  → ExecuteFunctionSkeleton → input.FunctionExecutor.ExecuteAsync("Plus", List<object?>)
                              ↓
                    FunctionExecutor 在 FunctionRegistry 中查找 "Plus"
                              ↓
                    未找到！返回 Failure("Function 'Plus' not found")
                              ↓
                    FunctionExecuteSuccess = false，但管线继续执行
                              ↓
                    WriteResultSkeleton 跳过写入（因无结果）
```

**根本原因**：`Plus` 注册在体系 A，但 `click` 管线调用体系 B，两者不互通。

## 2. 统一函数体系架构设计

### 2.1 核心设计原则

1. **单一注册中心**：所有函数统一注册到一个中心，不再分散
2. **统一调用接口**：所有调用方（UI 事件、工作流引擎、CLI 命令）使用同一接口
3. **参数自动适配**：支持 `Dictionary<string, string?>`（UI 事件）和 `List<object?>`（工作流引擎）两种参数格式
4. **向后兼容**：现有注册代码无需修改，仅需调整注册目标

### 2.3 统一注册中心接口

```csharp
/// <summary>
/// 统一函数注册中心
/// 所有函数统一注册到此中心，供 UI 事件、工作流引擎、CLI 命令调用
/// </summary>
public interface IUnifiedFunctionRegistry
{
    /// <summary>注册函数（委托）</summary>
    void Register(string name, Delegate function, string? description = null);

    /// <summary>注册函数（强类型）</summary>
    void Register<T>(string name, Func<T> function, string? description = null);
    void Register<T1, T2, TResult>(string name, Func<T1, T2, TResult> function, string? description = null);

    /// <summary>注销函数</summary>
    void Unregister(string name);

    /// <summary>执行函数（自动适配参数格式）</summary>
    Task<IFunctionExecutionResult> ExecuteAsync(string name, object? parameters = null);

    /// <summary>执行函数（指定参数格式）</summary>
    Task<IFunctionExecutionResult> ExecuteAsync(string name, Dictionary<string, string?> namedParams);
    Task<IFunctionExecutionResult> ExecuteAsync(string name, List<object?> positionalParams);

    /// <summary>获取函数描述符</summary>
    bool TryGetDescriptor(string name, out IFunctionDescriptor descriptor);

    /// <summary>获取所有已注册函数名</summary>
    IEnumerable<string> GetRegisteredNames();

    /// <summary>是否包含指定函数</summary>
    bool Contains(string name);
}
```

### 2.4 参数自动适配逻辑

```csharp
private object?[] BuildArguments(IFunctionDescriptor descriptor, object? parameters)
{
    if (descriptor.Parameters.Count == 0)
        return Array.Empty<object?>();

    var args = new object?[descriptor.Parameters.Count];

    switch (parameters)
    {
        // 按名匹配：Dictionary<string, string?>
        case IDictionary<string, string?> namedParams:
            for (int i = 0; i < descriptor.Parameters.Count; i++)
            {
                var param = descriptor.Parameters[i];
                if (namedParams.TryGetValue(param.Name, out var val) && val != null)
                    args[i] = ConvertValue(val, param.Type);
                else if (param.IsOptional)
                    args[i] = param.DefaultValue;
            }
            break;

        // 按位匹配：List<object?>
        case IList<object?> positionalParams:
            for (int i = 0; i < Math.Min(positionalParams.Count, descriptor.Parameters.Count); i++)
            {
                var param = descriptor.Parameters[i];
                args[i] = ConvertValue(positionalParams[i], param.Type);
            }
            break;

        // 单参数直接传入
        default:
            if (descriptor.Parameters.Count == 1)
                args[0] = ConvertValue(parameters, descriptor.Parameters[0].Type);
            break;
    }

    return args;
}
```

## 3. 迁移方案

### 3.1 第一阶段：创建统一注册中心（无侵入）

在 `Share/FunctionStorage/` 中创建 `UnifiedFunctionRegistry.cs`：

```csharp
namespace FunctionStorage
{
    /// <summary>
    /// 统一函数注册中心实现
    /// </summary>
    public class UnifiedFunctionRegistry : IUnifiedFunctionRegistry
    {
        private readonly ConcurrentDictionary<string, RegisteredFunction> _functions = new(StringComparer.OrdinalIgnoreCase);

        // ... 实现接口方法
    }

    /// <summary>
    /// 全局单例访问点
    /// </summary>
    public static class FunctionRegistry
    {
        private static readonly Lazy<IUnifiedFunctionRegistry> _instance =
            new(() => new UnifiedFunctionRegistry());

        public static IUnifiedFunctionRegistry Instance => _instance.Value;
    }
}
```

### 3.2 第二阶段：修改注册代码

修改 `MathLibrary.RegisterAll()`，将注册目标改为统一注册中心：

```csharp
public static void RegisterAll()
{
    if (_registered) return;
    _registered = true;

    var registry = FunctionRegistry.Instance;
    registry.Register("Add", (Func<double, double, double>)Add, "Addition: a + b");
    registry.Register("Plus", (Func<double, double, double>)Add, "Addition alias: a + b");
    registry.Register("Subtract", (Func<double, double, double>)Subtract, "Subtraction: a - b");
    registry.Register("Minus", (Func<double, double, double>)Subtract, "Subtraction alias: a - b");
    registry.Register("Multiply", (Func<double, double, double>)Multiply, "Multiplication: a * b");
    registry.Register("Divide", (Func<double, double, double>)Divide, "Division: a / b");
}
```

### 3.3 第三阶段：修改调用方

#### 3.3.1 UI 事件管线（ExecuteFunctionSkeleton）

修改 `ExecuteFunctionSkeleton`，使用统一注册中心：

```csharp
protected override FileDrivenPipelineContext ExecuteCore(FileDrivenPipelineContext input, SkeletonContext ctx)
{
    // ...
    var registry = FunctionRegistry.Instance;
    var result = registry.ExecuteAsync(input.BoundFunctionName, parameters).GetAwaiter().GetResult();
    // ...
}
```

或者，让 `FunctionExecutor` 回退到统一注册中心：

```csharp
public class FunctionExecutor : IFunctionExecutor
{
    public async Task<IFunctionExecutionResult> ExecuteAsync(string functionName, object? parameters = null)
    {
        // 1. 优先在本地 FunctionRegistry 查找
        var func = _registry.GetFunction(functionName);
        if (func != null)
            return await ExecuteDelegateAsync(func.Delegate, func.Descriptor, parameters);

        // 2. 回退到统一注册中心
        if (FunctionRegistry.Instance.Contains(functionName))
            return await FunctionRegistry.Instance.ExecuteAsync(functionName, parameters);

        return FunctionExecutionResult.Failure($"Function '{functionName}' not found", TimeSpan.Zero);
    }
}
```

#### 3.3.2 工作流引擎（WorkflowExecutionLayer）

修改 `WorkflowExecutionLayer.ExecuteWorkflow`，使用统一注册中心：

```csharp
// 原代码：
var execResult = await FunctionExecutionFramework.ExecuteAsync(step.FuncName, stepArgs).ConfigureAwait(false);

// 改为：
var execResult = await FunctionRegistry.Instance.ExecuteAsync(step.FuncName, stepArgs).ConfigureAwait(false);
```

### 3.4 第四阶段：清理旧体系（可选）

待统一注册中心稳定运行后，逐步废弃旧体系：

1. 移除 `UniversalWorkflowFramework.FunctionExecution.FunctionExecutionFramework` 中的注册/执行逻辑
2. 移除 `EventTriggerFramework.Core.FunctionRegistry` 中的重复实现
3. 统一使用 `FunctionStorage.FunctionRegistry.Instance`

## 5. 配置中的函数绑定规范

### 5.1 事件绑定配置格式

```json
{
  "template": "action-button",
  "name": "addButton",
  "text": "Add (+)",
  "functionName": "Plus",
  "inputs": ["valueATextBox", "valueBTextBox"],
  "output": "resultTextBox"
}
```

| 字段 | 说明 | 必须 |
|------|------|------|
| `functionName` | 统一注册中心中的函数名 | 是 |
| `inputs` | 输入控件名列表（按位置对应函数参数） | 是 |
| `output` | 输出控件名 | 否 |

### 5.2 参数映射规则

```
inputs: ["valueATextBox", "valueBTextBox"]
          ↓ 提取控件值
          {"valueATextBox": "10", "valueBTextBox": "25"}
          ↓ 统一注册中心自动适配
          Plus(double a=10, double b=25) → 35
          ↓ 写入输出控件
          resultTextBox.Text = "35"
```

public void Plus_Should_Return_Correct_Sum()
{
    var registry = FunctionRegistry.Instance;

    // 按名参数
    var result1 = registry.ExecuteAsync("Plus", new Dictionary<string, string?>

    // 按位参数
