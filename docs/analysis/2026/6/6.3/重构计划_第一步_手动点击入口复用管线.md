# 第一步重构方案：手动点击入口复用管线骨架

## 背景

当前架构存在两条路径：

**路径1（脚本入口）**：
```
PipelineEntry.CreateFileDrivenPipeline()
  → ScriptLoadSkeleton
    → ForEachPipeline
      → ParseCommandSkeleton
        → FindBindingSkeleton
          → ExtractValuesSkeleton
            → ExecuteFunctionSkeleton
              → WriteResultSkeleton
```

**路径2（手动点击入口 — 旧路径）**：
```
WinFormsEventBinder handler 触发
  → FireAndForgetTriggerAsync()
    → IEventTriggerService.TriggerEventAsync()
      → EventTriggerService 内部逻辑（非管线）
```

**问题**：手动点击入口走的是 `IEventTriggerService` 旧路径，没有复用 FileDriven 管线骨架。两条路径的绑定查找、值提取、函数执行、结果写入逻辑是重复的。

## 目标

将手动点击入口从 `IEventTriggerService` 旧路径迁移到复用 `PipelineEntry.BuildCommandPipeline()` 管线骨架，使两条路径共享同一套 `FindBindingSkeleton → ExtractValuesSkeleton → ExecuteFunctionSkeleton → WriteResultSkeleton`。

## 步骤

### 步骤1：在 `Share.CentralPipeline` 中定义 `IEventPipelineExecutor` 接口

**文件**：`Share/CentralPipeline/IEventPipelineExecutor.cs`

```csharp
namespace Share.CentralPipeline;

/// <summary>
/// 事件管线执行器接口
/// 供 WinFormsEventBinder 调用，将手动点击路由到 FileDriven 管线骨架
/// </summary>
public interface IEventPipelineExecutor
{
    /// <summary>
    /// 执行事件管线（FindBinding → ExtractValues → ExecuteFunction → WriteResult）
    /// </summary>
    /// <param name="controlName">控件名</param>
    /// <param name="eventType">事件类型（如 "click"）</param>
    /// <param name="value">事件值</param>
    /// <returns>是否执行成功</returns>
    bool Execute(string controlName, string eventType, string value);
}
```

### 步骤2：将 `PipelineEntry.BuildCommandPipeline()` 改为 `internal static`

**文件**：`FileDriven/FileDriven.Pipeline/PipelineEntry.cs`

将第135行的 `private static` 改为 `internal static`，使其可被 `EventPipelineExecutor` 复用。

### 步骤3：创建 `EventPipelineExecutor` 实现

**文件**：`FileDriven/FileDriven.Pipeline/EventPipelineExecutor.cs`

```csharp
using System.Windows.Forms;
using EventTriggerFramework.Abstractions;
using Share.CentralPipeline;

namespace FileDriven.Pipeline;

/// <summary>
/// 事件管线执行器
/// 复用 PipelineEntry.BuildCommandPipeline() 构建的子管线，
/// 将手动点击路由到 FileDriven 管线骨架
/// </summary>
public class EventPipelineExecutor : IEventPipelineExecutor
{
    private readonly CentralPipeline<FileDrivenPipelineContext> _pipeline;
    private readonly IEventBindingResolver _bindingResolver;
    private readonly IFunctionExecutor _functionExecutor;
    private readonly Form _targetForm;

    public EventPipelineExecutor(
        IEventBindingResolver bindingResolver,
        IFunctionExecutor functionExecutor,
        Form targetForm)
    {
        _bindingResolver = bindingResolver;
        _functionExecutor = functionExecutor;
        _targetForm = targetForm;
        // 复用 PipelineEntry.BuildCommandPipeline() 构建的子管线
        _pipeline = PipelineEntry.BuildCommandPipeline(bindingResolver, functionExecutor);
    }

    public bool Execute(string controlName, string eventType, string value)
    {
        var context = new FileDrivenPipelineContext
        {
            ParsedTarget = controlName,
            ParsedAction = eventType,
            TargetForm = _targetForm,
            BindingResolver = _bindingResolver,
            FunctionExecutor = _functionExecutor,
            IsNonEventCommand = false,
            ParseSuccess = true  // 手动点击不需要解析
        };

        try
        {
            _pipeline.Execute(context);
            if (context.TryGetError(true, out var errorMsg))
            {
                Console.WriteLine($"[手动点击] 执行失败: {controlName}.{eventType}, 错误: {errorMsg}");
                return false;
            }
            return true;
        }
        catch (Exception ex)
        {
            Console.WriteLine($"[手动点击] 执行异常: {controlName}.{eventType}, 异常: {ex.Message}");
            return false;
        }
    }
}
```

### 步骤4：修改 `WinFormsEventBinder` 支持双路径

**文件**：`Share/FunctionStorage/WinFormsEventBinder.cs`

改动点：
1. 构造函数增加 `IEventPipelineExecutor?` 可选参数
2. `FireAndForgetTriggerAsync` 优先走 `IEventPipelineExecutor`，降级走 `IEventTriggerService`

```csharp
// 新增字段
private readonly IEventPipelineExecutor? _eventPipelineExecutor;

// 构造函数增加可选参数
public WinFormsEventBinder(
    IEventTriggerService? eventTriggerService = null,
    IEventPipelineExecutor? eventPipelineExecutor = null)
{
    _eventTriggerService = eventTriggerService;
    _eventPipelineExecutor = eventPipelineExecutor;
}

// FireAndForgetTriggerAsync 修改为优先走管线
private async Task FireAndForgetTriggerAsync(string controlName, string eventType, string value)
{
    try
    {
        // ★ 优先走 IEventPipelineExecutor（新管线路径）
        if (_eventPipelineExecutor != null)
        {
            var success = _eventPipelineExecutor.Execute(controlName, eventType, value);
            if (!success)
            {
                System.Diagnostics.Debug.WriteLine(
                    $"[WinFormsEventBinder] 管线执行失败: {controlName}.{eventType}");
            }
            return;
        }

        // ★ 降级走 IEventTriggerService（旧路径）
        if (_eventTriggerService == null)
        {
            System.Diagnostics.Debug.WriteLine(
                $"[WinFormsEventBinder] 跳过触发: {controlName}.{eventType}, 无执行器注入");
            return;
        }

        var result = await _eventTriggerService.TriggerEventAsync(
            controlName, eventType, value);

        if (!result.IsSuccess)
        {
            System.Diagnostics.Debug.WriteLine(
                $"[WinFormsEventBinder] 触发失败: {controlName}.{eventType}, 错误: {result.ErrorMessage}");
        }
    }
    catch (Exception ex)
    {
        System.Diagnostics.Debug.WriteLine(
            $"[WinFormsEventBinder] 触发异常: {controlName}.{eventType}, 异常: {ex.Message}");
    }
}
```

### 步骤5：修改 `GuiModeRunner` 注入 `EventPipelineExecutor`

**文件**：`FileDriven/FileDriven.Launcher/GuiModeRunner.cs`

在创建 `WinFormsEventBinder` 时，同时传入 `EventPipelineExecutor`：

```csharp
// 创建 EventPipelineExecutor
var eventPipelineExecutor = new EventPipelineExecutor(
    bindingResolver, functionExecutor, mainForm);

// 注入到 WinFormsEventBinder（同时保留 IEventTriggerService 作为降级）
var winFormsEventBinder = new FunctionStorage.WinFormsEventBinder(
    eventTriggerService: eventTriggerService,
    eventPipelineExecutor: eventPipelineExecutor);
```

## 影响范围

| 文件 | 改动类型 | 风险 |
|------|---------|------|
| `Share/CentralPipeline/IEventPipelineExecutor.cs` | **新建** | 低 |
| `FileDriven/FileDriven.Pipeline/PipelineEntry.cs` | 修改（private → internal） | 低 |
| `FileDriven/FileDriven.Pipeline/EventPipelineExecutor.cs` | **新建** | 低 |
| `Share/FunctionStorage/WinFormsEventBinder.cs` | 修改（构造函数 + FireAndForgetTriggerAsync） | 中 |
| `FileDriven/FileDriven.Launcher/GuiModeRunner.cs` | 修改（注入 EventPipelineExecutor） | 低 |

## 迁移路径

| 阶段 | 说明 |
|------|------|
| **当前** | `WinFormsEventBinder` 同时支持 `IEventTriggerService`（旧路径）和 `IEventPipelineExecutor`（新路径） |
| **过渡期** | 新代码优先使用 `IEventPipelineExecutor`，旧路径保留向后兼容 |
| **最终** | `EventTriggerService` 废弃，所有事件处理通过同一管线完成 |
