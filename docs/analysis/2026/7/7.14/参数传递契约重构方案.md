# 参数传递契约重构方案

> 目标：在 `TConfig.TrConfig` 层定义统一的参数传递契约，消除各层对 `output` 语义的猜测和多余包装。

---

## 一、问题根因

`output` 字段在整个调用链中被赋予了**三种不同语义**，且没有任何区分标识：

| 阶段 | output 语义 | 代码位置 |
|------|------------|---------|
| JSON 配置 | 控件名（如 `"resultTextBox"`） | `bindings.output` |
| `EventBindingHelper.ResolveOutput` | 控件名（从 `OutputMapping` 取值） | `ResolveOutput` 返回 `mappedOutput` |
| `CreateEventHandler` 推断 | 字典键名（如 `"value"`） | `resolvedOutput = "value"` |
| `HandleExecutionResult` | 字典键名（用于 `dict.Contains(output)`） | `dict.Contains(output)` |
| `_outputControlFinder` | 控件名（用于查找控件） | `_outputControlFinder(sender, output)` |

**同一个变量 `output`，在 `HandleExecutionResult` 中先作为字典键名提取值，然后又作为控件名去查找控件。** 当推断为 `"value"` 后，`_outputControlFinder` 用 `"value"` 去找控件，必然找不到。

#### 3.1.2 修改 EventBindingHelper

**文件：`CsharpPrj/Share/EventBindingOrchestrator/Invoke/EventBindingHelper.cs`**

```csharp
/// <summary>
/// 解析 output 映射，返回 (outputTarget, outputKey) 元组
/// </summary>
public static (string? outputTarget, string? outputKey) ResolveOutput(
    EventBindingModel? bindings, string functionName)
{
    if (string.IsNullOrEmpty(functionName))
        return (null, null);

    // 1. 优先从 OutputMapping 查找（函数名 → 控件名）
    if (bindings?.OutputMapping is { Count: > 0 } &&
        bindings.OutputMapping.TryGetValue(functionName, out var mappedOutput))
    {
        return (mappedOutput, bindings.OutputKey);
    }

    // 2. 使用顶层 Output（控件名）
    return (bindings?.Output, bindings?.OutputKey);
}
```

#### 3.1.3 修改 EventBindingStageBase

**文件：`CsharpPrj/Operation/WorkFlowMethod/EventBinding/EventBindingStageBase.cs`**

```csharp
// CreateEventHandler 签名增加 outputKey 参数
public EventHandler CreateEventHandler(
    object control, string eventName, string functionName,
    IReadOnlyList<ParameterBinding>? parameterBindings,
    string? outputTarget,    // 控件名
    string? outputKey,       // ★ 新增：字典键名
    Action<string, string, object?>? onResult = null,
    object? bindingContext = null)
{
    // ... 事件处理器逻辑 ...
    
    // 推断 outputKey（当未显式指定时）
    if (string.IsNullOrEmpty(outputKey) && _registry != null)
    {
        if (_registry.TryGetConfig(functionName, out var funcConfig))
        {
            outputKey = funcConfig.Parameters.Count switch
            {
                1 => funcConfig.Parameters[0].Name,
                _ => null   // ★ 多参数函数不需要 outputKey
            };
        }
    }
    
    // 调用 HandleExecutionResult 时传入 outputTarget 和 outputKey
    await HandleExecutionResult(result, functionName, outputTarget, outputKey, sender, onResult, eventName);
}
```

```csharp
// HandleExecutionResult 增加 outputKey 参数
protected async Task HandleExecutionResult(
    ExecutionResult result,
    string functionName,
    string? outputTarget,     // 控件名
    string? outputKey,        // ★ 新增：字典键名
    object sender,
    Action<string, string, object?>? onResult,
    string eventName)
{
    object? resolvedValue = result.Value;

    // 只在有 outputKey 且返回值是 Dictionary 时才拆包
    if (!string.IsNullOrEmpty(outputKey) && 
        resolvedValue is System.Collections.IDictionary dict && 
        dict.Contains(outputKey))
    {
        resolvedValue = dict[outputKey];
    }

    // 用 outputTarget（控件名）查找控件并写回
    var target = _outputControlFinder?.Invoke(sender, outputTarget ?? functionName);
    if (target != null && _outputWriter != null)
    {
        _outputWriter(target, resolvedValue);
    }

    // 日志记录
    EventBindingDiagnosticContext.Record(EventNames.EventBinderFunctionSuccess, new
    {
        name = functionName,
        result = resolvedValue?.ToString(),
        resultType = resolvedValue?.GetType().Name,
        executionTimeMs = result.ExecutionTime.TotalMilliseconds
    });

    onResult?.Invoke(functionName, "success", new
    {
        result = resolvedValue,
        resultType = resolvedValue?.GetType().Name,
        eventName,
        executionTime = result.ExecutionTime.TotalMilliseconds,
        status = "Completed"
    });
}
```

### 第三阶段：消除多余包装

#### 3.3.1 WorkflowMethodExecutionService 消除多余 Dictionary 包装

**文件：`CsharpPrj/Operation/WorkFlowMethod/WorkflowMethodExecutionService.cs`**

```csharp
private async Task<ExecutionResult> ExecuteWorkflowAsync(
    WorkflowDefinitionEntry workflowDef,
    Dictionary<string, object> namedParameters)
{
    // ... 遍历节点执行 ...
    
    object? lastResult = null;
    foreach (var node in workflowDef.Nodes)
    {
        // ... 执行节点 ...
        lastResult = result.Value;
    }

    // ★ 单节点工作流：直接返回原始值，不包装为 Dictionary
    if (workflowDef.Nodes.Count == 1)
    {
        return ExecutionResult.Success(lastResult ?? new object());
    }

    // ★ 多节点工作流：需要 outputKey 映射
    var lastNode = workflowDef.Nodes?.LastOrDefault();
    var outputKey = lastNode?.OutputKey;
    if (string.IsNullOrWhiteSpace(outputKey) && lastNode?.FunctionName != null)
    {
        if (_registry.TryGetConfig(lastNode.FunctionName, out var lastConfig))
        {
            outputKey = lastConfig.Parameters.Count switch
            {
                1 => lastConfig.Parameters[0].Name,
                _ => "value"
            };
        }
    }

    var resultDict = new Dictionary<string, object>
    {
        [outputKey ?? "value"] = lastResult ?? new object()
    };
    return ExecutionResult.Success(resultDict);
}
```

## 五、数据流对比

### 重构前

```
JSON: output="resultTextBox"
  → EventBindingHelper.ResolveOutput → null（无 outputMapping）
    → CreateEventHandler 推断 → "value"
      → HandleExecutionResult: dict.Contains("value") → 提取 3.0
        → _outputControlFinder("value") → 找不到控件 ❌
```

### 重构后

```
JSON: output="resultTextBox", outputKey="value"
  → EventBindingHelper.ResolveOutput → ("resultTextBox", "value")
    → CreateEventHandler: outputTarget="resultTextBox", outputKey="value"
      → HandleExecutionResult: dict.Contains("value") → 提取 3.0
        → _outputControlFinder("resultTextBox") → 找到控件 ✅
        → _outputWriter(控件, 3.0) → 写入成功 ✅
```

### 单节点工作流（无 outputKey）

```
JSON: output="resultTextBox"（无 outputKey）
  → EventBindingHelper.ResolveOutput → ("resultTextBox", null)
    → CreateEventHandler: outputTarget="resultTextBox", outputKey=null
      → ExecuteWorkflowAsync: 单节点直接返回 3.0（不包装 Dictionary）
        → HandleExecutionResult: 不是 Dictionary，不拆包
          → _outputControlFinder("resultTextBox") → 找到控件 ✅
          → _outputWriter(控件, 3.0) → 写入成功 ✅
```
