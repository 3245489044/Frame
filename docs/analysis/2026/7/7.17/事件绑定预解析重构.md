# 事件绑定预解析重构文档

> **目标：** 将运行时的工作流解析提前到绑定阶段完成，缩短事件触发时的调用链。
>
> **核心思路：** 绑定阶段预查找工作流定义、预查找 delegate、预计算参数来源，生成预解析 handler；点击时只做"读取控件值 → delegate.Invoke"。

---

## 1. 现状分析

### 1.1 当前调用链（按钮点击 → 函数执行）

```
绑定阶段（一次）：
  ConfigBindingStage
    → _ioc.CreateEventHandler(control, eventName, functionName, parameterBindings, ...)
      → 返回一个闭包，闭包中记录了 functionName 和 parameterBindings

点击时（每次）：
  EventBus.Publish(eventName, sender, args)
    → handler 闭包
      → ParameterBuilder.Build(sender, parameterBindings)        // 遍历 bindings 查找控件
        → WorkflowMethodExecutionService.ExecuteFunctionAsync(functionName, parameters)
          → _workflows.TryGetValue(functionName)                  // 查找工作流定义
          → ExecuteWorkflowAsync(workflowDef, parameters)
            → foreach node in workflowDef.Nodes                   // 遍历节点
              → _registry.Find(node.FunctionName)                 // 查找 delegate
              → NodeExecutor.ExecuteNodeAsync(stepDef, context)
                → delegate.DynamicInvoke(parameters)
```

**运行时调用链长度：6 层（EventBus → handler → ParameterBuilder → ExecutionService → NodeExecutor → delegate）**

### 1.2 问题

每次点击都重复执行以下"查找"操作：
1. `ParameterBuilder.Build` — 遍历 `parameterBindings`，通过控件名查找控件、读取属性值
2. `_workflows.TryGetValue` — 从字典查找工作流定义
3. `foreach workflowDef.Nodes` — 遍历节点列表（单函数只有一个节点）
4. `_registry.Find` — 从注册表查找 delegate

这些操作的结果在绑定阶段就已经确定，不需要每次点击都重新计算。

## 2. 目标设计

### 2.1 目标调用链

```
绑定阶段（一次）：
  ConfigBindingStage
    → _ioc.ResolveWorkflow(functionName)              // 预查找工作流定义
    → _ioc.ResolveDelegate(functionName)               // 预查找 delegate
    → _ioc.PrecomputeParameterSources(bindings)        // 预计算参数来源
    → _ioc.CreatePreResolvedHandler(...)               // 生成预解析 handler
    → EventBus.Subscribe(handler)

点击时（每次）：
  EventBus.Publish
    → preResolvedHandler
      → ParameterBuilder.BuildFromSources(sources, form, sender)  // 只读取控件值
      → delegate.DynamicInvoke(values)                            // 直接调用
      → 回写结果
```

**运行时调用链长度：3 层（EventBus → handler → delegate）**

### 2.2 核心变化

| 操作 | 当前（运行时） | 改为（绑定阶段） |
|------|--------------|----------------|
| 查找工作流定义 | 每次点击 `_workflows.TryGetValue` | 绑定阶段 `ResolveWorkflow` |
| 查找 delegate | 每次点击 `_registry.Find` | 绑定阶段 `ResolveDelegate` |
| 解析参数绑定 | 每次点击遍历 `parameterBindings` | 绑定阶段 `PrecomputeParameterSources` |
| 执行工作流 | 每次点击遍历 `Nodes` | 绑定阶段判断单节点，直接引用 delegate |

### 3.3 `EventBindingIoC` 实现

**位置：** `CsharpPrj/Operation/BackEndDriven/EventBinding/EventBindingIoC.cs`

```csharp
// ============================================================
// 预解析方法实现
// ============================================================

public WorkflowDefinitionEntry? ResolveWorkflow(string functionName)
{
    // 从 WorkflowMethodExecutionService 查找工作流定义
    return _executionService?.FindWorkflow(functionName);
}

public Delegate? ResolveDelegate(string functionName)
{
    // 从 IFunctionRegistry 查找 delegate
    return _registry?.Find(functionName);
}

public ParameterSource[] PrecomputeParameterSources(
    IReadOnlyList<ParameterBinding>? bindings)
{
    // 委托给 ParameterBuilder
    return _parameterBuilder?.PrecomputeSources(bindings)
           ?? Array.Empty<ParameterSource>();
}

public Delegate CreatePreResolvedHandler(
    Control control,
    string eventName,
    string functionName,
    IReadOnlyList<ParameterBinding>? parameterBindings,
    WorkflowDefinitionEntry? resolvedWorkflow,
    Delegate? resolvedDelegate,
    ParameterSource[] precomputedSources,
    Action<string, string, object?>? onResult)
{
    // 验证预解析结果
    if (resolvedDelegate == null)
    {
        // delegate 未解析成功，回退到运行时解析路径
        return CreateEventHandler(control, eventName, functionName,
            parameterBindings, null, null, onResult);
    }

    // 判断是否为单节点工作流
    var isSingleNode = resolvedWorkflow?.Nodes?.Count <= 1;

    // 生成预解析闭包
    return new EventHandler((sender, args) =>
    {
        try
        {
            // 1. 从预计算的参数来源读取值
            var form = (sender as Control)?.FindForm();
            var parameters = _parameterBuilder.BuildFromSources(
                precomputedSources, form, sender);

            // 2. 直接调用 delegate
            object? result;
            if (isSingleNode)
            {
                result = resolvedDelegate.DynamicInvoke(
                    parameters.Values.ToArray());
            }
            else
            {
                // 多节点工作流走完整路径
                var execResult = _executionService
                    .ExecuteFunctionAsync(functionName, parameters)
                    .GetAwaiter().GetResult();
                result = execResult.Value;
            }

            // 3. 回写结果
            HandleExecutionResult(control, functionName, result, onResult);
        }
        catch (Exception ex)
        {
            onResult?.Invoke(functionName, "error", ex.Message);
        }
    });
}
```

### 3.5 `ParameterBuilder` 新增预计算方法

**位置：** `CsharpPrj/Operation/WorkFlowMethod/Parameters/ParameterBuilder.cs`

```csharp
// ============================================================
// 新增：预计算参数来源
// ============================================================

/// <summary>
/// 预计算参数来源 — 绑定阶段调用
/// <para>将 parameterBindings 转换为 ParameterSource 数组，</para>
/// <para>点击时直接使用该数组读取控件值，跳过遍历和查找。</para>
/// </summary>
public ParameterSource[] PrecomputeSources(
    IReadOnlyList<ParameterBinding>? parameterBindings)
{
    if (parameterBindings == null || parameterBindings.Count == 0)
        return Array.Empty<ParameterSource>();

    var sources = new ParameterSource[parameterBindings.Count];
    for (int i = 0; i < parameterBindings.Count; i++)
    {
        var binding = parameterBindings[i];
        sources[i] = new ParameterSource
        {
            SourceControlName = binding.Source ?? "",
            SourceProperty = binding.Property ?? "Text",
            TargetParameterName = binding.Target ?? binding.Source ?? $"param{i}"
        };
    }
    return sources;
}

/// <summary>
/// 从预计算的参数来源读取值 — 点击时调用
/// <para>直接使用 ParameterSource 数组读取控件值，不遍历 parameterBindings。</para>
/// </summary>
public Dictionary<string, object> BuildFromSources(
    ParameterSource[] sources,
    Form? parentForm,
    object sender)
{
    if (sources == null || sources.Length == 0)
    {
        // 无参数绑定时的回退：从 sender 读取 Text
        var value = (sender as Control)?.Text ?? "";
        return new Dictionary<string, object> { ["value"] = value };
    }

    var result = new Dictionary<string, object>(sources.Length);
    foreach (var source in sources)
    {
        Control? sourceControl;

        if (string.IsNullOrEmpty(source.SourceControlName))
        {
            // 未指定控件名，使用 sender
            sourceControl = sender as Control;
        }
        else
        {
            // 从父窗体查找控件
            sourceControl = parentForm?.Controls
                .Find(source.SourceControlName, true)
                .FirstOrDefault();
        }

        object? value = null;
        if (sourceControl != null && !string.IsNullOrEmpty(source.SourceProperty))
        {
            var prop = sourceControl.GetType()
                .GetProperty(source.SourceProperty,
                    BindingFlags.Public | BindingFlags.Instance | BindingFlags.IgnoreCase);
            if (prop != null && prop.CanRead)
            {
                value = prop.GetValue(sourceControl);
            }
        }

        result[source.TargetParameterName] = value ?? "";
    }
    return result;
}
```

### 3.6 `WorkflowMethodExecutionService` 新增预解析执行路径

**位置：** `CsharpPrj/Operation/WorkFlowMethod/WorkflowMethodExecutionService.cs`

```csharp
// ============================================================
// 新增：预解析执行路径
// ============================================================

/// <summary>
/// 查找工作流定义（供绑定阶段预解析使用）
/// </summary>
public WorkflowDefinitionEntry? FindWorkflow(string functionName)
{
    _workflows.TryGetValue(functionName, out var workflow);
    return workflow;
}

/// <summary>
/// 预解析执行 — 跳过工作流查找和节点遍历
/// <para>绑定阶段已预解析好 delegate 和工作流定义，</para>
/// <para>此方法直接执行，不做任何查找操作。</para>
/// </summary>
public async Task<ExecutionResult> ExecutePreResolvedAsync(
    Delegate? resolvedDelegate,
    WorkflowDefinitionEntry? resolvedWorkflow,
    string functionName,
    Dictionary<string, object> parameters)
{
    // 单节点短路：直接调用 delegate
    if (resolvedDelegate != null &&
        (resolvedWorkflow?.Nodes?.Count ?? 0) <= 1)
    {
        object? result;
        try
        {
            result = resolvedDelegate.DynamicInvoke(
                parameters.Values.ToArray());
        }
        catch (Exception ex)
        {
            return ExecutionResult.Failure(
                $"Pre-resolved execution failed for '{functionName}': {ex.Message}");
        }

        // 统一包装返回值
        var outputKey = resolvedWorkflow?.Nodes?.LastOrDefault()?.OutputKey ?? "value";
        return ExecutionResult.Success(new Dictionary<string, object>
        {
            [outputKey] = result ?? new object()
        });
    }

    // 多节点工作流：走完整路径
    if (resolvedWorkflow != null)
        return await ExecuteWorkflowAsync(resolvedWorkflow, parameters);

    // 无工作流定义时，从 registry 自动包装
    if (_registry.Find(functionName) != null)
    {
        var autoWorkflow = new WorkflowDefinitionEntry
        {
            Id = functionName,
            Name = functionName,
            DisplayName = functionName,
            Nodes = new List<WorkflowNodeEntry>
            {
                new()
                {
                    Id = $"node-{functionName}",
                    FunctionName = functionName,
                    Parameters = parameters,
                    OutputKey = "value",
                    OutputTarget = null
                }
            }
        };
        return await ExecuteWorkflowAsync(autoWorkflow, parameters);
    }

    throw new InvalidOperationException(
        $"Pre-resolved execution failed: no delegate and no workflow for '{functionName}'");
}
```

## 4. 回退策略

### 4.1 预解析失败时的降级

当预解析失败时（如工作流尚未注册），自动降级到运行时解析路径：

```csharp
// 在 CreatePreResolvedHandler 中
if (resolvedDelegate == null)
{
    // 降级到运行时解析
    return CreateEventHandler(control, eventName, functionName,
        parameterBindings, outputTarget, outputKey, onResult);
}
```

### 4.2 异常处理

预解析 handler 中的异常统一通过 `onResult` 回调报告，不抛出未处理异常：

```csharp
try
{
    // 执行逻辑
}
catch (Exception ex)
{
    onResult?.Invoke(functionName, "error", ex.Message);
}
```
