## 二、逐项修复方案

### 修复 1：ParameterTransformer.FillFromDict — 参数名不匹配时记录 Warning

**位置**：`CsharpPrj/Modules/ExecutionFramework/Engine/ParameterTransformer.cs:137`

**当前代码**：
```csharp
// ★ 2026-07-05 修复：未匹配参数时使用默认值
//   当 Dictionary 中的键名与函数参数名不匹配时，使用默认值（null/零值）
//   会导致函数以错误的参数执行，但此处不抛错以保持兼容性
args[i] = _getDefault(i);
```

**修复方案**：
```csharp
// 未匹配参数时使用默认值，但记录 Warning 日志
// 参数名不匹配通常是配置错误，需要开发者注意
args[i] = _getDefault(i);

// 记录 Warning 日志（通过注入的 ILogger 或全局诊断上下文）
// 注意：ParameterTransformer 是静态工厂创建的，需要注入 ILogger
// 方案 A：ParameterTransformer 接受可选 ILogger
// 方案 B：通过全局诊断上下文记录
DiagnosticContext.Warning(
    "ParameterTransformer.FillFromDict.UnmatchedParameter",
    $"参数 '{_paramNames[i]}' 在 Dictionary 中未找到，使用默认值。"
    + $"可用键: {string.Join(", ", dict.Keys)}");
```

**注意**：`ParameterTransformer` 当前是静态工厂方法创建，没有 `ILogger` 注入点。需要：
1. 为 `ParameterTransformer` 添加可选的 `ILogger` 参数
2. 或在 `FunctionExecutor` 中捕获参数转换结果并检查是否有未匹配参数

**推荐方案**：在 `FunctionExecutor.ExecuteWithTimeoutAsync` 中，参数转换后检查结果中是否有默认值（0 / null），如果有且输入参数中有对应的键名，记录 Warning。

### 修复 5：UnifiedConfigLoader — workflow 注册时验证委托

**位置**：`FileDriven/FileDriven.Execution/` 中的 `UnifiedConfigLoader`

**当前行为**：`RegisterWorkflow` 只创建 `TrConfigRecord`，不验证对应的委托是否存在。

**修复方案**：
```csharp
// 在 RegisterWorkflow 中验证
private void RegisterWorkflow(FunctionConfig func, UnifiedConfig unifiedConfig)
{
    // 1. 先注册 TrConfigRecord（当前逻辑）
    var record = new TrConfigRecord(...);
    _registry.Register(func.Name, record);

    // 2. 验证对应的 delegate 是否存在（新增）
    if (!_registry.TryGetConfig(func.Name, out var config) || config is not DelegateTrConfig)
    {
        // 记录 Warning，但不阻止注册
        // workflow 可能在后续阶段才绑定 delegate
        EventBindingDiagnosticContext.Record("UnifiedConfigLoader.WorkflowWithoutDelegate", new
        {
            functionName = func.Name,
            warning = "Workflow 注册时未找到对应的 Delegate 配置，"
                + "执行时可能失败。请确保存在同名的 delegate 类型函数配置。"
        });
    }
}
```

### 修复 6：FunctionExecutor — 区分超时和取消

**位置**：`CsharpPrj/Modules/ExecutionFramework/Engine/FunctionExecutor.cs:192-200`

**当前代码**：
```csharp
catch (OperationCanceledException)
{
    stopwatch.Stop();
    return ExecutionResult.Cancelled();
}
catch (TimeoutException)
{
    stopwatch.Stop();
    return ExecutionResult.Timeout();
}
```

**修复方案**：
```csharp
catch (OperationCanceledException ex)
{
    stopwatch.Stop();
    // 区分超时取消和用户取消
    if (ex.CancellationToken == context.CancellationToken)
    {
        // 用户主动取消
        return ExecutionResult.Cancelled("用户取消操作");
    }
    else
    {
        // 超时取消（由 cts.CancelAfter 触发）
        return ExecutionResult.Timeout($"操作超时（{_defaultTimeout.TotalSeconds}秒）");
    }
}
catch (TimeoutException tex)
{
    stopwatch.Stop();
    return ExecutionResult.Timeout($"操作超时: {tex.Message}");
}
```

**注意**：`OperationCanceledException` 的 `CancellationToken` 属性在 .NET 中需要检查与哪个 Token 关联。当前代码使用 `CreateLinkedTokenSource`，可以通过检查 `cts.Token` 来区分。

### 修复 7：RestoreSnapshot — 文档化快照覆盖范围

**位置**：`EventBindingContext` 的 `WalkAndBind` 方法

**当前问题**：快照机制没有文档化哪些属性会被保存和恢复。

**修复方案**：在 `EventBindingContext` 类中添加注释：

```csharp
/// <summary>
/// 快照保存/恢复机制
/// 
/// 保存的属性：
///   - CurrentControl
///   - CurrentControlConfig
///   - CurrentDeclaration
///   - CurrentParameterBindings
///   - CurrentOutput
///   - SkipCurrentControl
/// 
/// 不保存的属性（Execute 中修改后不会被恢复）：
///   - BoundControls（累积）
///   - SkippedControls（累积）
///   - BoundCount / SkippedCount（累积计数器）
///   - EventBus（全局共享）
///   - Config（全局共享）
/// 
/// 设计原则：快照只保存"当前控件"相关的上下文，
/// 累积统计和全局共享状态不在快照范围内。
/// </summary>
```

### 4.1 单元测试验证

```csharp
// 测试 1：参数名不匹配时应有 Warning 日志
[Test]
public void FillFromDict_UnmatchedParameter_LogsWarning()
{
    var transformer = ParameterTransformer.ForMethod(
        typeof(MathLibrary).GetMethod("Add"));
    var dict = new Dictionary<string, object> { { "wrongName", 3.0 }, { "b", 5.0 } };

    var result = transformer.Transform(dict);

    // 验证：a 参数使用默认值 0.0
    Assert.That(result[0], Is.EqualTo(0.0));
    // 验证：有 Warning 日志记录
    Assert.That(TestDiagnosticContext.LastWarning,
        Does.Contain("UnmatchedParameter"));
}

    // 验证：有 Error 日志记录
```
