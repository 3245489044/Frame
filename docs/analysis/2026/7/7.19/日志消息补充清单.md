## 5. 动态 msgId 修复清单

以下调用使用运行时拼接的 msgId，**无法在 JSON 中预注册**，需要改为静态 msgId + 参数传递。

### 5.1 MainForm.cs — stageCoordinator_null

**当前代码：**
```csharp
UILog.Log($"MainForm_{caller}_stageCoordinator_null",
    new { warning = "StageCoordinator 未注入，创建默认实例" });
```

**建议改为：**
```csharp
UILog.Log("MainForm_stageCoordinator_null",
    new { caller, warning = "StageCoordinator 未注入，创建默认实例" });
```

**对应 JSON 定义：**
```json
"MainForm_stageCoordinator_null": {
    "level": "Warning",
    "category": "Launcher_Bootstrap",
    "template": "[MainForm] {caller}: {warning}"
}
```

### 5.2 FileDrivenWdUIBridge.cs — 动态 logPrefix

**当前代码（5 处）：**
```csharp
UILog.Log($"MainForm_{logPrefix}_diagnostic", new { indexKeys, foundContainers = containerNames });
UILog.Log($"MainForm_{logPrefix}_detail", new { ... });
UILog.Log($"MainForm_{logPrefix}_corrupted", new { actualName = c.Name, expectedName = containerName });
UILog.Log($"MainForm_{logPrefix}_fallback_detail", new { foundContainers = containerNames, indexKeys });
UILog.Log($"MainForm_{logPrefix}_fallback_registered");
```

**建议统一改为：**
```csharp
UILog.Log("MainForm_WdUIBridge_diagnostic", new { logPrefix, indexKeys, foundContainers = containerNames });
UILog.Log("MainForm_WdUIBridge_detail", new { logPrefix, ... });
UILog.Log("MainForm_WdUIBridge_corrupted", new { logPrefix, actualName = c.Name, expectedName = containerName });
UILog.Log("MainForm_WdUIBridge_fallback_detail", new { logPrefix, foundContainers = containerNames, indexKeys });
UILog.Log("MainForm_WdUIBridge_fallback_registered", new { logPrefix });
```

**对应 JSON 定义：**
```json
"MainForm_WdUIBridge_diagnostic": {
    "level": "Debug",
    "category": "Launcher_Bootstrap",
    "template": "[MainForm] WdUIBridge diagnostic: logPrefix={logPrefix}, indexKeys={indexKeys}, foundContainers={foundContainers}"
},
"MainForm_WdUIBridge_detail": {
    "level": "Debug",
    "category": "Launcher_Bootstrap",
    "template": "[MainForm] WdUIBridge detail: logPrefix={logPrefix}, ..."
},
"MainForm_WdUIBridge_corrupted": {
    "level": "Warning",
    "category": "Launcher_Bootstrap",
    "template": "[MainForm] WdUIBridge corrupted: logPrefix={logPrefix}, actualName={actualName}, expectedName={expectedName}"
},
"MainForm_WdUIBridge_fallback_detail": {
    "level": "Debug",
    "category": "Launcher_Bootstrap",
    "template": "[MainForm] WdUIBridge fallback detail: logPrefix={logPrefix}, foundContainers={foundContainers}, indexKeys={indexKeys}"
},
"MainForm_WdUIBridge_fallback_registered": {
    "level": "Info",
    "category": "Launcher_Bootstrap",
    "template": "[MainForm] WdUIBridge fallback registered: logPrefix={logPrefix}"
}
```
