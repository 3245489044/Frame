## 3. vscode-plugin-framework 框架

### 3.1 概述

vscode-plugin-framework 是一个模块化的 VS Code 插件配置与执行框架，位于 `vscode-plugin-framework/` 目录。

**架构**：

```
vscode-plugin-framework/
├── core/           # 核心层：配置加载、路径解析、菜单、执行调度
├── plugins/        # 插件层：每个插件一个独立模块
├── config/         # 配置层：全局配置和启动项注册表
├── runner.bat      # 入口：一键启动
└── install.bat     # 安装：自动集成到 VS Code
```
