## 一、根因抽象：四个断链

```
入队成功 ≠ 渲染执行 ≠ 控件挂载 ≠ 控件可见
   ①           ②           ③        ④
  无结果契约    无执行校验    无挂载校验   无可见性校验
```

- ① 发射链：`MatrixEventSink.EmitLoadConfig` 入队即返回 true（且矩阵无消费者）。
- ② 执行链：`EcsGate` 审计 result=True = 无异常；host=null 也照常执行。
- ③ 挂载链：`WinFormApplier.ApplyRelations` Skip 是 Debug 级、不汇总、不上报。
- ④ 验证链：validate = 池存在性；快照 = ECS 实体数；报告不区分容器。

## 二、核验补充发现（分析文档之外的 4 条决定性证据）

## 三、重构方案（分层，S1-S5 已实施）

### S1 · WinFormApplier 挂载结果回传（ApplyResult）

- **`WinFormSnapshot.cs`**：新增 `ApplyResult`（`ControlsProcessed/CreatedCount/UpdatedCount/ControlsSkipped/RelationsProcessed/RelationsApplied/RelationsSkipped/SkipReasons[]/AllMounted/ToSummaryText`）。
- **`WinFormApplier.cs`**：`Apply` 返回 `ApplyResult`；`ApplyControls` 统计创建/更新/跳过；`ApplyRelations` 统计挂载/跳过，`Skip_RelationControlNotFound`/`Skip_InvalidTargetPanel` **升 Warning** 且进入 `SkipReasons`（含 ParseFailed 分类）。
- **`Ports.cs`**：`WinFormsOutputPort.ApplySnapshot` 返回 `ApplyResult`。
- **`fde_log_messages.json`**：`WinFormApplier_ApplyResult_summary`（Info）新增；Skip 消息升 Warning。

### S2 · 结果契约链路（RenderRunResult → EcsGate → 状态管线）

- **`RenderPipelineStages.cs`**：`RenderRunResult` 扩展 `MountedCount/OrphanCount/ControlsSkippedCount/SkipReasons` + `Succeeded`（= `RenderExecuted && OrphanCount==0 && ControlsSkippedCount==0`）；`RenderContext` 增 `ApplyResult`；`RenderApplyStage` 回填。
- **`RenderStageRunner.cs`**：`BuildResult` 组装挂载统计。
- **`RenderPipelineComposition.cs`**：`Execute`/`ExecuteRenderStage` 返回 `RenderRunResult`；摘要日志加 `mountedCount/orphanCount`。
- **`EcsOperation.cs`**：`LoadAndRenderOperation : EcsOperation<RenderRunResult>`。
- **`EcsGate.cs`**：`LoadConfigAndRenderAsync` 返回 `Task<RenderRunResult>`；`DoLoadAndRender` **host=null 显式抛 `InvalidOperationException`**（不再静默创建孤儿实体）；`AuditLogInterceptor` 审计携带 `collected/mounted/orphan/succeeded/skipReasons`（替代裸 bool 假绿）。
- **`ContainerProjector.cs`**：`RenderAsync`/`RenderOnUIThreadAsync` 返回 `RenderRunResult`；`PublishLoadedAsync` 携带 `MountedCount`。
- **`ContainerCommandExecutor.cs`**：`LoadToScopeAsync` 返回 `result.Succeeded`，失败打 `ContainerCommandExecutor_Render_NotSucceeded`（Warning）。


### S3 · 验证语义升格（存在性 → 挂载可见性）

- **`UiCommandSystems.cs` ValidateSystem**：
  - `ResolveScopedControl` 无 scope 时默认**可见窗体树查找**（`FindAcrossForms(form.Visible)` + `FindRecursive`）；`ControlPool` 直查仅作降级并 WARN `Command_Validate_Fallback_PoolExistence`。
  - 找到控件后校验 `IsMountedOnVisibleTree`（`FindForm() != null`）——孤儿控件判失败 `Command_Validate_NotMounted`。
  - `expectedText` 参数存在即比对（**含空串**：合法"期望空文本"断言；模板缺失展开的空串对非空控件必然失配 → fail-fast，杜绝静默降级）。
- **`UiCommandSystems.cs` AssertSystem**：新增 `container` 子命令（`assert container <host> count<op><n>`，宿主须已挂载 + 直接子控件数断言）。
- **`UiCommandSystems.cs` 新增 `ValidateMountSystem`**（action `validate-mount`/`mount`）：校验控件挂载到指定宿主（`parent=<host>` 可选 `visible`）。
- **`UiCommandSystems.cs` 新增共享 `ValidateSystemHelpers`**（`IsMountedOnVisibleTree/IsDescendantOf/TryParseCountExpr/CompareCount/GetParamString`）。
- **`CommandCoordinator.cs`**：注册 `ValidateMountSystem`。
- **`backend_log_messages.json`**：**补全** `Command_Validate_TextMatch`/`PositionMatch`（消除"消息未找到"WARN 噪音）；新增 `Command_Validate_NotMounted`（Warning）/`Command_Validate_Fallback_PoolExistence`（Warning）/`Command_Validate_Mount_Success`/`Command_Assert_Container`。

### S4 · 布局报告容器归属统计（口径显式化）

- **`LayoutInspectSystem.cs`** `ExecuteReport`：末尾追加「容器归属统计（直接子控件数）」——所有命名容器（Panel/GroupBox/SplitContainer/ContainerControl/TabControl 或已有子控件）逐一列出，空容器标注 `← 空容器（未挂载任何子控件）`；`Layout_Report` 日志模板加 `containerCount`。
- 说明：`layout report` 本为可见树口径（非 ECS/池视角），此改动让 sideContainer 空显式暴露，不再淹没在控件总数里。

### S5 · 发射链收敛（删除矩阵死胡同）

- **`UIToolbox.cs`** `LoadConfigFromPath`：删除 `sink.EmitLoadConfig` 优先分支，统一走 `ILoadConfigPort`（状态管线）。
- **`MainFormGateFactory.cs`**：删除 `RegisterMatrixHandlers` + `AwaitAndRespond`（死代码——`Resolve<ITaskExecutorPool>() as TaskExecutorPool` 恒 null），清理 using。
- **`MatrixEventSink.cs`**：`EmitLoadConfig` 标记 `[Obsolete]`（矩阵无 handler 消费，禁止再走发射路径）。

### S6 · 脚本资产与回归（待执行）

- 运行 `echo 9 | EnableMent\交互启动.bat`，核对：
  1. `WinFormApplier_ApplyResult_summary`（allMounted）
  2. `ContainerCommandExecutor_Render_NotSucceeded` / `WinFormApplier_Skip_*`（Warning，若挂载失败）
  3. `EcsGate_audit_after` detail（mountedCount/orphanCount/succeeded）
  4. `layout report` 容器归属统计（sideContainer 空显式标注）
