# 参数绑定链与生命周期钩子收敛重构方案（实施记录）

> **版本：** v1.0
> **日期：** 2026-08-05
> **范围：** 生命周期钩子接线（P0）、参数绑定/事件链收敛（D1/D3/D5/D6/W1/W2/W3）、控件查找面废弃方向（D4/W4）
> **关联故障：** mainlayout_run_ui.json 调用链——configListView 空 → LoadConfigToTarget configPath 空 → sideContainer 未加载

---

## 一、根因与修复结论

### 1.1 P0 生命周期钩子加载路径零消费（已修复）

- **根因**：`ConfigSelector.json` 声明 `lifecycle.onAfterLoad:["LoadJsonConfigList"]`，但加载路径
  `ScopeLifecycleAdapter.RenderAsync`（2026-08-05 StateCenter 收敛后）未调用 `LifecycleHookExecutor`
  （仅销毁路径 `ConfigurationLifecycleManager.DestroyScopeAsync` 消费了 OnBeforeDestroy/OnAfterDestroy）。
- **修复**：`ScopeLifecycleAdapter.RenderAsync` 接线：
  - 配置加载后、渲染前：`OnBeforeLoad`（失败不阻断渲染）
  - 渲染 + `MarkMounted` 成功后、`Loaded` 事件前：`OnAfterLoad`（仅挂载成功时执行，避免在失效 UI 上跑初始化）
  - 向后兼容：未声明 `lifecycle` 时回退执行旧 `initCommands`（`exec X k=v` 命令式条目经 `ExecuteWorkflow` 统一函数通道）
- **验证**：`UIToolbox_LoadJsonConfigList_start/completed(count=8)` 出现；`mainlayout_run_ui.json` 23/23 PASS。

### 1.2 架构约束：钩子落点

- 钩子**必须**放在 `ScopeLifecycleAdapter`（纯 async 链），**不能**放在 `RenderStageRunner` 管线内——
  管线执行是 `GetAwaiter().GetResult()` 同步包装，async 钩子有 UI 线程互等死锁风险。

### 1.3 P1/P2 行为修复（已提交）

| 项 | 修复 | 文件 |
|----|------|------|
| SetSystem 假阳性 | ListView 无匹配项 → `false`（如实失败） | `ClickSetGetSystems.cs` |
| 双击假阳性 | 非 Button 且无 `OnDoubleClick` 反射 → `false` | 同上 |
| 参数绑定空值静默 | `value==null && Default==null` → `LogWarning`（参数名+来源+属性路径） | `ParameterBinder.cs` |
| 日志模板 | `UIToolbox_LoadConfigToTarget_error` 补 `configPath`/`targetContainer` | `UIToolbox.cs` |

## 二、重复逻辑收敛

### 2.1 D1/D5 参数求值内核单点化（阶段 3，已提交）

- 新增内核（`Modules/ParameterResolver`）：
  - `Utilities/PropertyPathResolver`：`ReadNestedProperty`/`GetIndexedValue` 唯一实现（吸收 3 份逐行重复：
    `BackEndDriven.ParameterBinder` / `WorkFlowMethod.ParameterBuilder` / `WorkFlowMethod.ParameterValueResolver`）
  - `Sources/WinForms/ControlValueAccessor`：控件取值（含 ListView 选中项特判）唯一实现（吸收 D5）
- `BackEndDriven.ParameterBinder`、`WorkFlowMethod.ParameterValueResolver` 改委托内核（行为不变）
- **删除死链**：`WorkFlowMethod.ParameterBuilder` + `Abstractions/IParameterBuilder` + `ParameterBuilderStages`
  （零真实消费者——仅死注入 `EventBindingOptions.ParameterBuilder` 与死构造依赖 `IParameterBuilder`）
- **删除死注入**：`EventBindingOptions.ParameterBuilder` 属性 + `EventBindingInitializer` 死委托 + `ParameterBinder` 死构造依赖
- 新增内核单测 12 个（`PropertyPathResolverTests`），全过。

### 2.2 D6/W1 事件参数 DTO 链坍缩（阶段 4，已提交）

**前**（5 层转换）：
```
JSON → TConfig.ParameterBinding → EcsParameterBinding(×3 复制) → ParameterMapping → TConfig.ParameterBinding → ParameterSource → 求值
```
**后**（1 层直通）：
```
JSON → TConfig.ParameterBinding ──直通 ECS/声明/触发──→ 求值
```
- `EventBindingsComponent.Parameters`：`EcsParameterBinding[]` → `TConfig.ParameterBinding[]`（同项目 TConfig，零复制）
- `ControlFactory` 3 处复制构造 → 直接引用
- `EventBindingDeclaration<IReadOnlyList<ParameterMapping>>` → `IReadOnlyList<ParameterBinding>`（声明链 8 文件）
- `ExtractFromDeclaration` → 直接透传（删 ParameterMapping→ParameterBinding 回转换）
- `IParameterBinder`：删 `PrecomputeSources`/`BuildFromSources(ParameterSource[])` → `Build(IReadOnlyList<ParameterBinding>)`
- **删除** `TConfig.ParameterSource` 类；`ResolverContext.MapParameters` 删除
- `ParameterMapping`（配置/校验域 DTO）**保留**——Validation/IBindingResolver/EventDescriptor 消费，非事件绑定运行时链。

### 2.3 D4/W4 IControlFinder 废弃方向落实（阶段 5，已提交）

- 三套接口现状：`WinFormsAbstractions.IControlFinder`（统一面，`ControlFinderAdapter` 委托 `Share.ControlLookup` 内核）
  已作为脚本命令主通道；`FrameworkAbstractions.Controls.IControlFinder`/`TConfig.IControlFinder`（object 签名，
  承载多级查找：ControlPool→EntityTree→Registry）仍有工作流执行路径消费。
- 落实 `[Obsolete]` 标记（接口注释已声明的 R2 废弃方向）指向统一面；**消费方迁移完成前不删除接口**。
- **遗留（后续工作）**：`WorkflowMethodExecutionWorkflow`/`CommandFramework`/`EventBindingInitializer.TConfig.IControlFinder`
  迁移到统一面 + `ControlFinderAdapter`(树遍历) 与 `ControlRegistryAwareFinder`(多源) 两种查找策略合并 + 适配器删除。

## 三、错误逻辑/冗余逻辑结论

### 3.1 W6 双收集口径（无需改码）

`RenderPipelineComposition_Execute_summary`（collectedCount=0）为**加载区间**日志（`Execute()` 仅 Load/Creation，
注释已明确"区间未运行而非结果为空"）；`CsgEntryPoint controlCount=18` 为**渲染区间**日志。两阶段语义正确，
非口径分裂——报告误读。

### 3.2 遗留 MountState（P0 修复后自然解决）

`sideContainer` 的 MountState 由"其所属 scope（Side）是否已注入宿主"决定。P0 修复后 Side 真实加载 →
`ScopeLifecycleAdapter.MarkMounted("Side")` 执行 → Mounted。原始"MountState=Registered"是根因（Side 从未加载）的症状。

### 3.3 initCommands 死配置

`AgentConfigUI.json`/`MathFunctionBrowser.json` 仍声明 `initCommands`（迁移期保留）。P0 修复已实现
`lifecycle ?? initCommands` 回退执行；待两配置迁移到 `lifecycle.onAfterLoad` 后可删除 `InitCommands/InitCommandMode`。
