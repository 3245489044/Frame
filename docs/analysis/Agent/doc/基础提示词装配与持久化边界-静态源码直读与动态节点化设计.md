# 基础提示词装配与持久化边界设计（静态源码直读 · 动态节点化）

> **范围**：`agent_conversation` 主对话框头提示层 + 统一装配框架（Agent.Assembly）的写侧捕获 / 读侧投影 / 持久化边界。
> **状态**：核心已落地（`Agent.sln` 编译通过）；读侧 skill 直投 与 L1/L2 的 prompt 段投影为**待补齐缺口**（见 §8.3）。

---

## 1. 背景与目标

- **测试诉求**：基础提示词校验**不触发 LLM 请求**，仅校验基础提示词；**创建空 task/history 即可**完成校验。
- **设计目标**：把"基础提示词（L0/skill）"与"动态装配（L1/L2）"的**持久化边界**厘清，消除 `__prompt_snapshot` 特殊键的全量冗余落库。

---

## 2. 问题定义

当前 `__prompt_snapshot`（`PromptSnapshot.ToJson()` 序列化 L0 + SkillBlock + L1 + L2 + SelectedSkills）同时犯两个错：

1. **冗余落库静态内容**：L0（`PromptCatalog.L0SystemPrompt` / `AgentSystemPrompts.ConversationAssistant`）与 skill（`skills/**/SKILL.md`）本有**代码/配置文件源**，却被复制进快照持久化 —— 非单源、体积膨胀。
2. **动态内容没用节点**：L1/L2 是每轮动态产出，本应像其它工作流节点一样走 ur_nodes 存储，却用特殊键 `__prompt_snapshot` 落库，且与节点横切写重复。

---

## 3. 设计语义（三态收敛）

| 内容 | 性质 | 存储 | 读侧 |
|---|---|---|---|
| L0 基础提示词 | 静态源码 | **不落库**，直读 `PromptCatalog.L0SystemPrompt` | UI 头提示层 `prompt:l0` |
| skill 块 | 静态 SKILL.md 源 | **不落库**，直读 skill 源 | UI 头提示层 `prompt:skill.block` |
| 动态 L1/L2 | 运行期产出 | **作为 ur_nodes 节点**（provide_prompt 节点端口） | `BuildTaskAsync` 合成 canonical |

> 特殊键 `__prompt_snapshot` 全量落库路径**取消**。

---

## 4. 持久化边界

- **L0 / skill**：静态、确定性、体积有界 → **不落库**；UI 渲染直读源码。
- **动态 L1/L2**：运行期瞬态 → **作为基础节点落库**（ur_nodes），随轮滚动、可恢复。
- **`__prompt_snapshot` 特殊键**：取消持久化（不再作为工作流 ResultKey / task Data 键）。

- `IPromptSnapshotStore` / `PromptSnapshotStore` 仍保留为**进程内内存视图**，供 UI≡LLM 运行期校验；不再作为持久化通道。

## 6. 读侧设计

### 6.1 L0 源码直投（已落地）
`Agent.Launcher/Modules/Libraries/ConversationViewService.cs`：

```csharp
var snapshot = AppServiceProvider.Resolve<IPromptSnapshotStore>()?.Read(scopeKey)
    ?? BuildBasePromptSnapshot();   // 源码 L0 兜底

private static PromptSnapshot? BuildBasePromptSnapshot()
{
    var l0 = Agent.Axioms.Prompts.PromptCatalog.L0SystemPrompt;
    return string.IsNullOrWhiteSpace(l0) ? null
        : PromptSnapshotBuilder.Build(l0, string.Empty, string.Empty, string.Empty, null);
}
```

- 运行期快照优先；无快照（如**创建空 task/history**）时直读 `PromptCatalog.L0SystemPrompt` 渲染 `prompt:l0`，**零 LLM**。
- `UiViewProjector.Build(canonical, snapshot)` → `PromptSegments.FromSnapshot` 投影头提示层。

### 6.2 读侧投影链路
```
ConversationViewService.RenderViewAsync
  → store.Read(scopeKey) ?? BuildBasePromptSnapshot()   // 头提示层 L0（源码/运行期）
  → UiViewProjector.Build(canonical, snapshot)           // 头提示层 + canonical 历史/节点
  → LlmViewProjector.Build(canonical, snapshot)          // 与 UiView 同源，供 UI≡LLM 校验
```

## 10. 边界与不变式对齐

| 不变式 | 对齐 |
|---|---|
| `SingleImplementation` / TH-12 | L0/skill 单一源码；L1/L2 单一 ur_nodes；消除 `__prompt_snapshot` 双写 |
| `QuantificationConstraint` | 不再有全量快照落库（落库体积有界） |
| `InformationMonotonicity` | 静态源码只增不丢；动态节点随轮滚动可恢复；对话/历史仍持久 |
| `ANTI-FIDELITY-LOSS`（R3） | L0 逐字一致由单一源码 + 哈希保证 |
