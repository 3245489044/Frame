# 动态工作流生成实现方案

## 基于 WorkFlowMethod JSON 合并引擎构建 Cline 风格编程智能体

---

## 一、概述

本文档详细描述如何基于 WorkFlowMethod 框架已有的**动态 JSON 工作流合并能力**，改造当前 Agent 项目，实现 Cline 风格的编程智能体。

### 核心思想

```
LLM 规划器 → 输出 JSON 工作流片段 → 合并到当前执行链 → 执行 → 观察结果 → 继续循环
```

### 当前状态 vs 目标状态

| 维度 | 当前状态 | 目标状态 |
|------|---------|---------|
| 工作流定义 | 静态 JSON 文件 | 静态骨架 + 动态片段拼接 |
| LLM 输出 | 纯文本回复 | 结构化 JSON 工作流片段 |
| 工具调用 | 硬编码在代码中 | 由 LLM 动态决定调用序列 |
| 循环控制 | 单次执行 | 完整的 ReAct 循环（规划→执行→观察→再规划） |
| 上下文管理 | 无 | AFM 策略压缩历史 |

## 二、WorkFlowMethod 已有的动态合并能力

### 2.1 ConnectChainInfoConfig — 运行时跨链拼接

`NodeConfig.NextNodeConfig` 中的 `ConnectChainInfoConfig` 字段允许在运行时动态拼接另一个工作流链：

```json
{
  "nextNodeConfig": {
    "ConnectChainInfoKey": "OBJSET:{...}, VALUESET:{...}",
    "ConnectChainInfoConfig": "目标链名称",
    "UpdateChain": "true",
    "AfterNodeCallkey": "在哪个节点之后插入"
  }
}
```

**关键字段说明：**

| 字段 | 类型 | 说明 |
|------|------|------|
| `ConnectChainInfoConfig` | string | 目标 ChainInfo 的名称（存储在 StorageManager 中） |
| `ConnectChainInfoKey` | string | 键位映射规则，定义数据如何传递到被拼接的工作流 |
| `UpdateChain` | bool | 是否更新当前链（true=替换，false=追加） |
| `AfterNodeCallkey` | string | 在指定节点之后插入 |
| `BeforeNodeCallkey` | string | 在指定节点之前插入 |

### 2.2 ChainInfoWorkflowStorageManager — 链信息存储

```csharp
var storage = new ChainInfoWorkflowStorageManager();
storage.SaveChainInfo("my_chain", chain);     // 保存工作流
var chain = storage.GetChainInfo("my_chain");  // 获取工作流
storage.ContainsChainInfo("my_chain");         // 检查存在
storage.DeleteChainInfo("my_chain");           // 删除
storage.Clear();                               // 清空所有
```

### 2.3 WorkflowBuilder — 编程式构建节点

```csharp
// 从 JSON 字符串创建节点列表
var nodes = WorkflowBuilder.CreateNodesFromJson(jsonString);

// 编程式添加节点
WorkflowBuilder.AddNode(nodes, "process", "ReadFile", "mcp_call_tool",
    new[] { "server", "tool", "arguments" },
    new[] { "result" });

// 构建完整工作流 JSON
var workflowJson = WorkflowBuilder.BuildWorkflow(nodes);
```

### 2.4 ExecuteFromJsonAsync — 从 JSON 字符串直接执行

```csharp
// 直接从 JSON 字符串执行工作流（无需文件）

```

### 步骤 1：创建 DynamicWorkflowMerger（核心引擎）

**文件：** `src/Agent.Core/DynamicWorkflowMerger.cs`

```csharp
// ============================================================
// DynamicWorkflowMerger.cs — 动态 JSON 工作流合并引擎
//
// 职责：将 LLM 规划器输出的 JSON 工作流片段合并到当前执行链
// 利用 WorkFlowMethod 的 ConnectChainInfoConfig 机制实现
// ============================================================

using System;
using System.Collections.Generic;
using System.Text.Json;
using System.Threading.Tasks;
using WorkFlowMethod.Usage;
using WorkFlowMethod.Skeletons.NodeProcess.Models;
using WorkFlowMethod.Skeletons.NodeProcess;
using WfContext = WorkFlowMethod.Orchestration.Context.Models.WorkflowContext;

namespace Agent.Core
{
    /// <summary>
    /// LLM 输出的工作流片段模型
    /// </summary>
    public class WorkflowFragment
    {
        /// <summary>工作流节点列表</summary>
        public List<FragmentNode> Nodes { get; set; } = new();

        /// <summary>键位映射规则（源字段 → 目标字段）</summary>
        public Dictionary<string, string> KeyMapping { get; set; } = new();
    }

    /// <summary>
    /// 工作流片段中的节点定义
    /// </summary>
    public class FragmentNode
    {
        /// <summary>节点标识（process/start/end/error）</summary>
        public string Symbol { get; set; } = "process";

        /// <summary>节点 ID</summary>
        public string NodeId { get; set; } = "";

        /// <summary>注册的函数名称</summary>
        public string FuncName { get; set; } = "";

        /// <summary>参数键列表（从上下文中获取）</summary>
        public List<string>? ParameterKeys { get; set; }

        /// <summary>参数值（直接指定）</summary>
        public Dictionary<string, object>? ParameterValues { get; set; }

        /// <summary>结果键列表</summary>
        public List<string>? ResultKeys { get; set; }

        /// <summary>下一节点配置</summary>
        public Dictionary<string, object>? NextNodeConfig { get; set; }
    }

    /// <summary>
    /// 动态 JSON 工作流合并引擎
    /// </summary>
    public class DynamicWorkflowMerger
    {
        private readonly ChainInfoWorkflowStorageManager _storage = new();
        private int _fragmentCounter;

        /// <summary>
        /// 将 LLM 生成的 JSON 工作流片段合并到当前执行链并执行
        /// </summary>
        /// <param name="fragmentJson">LLM 输出的 JSON 工作流片段</param>
        /// <param name="context">当前工作流上下文</param>
        /// <returns>执行结果</returns>
        public async Task<object> MergeAndExecuteAsync(string fragmentJson, WfContext context)
        {
            // 1. 解析 JSON 片段
            var fragment = ParseFragment(fragmentJson);
            if (fragment == null || fragment.Nodes.Count == 0)
                return new { status = "error", message = "无法解析 LLM 输出的工作流片段" };

            Console.WriteLine($"[DynamicMerger] 解析到 {fragment.Nodes.Count} 个动态节点");

            // 2. 将片段节点转换为标准工作流 JSON
            var workflowJson = BuildWorkflowJson(fragment);

            // 3. 通过 ExecuteFromJsonAsync 直接执行
            var execContext = new UniversalWorkflowFramework.FunctionExecution.Core.ExecutionContext
            {
                FunctionName = $"dynamic_fragment_{++_fragmentCounter}",
                Items = ConvertContextItems(context)
            };

            var result = await WorkFlowMethodUsage.ExecuteFromJsonAsync(workflowJson, execContext);

            return new
            {
                status = result.IsSuccess ? "success" : "error",
                fragment_id = _fragmentCounter,
                node_count = fragment.Nodes.Count,
                result = result.IsSuccess ? result.Value : result.ErrorMessage
            };
        }

        /// <summary>
        /// 将片段注册为 ChainInfo 并返回连接配置
        /// （用于通过 ConnectChainInfoConfig 机制拼接）
        /// </summary>
        public string RegisterAsChainInfo(WorkflowFragment fragment)
        {
            var chainId = $"dynamic_chain_{++_fragmentCounter}";

            // 将片段节点转换为 NodeConfig 列表
            var nodes = ConvertToNodeConfigs(fragment);

            // 保存到 StorageManager
            _storage.SaveChainInfo(chainId, new ChainInfo
            {
                // ChainInfo 结构由 WorkFlowMethod 定义
                // 此处使用 WorkflowBuilder 构建完整结构
            });

            Console.WriteLine($"[DynamicMerger] 已注册动态链: {chainId} ({fragment.Nodes.Count} 节点)");
            return chainId;
        }

        /// <summary>
        /// 解析 LLM 输出的 JSON 字符串为 WorkflowFragment
        /// </summary>
        private WorkflowFragment? ParseFragment(string json)
        {
            try
            {
                // 尝试直接解析
                var fragment = JsonSerializer.Deserialize<WorkflowFragment>(json,
                    new JsonSerializerOptions { PropertyNameCaseInsensitive = true });
                if (fragment?.Nodes.Count > 0) return fragment;

                // 如果直接解析失败，尝试从嵌套字段中提取
                using var doc = JsonDocument.Parse(json);
                var root = doc.RootElement;

                // 尝试常见的嵌套路径
                if (root.TryGetProperty("workflow_fragment", out var fragmentEl))
                {
                    return JsonSerializer.Deserialize<WorkflowFragment>(
                        fragmentEl.GetRawText(),
                        new JsonSerializerOptions { PropertyNameCaseInsensitive = true });
                }

                if (root.TryGetProperty("fragment", out var fragEl))
                {
                    return JsonSerializer.Deserialize<WorkflowFragment>(
                        fragEl.GetRawText(),
                        new JsonSerializerOptions { PropertyNameCaseInsensitive = true });
                }

                return null;
            }
            catch (JsonException ex)
            {
                Console.WriteLine($"[DynamicMerger] JSON 解析失败: {ex.Message}");
                return null;
            }
        }

        /// <summary>
        /// 将 WorkflowFragment 构建为标准工作流 JSON
        /// </summary>
        private string BuildWorkflowJson(WorkflowFragment fragment)
        {
            var nodes = new List<object>();

            foreach (var fragNode in fragment.Nodes)
            {
                // 构建 funcPipelineConfig
                var funcConfig = new Dictionary<string, object>
                {
                    ["FuncName"] = fragNode.FuncName
                };

                if (fragNode.ParameterKeys != null)
                    funcConfig["ParameterKeys"] = fragNode.ParameterKeys;

                if (fragNode.ParameterValues != null)
                    funcConfig["ParameterValues"] = fragNode.ParameterValues;

                if (fragNode.ResultKeys != null)
                    funcConfig["ResultKeys"] = fragNode.ResultKeys;

                // 构建节点
                var node = new Dictionary<string, object>
                {
                    ["Symbol"] = fragNode.Symbol,
                    ["NodeId"] = fragNode.NodeId,
                    ["funcPipelineConfig"] = funcConfig
                };

                // 添加 KeyMapping（如果有）
                if (fragment.KeyMapping.Count > 0)
                {
                    node["KeyMapping"] = new Dictionary<string, object>
                    {
                        ["Mappings"] = fragment.KeyMapping
                    };
                }

                // 添加下一节点配置
                if (fragNode.NextNodeConfig != null)
                {
                    node["NextNodeConfig"] = new Dictionary<string, object>
                    {
                        ["Configs"] = fragNode.NextNodeConfig
                    };
                }

                nodes.Add(node);
            }

            // 使用 WorkflowBuilder 构建完整 JSON
            return WorkFlowMethodUsage.BuildWorkflow(nodes);
        }

        /// <summary>
        /// 将 FragmentNode 列表转换为 NodeConfig 列表
        /// </summary>
        private List<NodeConfig> ConvertToNodeConfigs(WorkflowFragment fragment)
        {
            var configs = new List<NodeConfig>();
            foreach (var fragNode in fragment.Nodes)
            {
                var config = new NodeConfig
                {
                    Symbol = fragNode.Symbol,
                    NodeId = fragNode.NodeId,
                    FuncName = fragNode.FuncName,
                    ParameterKeys = fragNode.ParameterKeys?.ToArray(),
                    ResultKeys = fragNode.ResultKeys?.ToArray()
                };

                if (fragNode.NextNodeConfig != null)
                {
                    config.NextNodeConfig = new NodeConfig.NextNodeConfig
                    {
                        Configs = fragNode.NextNodeConfig
                    };
                }

                configs.Add(config);
            }
            return configs;
        }

        /// <summary>
        /// 将 WfContext 的 Items 转换为普通 Dictionary
        /// </summary>
        private Dictionary<string, object> ConvertContextItems(WfContext context)
        {
            var items = new Dictionary<string, object>();
            foreach (var kvp in context.Items)
                items[kvp.Key] = kvp.Value;
            return items;
        }
    }
}
```

### 步骤 2：改造 SKPlannerFunction — 输出结构化 JSON

**文件：** `src/Agent.Planner/SKPlannerFunction.cs`

核心改动：让 LLM 输出结构化 JSON 工作流片段，而非纯文本。

```csharp
// ============================================================
// SKPlannerFunction.cs — 改造后的 Semantic Kernel 规划器
//
// 改造要点：
//   1. 系统提示词要求 LLM 输出 JSON 工作流片段
//   2. 将 MCP 工具注册为 SK Plugin，启用 Auto Function Calling
//   3. 将 FunctionCall 结果转换为 JSON 工作流片段
// ============================================================

using System;
using System.Collections.Generic;
using System.Linq;
using System.Text.Json;
using System.Threading.Tasks;
using Microsoft.SemanticKernel;
using Microsoft.SemanticKernel.ChatCompletion;
using Microsoft.SemanticKernel.Connectors.OpenAI;
using WorkFlowMethod.Usage;
using WfContext = WorkFlowMethod.Orchestration.Context.Models.WorkflowContext;

namespace Agent.Planner
{
    public static class SKPlannerFunction
    {
        private static Kernel? _kernel;

        public static void Initialize(string? apiKey = null, string modelId = "deepseek-chat")
        {
            _kernel = SemanticKernelFactory.CreateDeepSeekKernel(apiKey, modelId);
            RegisterMcpToolsAsPlugins();
        }

        public static void Register()
        {
            _kernel ??= SemanticKernelFactory.CreateDeepSeekKernel();
            RegisterMcpToolsAsPlugins();

            WorkFlowMethodUsage.RegisterAsyncFunction("sk_plan", ExecutePlanAsync);
            WorkFlowMethodUsage.RegisterAsyncFunction("sk_chat", ExecuteChatAsync);

            Console.WriteLine("[Planner] 已注册函数: sk_plan, sk_chat");
        }

        /// <summary>
        /// 将 MCP 工具注册为 Semantic Kernel 的 Plugin
        /// 使 LLM 可以通过 Auto Function Calling 感知可用工具
        /// </summary>
        private static void RegisterMcpToolsAsPlugins()
        {
            try
            {
                // 获取所有已注册的 MCP 工具
                var toolNames = WorkFlowMethodUsage.GetAllFunctionNames()
                    .Where(n => n.StartsWith("mcp_"))
                    .ToList();

                if (toolNames.Count == 0)
                {
                    Console.WriteLine("[Planner] 未发现 MCP 工具函数");
                    return;
                }

                // 为每个 MCP 工具创建 SK Plugin
                foreach (var toolName in toolNames)
                {
                    // 通过 KernelFunctionFactory 创建 SK Function
                    var skFunction = KernelFunctionFactory.CreateFromMethod(
                        async (string server, string tool, string arguments) =>
                        {
                            var context = new WfContext(
                                parameters: new Dictionary<string, object>
                                {
                                    ["server"] = server,
                                    ["tool"] = tool,
                                    ["arguments"] = JsonSerializer.Deserialize<Dictionary<string, object>>(arguments ?? "{}") ?? new()
                                },
                                data: new Dictionary<string, object>(),
                                executionId: Guid.NewGuid().ToString(),
                                nodeKey: toolName,
                                workflowId: "agent-dynamic"
                            );
                            return await WorkFlowMethodUsage.CallBridgedFunctionAsync(toolName, context);
                        },
                        toolName,
                        "MCP tool: " + toolName
                    );

                    _kernel!.Plugins.AddFromObject(new { Function = skFunction }, $"McpTools_{toolName}");
                }

                Console.WriteLine($"[Planner] 已注册 {toolNames.Count} 个 MCP 工具到 SK Plugin");
            }
            catch (Exception ex)
            {
                Console.WriteLine($"[Planner] 注册 MCP 工具到 SK 失败: {ex.Message}");
            }
        }

        /// <summary>
        /// 执行规划 — 输出 JSON 工作流片段
        /// </summary>
        private static async Task<object> ExecutePlanAsync(WfContext context)
        {
            var input = context.Parameters.TryGetValue("input", out var inp)
                ? inp?.ToString() ?? ""
                : "";

            if (string.IsNullOrWhiteSpace(input))
                return new { status = "error", message = "缺少 input 参数" };

            var chatCompletion = _kernel!.GetRequiredService<IChatCompletionService>();
            var chatHistory = new ChatHistory();

            // ========== 增强的系统提示词 ==========
            chatHistory.AddSystemMessage(@"你是一个编程智能体助手。你的任务是将用户需求分解为一系列可执行的步骤。

可用工具：
- mcp_call_tool(server, tool, arguments) — 调用 MCP 工具
- mcp_list_tools(server) — 列出 MCP 服务器的可用工具
- sk_chat(input) — 纯文本聊天/分析

你必须以 JSON 格式输出工作流片段，格式如下：
{
  ""workflow_fragment"": {
    ""nodes"": [
      {
        ""NodeId"": ""step_1"",
        ""FuncName"": ""mcp_call_tool"",
        ""ParameterValues"": {
          ""server"": ""filesystem"",
          ""tool"": ""read_file"",
          ""arguments"": { ""path"": ""/workspace/main.py"" }
        },
        ""ResultKeys"": [""file_content""]
      }
    ],
    ""key_mapping"": {
      ""file_content"": ""analysis_input""
    }
  }
}

规则：
1. 每个步骤必须是一个可执行的函数调用
2. 使用 ResultKeys 指定输出数据的键名
3. 使用 key_mapping 将上一步的输出映射为下一步的输入
4. 步骤之间按顺序执行
5. 只输出 JSON，不要包含其他文本");

            // 添加对话历史
            if (context.Parameters.TryGetValue("history", out var history) && history is List<object> historyList)
            {
                foreach (var msg in historyList)
                {
                    if (msg is Dictionary<string, object> dict)
                    {
                        if (dict.TryGetValue("role", out var role) && dict.TryGetValue("content", out var content))
                        {
                            chatHistory.AddMessage(
                                role?.ToString() == "assistant"
                                    ? AuthorRole.Assistant
                                    : AuthorRole.User,
                                content?.ToString() ?? "");
                        }
                    }
                }
            }

            // 添加上下文信息（可用工具列表等）
            var availableTools = GetAvailableToolsSummary();
            chatHistory.AddSystemMessage($"当前可用工具:\n{availableTools}");

            // 添加用户输入
            chatHistory.AddUserMessage(input);

            // 调用 LLM（启用 Auto Function Calling）
            var executionSettings = new OpenAIPromptExecutionSettings
            {
                ToolCallBehavior = ToolCallBehavior.AutoInvokeKernelFunctions,
                Temperature = 0.1,  // 低温度确保输出结构化
                ResponseFormat = "json_object"  // 要求 JSON 格式输出
            };

            var result = await chatCompletion.GetChatMessageContentAsync(
                chatHistory, executionSettings, _kernel!);

            var content = result.Content ?? "";

            // 验证输出是否为有效的 JSON 工作流片段
            if (!IsValidWorkflowFragment(content))
            {
                // 如果 LLM 没有输出 JSON，尝试将 Auto Function Calling 结果转换为 JSON
                content = ConvertFunctionCallResultToFragment(result, input);
            }

            return new
            {
                status = "success",
                content = content,
                role = "assistant",
                is_workflow_fragment = true
            };
        }

        /// <summary>
        /// 将 Auto Function Calling 的结果转换为 JSON 工作流片段
        /// </summary>
        private static string ConvertFunctionCallResultToFragment(
            ChatMessageContent result, string originalInput)
        {
            var nodes = new List<object>();

            // 检查是否有工具调用
            if (result.ToolCallCount > 0)
            {
                foreach (var toolCall in result.ToolCalls)
                {
                    if (toolCall is FunctionCallContent functionCall)
                    {
                        var node = new Dictionary<string, object>
                        {
                            ["NodeId"] = $"step_{nodes.Count + 1}",
                            ["FuncName"] = functionCall.FunctionName,
                            ["ParameterValues"] = functionCall.Arguments?.ToDictionary(
                                kvp => kvp.Key,
                                kvp => kvp.Value?.ToString() ?? "") ?? new Dictionary<string, object>(),
                            ["ResultKeys"] = new[] { $"{functionCall.FunctionName}_result" }
                        };
                        nodes.Add(node);
                    }
                }
            }

            // 如果没有工具调用，创建一个 sk_chat 节点
            if (nodes.Count == 0)
            {
                nodes.Add(new Dictionary<string, object>
                {
                    ["NodeId"] = "chat",
                    ["FuncName"] = "sk_chat",
                    ["ParameterValues"] = new Dictionary<string, object>
                    {
                        ["input"] = originalInput
                    },
                    ["ResultKeys"] = new[] { "chat_result" }
                });
            }

            var fragment = new Dictionary<string, object>
            {
                ["workflow_fragment"] = new Dictionary<string, object>
                {
                    ["nodes"] = nodes,
                    ["key_mapping"] = new Dictionary<string, object>()
                }
            };

            return JsonSerializer.Serialize(fragment, new JsonSerializerOptions { WriteIndented = true });
        }

        /// <summary>
        /// 验证字符串是否为有效的工作流片段 JSON
        /// </summary>
        private static bool IsValidWorkflowFragment(string json)
        {
            try
            {
                using var doc = JsonDocument.Parse(json);
                var root = doc.RootElement;

                // 检查是否有 workflow_fragment 或 nodes 字段
                if (root.TryGetProperty("workflow_fragment", out var fragment))
                    return fragment.TryGetProperty("nodes", out _);

                if (root.TryGetProperty("nodes", out var nodes))
                    return nodes.GetArrayLength() > 0;

                return false;
            }
            catch
            {
                return false;
            }
        }

        /// <summary>
        /// 获取可用工具摘要
        /// </summary>
        private static string GetAvailableToolsSummary()
        {
            var functions = WorkFlowMethodUsage.GetAllFunctionNames().ToList();
            return string.Join("\n", functions.Select(f => $"  - {f}"));
        }

        /// <summary>
        /// 纯聊天（无工具调用）
        /// </summary>
        private static async Task<object> ExecuteChatAsync(WfContext context)
        {
            var input = context.Parameters.TryGetValue("input", out var inp)
                ? inp?.ToString() ?? ""
                : "";

            if (string.IsNullOrWhiteSpace(input))
                return new { status = "error", message = "缺少 input 参数" };

            var chatCompletion = _kernel!.GetRequiredService<IChatCompletionService>();
            var chatHistory = new ChatHistory();

            chatHistory.AddSystemMessage("你是一个智能助手，请直接回答用户的问题。");
            chatHistory.AddUserMessage(input);

            var result = await chatCompletion.GetChatMessageContentAsync(chatHistory);

            return new
            {
                status = "success",
                content = result.Content,
                role = "assistant"
            };
        }
    }
}
```

### 步骤 3：改造 AgentLoopFunction — 集成动态合并引擎

**文件：** `src/Agent.Core/AgentLoopFunction.cs`

```csharp
// ============================================================
// AgentLoopFunction.cs — 改造后的 Agent 主循环函数
//
// 改造要点：
//   1. 集成 DynamicWorkflowMerger
//   2. 实现 ReAct 循环（规划→执行→观察→再规划）
//   3. 支持最大迭代次数和停止条件
// ============================================================

using System;
using System.Collections.Generic;
using System.Text.Json;
using System.Threading.Tasks;
using WorkFlowMethod.Usage;
using WfContext = WorkFlowMethod.Orchestration.Context.Models.WorkflowContext;

namespace Agent.Core
{
    public static class AgentLoopFunction
    {
        private static readonly DynamicWorkflowMerger _merger = new();

        // 循环控制参数
        private const int MaxIterations = 25;
        private const int MaxTokensPerRound = 8000;

        public static void Register()
        {
            WorkFlowMethodUsage.RegisterAsyncFunction("agent_loop", ExecuteAsync);
            Console.WriteLine("[Agent] 已注册函数: agent_loop (支持动态工作流合并)");
        }

        private static async Task<object> ExecuteAsync(WfContext context)
        {
            var userInput = context.Parameters.TryGetValue("user_input", out var input)
                ? input?.ToString() ?? ""
                : "";

            if (string.IsNullOrWhiteSpace(userInput))
                return new { status = "error", message = "缺少 user_input 参数" };

            Console.WriteLine($"[Agent] 收到用户输入: {userInput}");

            // 初始化对话历史
            var history = new List<Dictionary<string, object>>();
            var iteration = 0;
            object? lastResult = null;

            // ========== ReAct 主循环 ==========
            while (iteration < MaxIterations)
            {
                iteration++;
                Console.WriteLine($"[Agent] === 迭代 {iteration}/{MaxIterations} ===");

                // ---- 步骤 A：输入安全过滤 ----
                var safeInput = await CallGuardFunction("guard_input",
                    new Dictionary<string, object> { ["input"] = iteration == 1 ? userInput : lastResult });

                // ---- 步骤 B：LLM 规划 ----
                var planResult = await CallPlanner(safeInput, history);

                // 检查 LLM 是否认为任务已完成
                if (IsTaskComplete(planResult))
                {
                    Console.WriteLine("[Agent] LLM 判定任务完成");
                    lastResult = planResult;
                    break;
                }

                // ---- 步骤 C：检查是否为 JSON 工作流片段 ----
                if (IsJsonWorkflowFragment(planResult))
                {
                    Console.WriteLine("[Agent] 检测到 JSON 工作流片段，开始动态合并执行");

                    // 创建子上下文用于动态执行
                    var dynamicContext = new WfContext(
                        parameters: new Dictionary<string, object>(),
                        data: new Dictionary<string, object>
                        {
                            ["history"] = history,
                            ["iteration"] = iteration,
                            ["user_input"] = userInput
                        },
                        executionId: context.ExecutionId + $"_iter_{iteration}",
                        nodeKey: "dynamic_execution",
                        workflowId: "agent-dynamic"
                    );

                    // 合并并执行动态工作流
                    var execResult = await _merger.MergeAndExecuteAsync(planResult, dynamicContext);

                    // 记录执行结果到历史
                    history.Add(new Dictionary<string, object>
                    {
                        ["role"] = "assistant",
                        ["content"] = $"[执行工作流片段] 结果: {JsonSerializer.Serialize(execResult)}"
                    });

                    lastResult = execResult;
                }
                else
                {
                    // 纯文本回复，直接记录
                    history.Add(new Dictionary<string, object>
                    {
                        ["role"] = "assistant",
                        ["content"] = planResult
                    });
                    lastResult = planResult;
                    break;  // 纯文本回复通常意味着任务完成
                }

                // ---- 步骤 D：输出安全过滤 ----
                lastResult = await CallGuardFunction("guard_output",
                    new Dictionary<string, object> { ["output"] = lastResult });

                // ---- 步骤 E：上下文压缩（AFM 策略） ----
                if (ShouldCompressContext(history))
                {
                    history = CompressHistory(history);
                    Console.WriteLine("[Agent] 已压缩对话历史");
                }
            }

            // 输出最终结果
            var finalOutput = await CallGuardFunction("guard_output",
                new Dictionary<string, object> { ["output"] = lastResult ?? "无结果" });

            return new
            {
                status = "success",
                input = userInput,
                output = finalOutput,
                iterations = iteration,
                timestamp = DateTime.UtcNow
            };
        }

        /// <summary>
        /// 调用护栏函数
        /// </summary>
        private static async Task<string> CallGuardFunction(string funcName, Dictionary<string, object> parameters)
        {
            var context = new WfContext(
                parameters: parameters,
                data: new Dictionary<string, object>(),
                executionId: Guid.NewGuid().ToString(),
                nodeKey: funcName,
                workflowId: "agent-loop"
            );

            var result = await WorkFlowMethodUsage.CallBridgedFunctionAsync(funcName, context);
            return result?.ToString() ?? "";
        }

        /// <summary>
        /// 调用规划器
        /// </summary>
        private static async Task<string> CallPlanner(string input, List<Dictionary<string, object>> history)
        {
            var context = new WfContext(
                parameters: new Dictionary<string, object>
                {
                    ["input"] = input,
                    ["history"] = history
                },
                data: new Dictionary<string, object>(),
                executionId: Guid.NewGuid().ToString(),
                nodeKey: "sk_plan",
                workflowId: "agent-loop"
            );

            var result = await WorkFlowMethodUsage.CallBridgedFunctionAsync("sk_plan", context);

            // 从规划器结果中提取 content 字段
            if (result is Dictionary<string, object> dict &&
                dict.TryGetValue("content", out var content))
            {
                return content?.ToString() ?? "";
            }

            return result?.ToString() ?? "";
        }

        /// <summary>
        /// 检查 LLM 输出是否表示任务完成
        /// </summary>
        private static bool IsTaskComplete(string output)
        {
            // 检查是否包含任务完成标记
            if (string.IsNullOrEmpty(output)) return true;

            try
            {
                using var doc = JsonDocument.Parse(output);
                var root = doc.RootElement;

                // 检查 workflow_fragment 中是否有 status: complete
                if (root.TryGetProperty("workflow_fragment", out var fragment))
                {
                    if (fragment.TryGetProperty("status", out var status))
                        return status.GetString() == "complete";
                }

                if (root.TryGetProperty("status", out var directStatus))
                    return directStatus.GetString() == "complete";
            }
            catch
            {
                // 非 JSON 输出，视为普通回复
            }

            return false;
        }

        /// <summary>
        /// 检查字符串是否为 JSON 工作流片段
        /// </summary>
        private static bool IsJsonWorkflowFragment(string output)
        {
            if (string.IsNullOrEmpty(output)) return false;

            try
            {
                using var doc = JsonDocument.Parse(output);
                var root = doc.RootElement;

                // 包含 workflow_fragment 或 nodes 字段
                if (root.TryGetProperty("workflow_fragment", out var fragment))
                    return fragment.TryGetProperty("nodes", out var nodes) && nodes.GetArrayLength() > 0;

                if (root.TryGetProperty("nodes", out var directNodes))
                    return directNodes.GetArrayLength() > 0;

                return false;
            }
            catch
            {
                return false;
            }
        }

        /// <summary>
        /// 判断是否需要压缩上下文
        /// </summary>
        private static bool ShouldCompressContext(List<Dictionary<string, object>> history)
        {
            // 粗略估计 Token 数（每个条目约 50 token）
            return history.Count > 10 || EstimateTokens(history) > MaxTokensPerRound;
        }

        /// <summary>
        /// 估算历史 Token 数
        /// </summary>
        private static int EstimateTokens(List<Dictionary<string, object>> history)
        {
            int total = 0;
            foreach (var entry in history)
            {
                if (entry.TryGetValue("content", out var content) && content is string str)
                    total += str.Length / 2;  // 粗略估计：中文字符约 2 字符/token
            }
            return total;
        }

        /// <summary>
        /// 压缩对话历史（保留最近 N 条 + 关键信息摘要）
        /// </summary>
        private static List<Dictionary<string, object>> CompressHistory(
            List<Dictionary<string, object>> history)
        {
            // 保留最近 5 条完整记录
            var recent = history.Count > 5
                ? history.GetRange(history.Count - 5, 5)
                : new List<Dictionary<string, object>>(history);

            // 创建摘要
            var summary = new Dictionary<string, object>
            {
                ["role"] = "system",
                ["content"] = $"[上下文摘要] 之前的对话共 {history.Count} 轮，" +
                              $"已完成 {history.Count - recent.Count} 轮交互。"
            };

            recent.Insert(0, summary);
            return recent;
        }
    }
}
```

## 六、关键设计决策

### 6.1 为什么选择 ExecuteFromJsonAsync 而非 ConnectChainInfoConfig？

| 方式 | 优点 | 缺点 |
|------|------|------|
| `ExecuteFromJsonAsync` | 简单直接，无需预注册 | 每次执行独立，无法跨步骤共享状态 |
| `ConnectChainInfoConfig` | 支持链式拼接，状态共享 | 需要预注册 ChainInfo，复杂度高 |

**决策：** 初期使用 `ExecuteFromJsonAsync` 快速实现，后续可升级为 `ConnectChainInfoConfig` 以获得更好的状态共享能力。

### 6.2 为什么在 AgentLoopFunction 内部实现循环而非使用 LoopFramework？

| 方式 | 优点 | 缺点 |
|------|------|------|
| 内部循环 | 实现简单，控制灵活 | 与框架耦合度低 |
| LoopFramework | 标准化循环控制 | 需要适配 WfContext 类型 |

**决策：** 初期使用内部循环实现，后续可迁移到 `LoopFramework` 以获得更标准的循环控制（最大迭代、超时、停止条件等）。

### 6.3 上下文压缩策略

采用 AFM（Auto-Fact-Management）风格的压缩策略：
1. **保留最近 N 条完整记录**（默认 5 条）
2. **创建历史摘要**：记录已完成的轮数和关键决策
3. **选择性保留**：只保留与当前任务相关的上下文

## 七、风险与注意事项

### 7.1 JSON 输出稳定性
- LLM 可能输出格式不正确的 JSON
- 需要健壮的解析和降级策略
- 建议使用 `ResponseFormat = "json_object"` 强制 JSON 输出

### 7.2 工具调用安全性
- MCP 工具可能执行危险操作（文件删除、命令执行等）
- 护栏函数必须严格检查参数
- 建议实现白名单机制

### 7.3 循环终止条件
- 必须设置最大迭代次数（建议 25 次）
- 必须设置超时时间（建议 15 分钟）
- LLM 可能陷入无限循环，需要检测重复模式

### 7.4 上下文窗口限制
- LLM 上下文窗口有限（DeepSeek 约 128K tokens）
- 需要主动压缩历史
- 建议实现滑动窗口策略

5. 实现后，Agent 将具备 Cline 风格的动态工作流生成能力：感知→思考→行动→观察→再规划
