## 二、当前仍存在的重复逻辑

### 2.1 LogPipelineContext 与 FileDrivenPipelineContext 字段重复 ✅ 已修复

**修复方式：** 使用组合模式创建 `BatchContextData` 共享数据类（`FileDriven.Logging/BatchContextData.cs`），
两个上下文类各自包含一个 `BatchContextData` 实例，保留便捷属性保持向后兼容。

**涉及文件：**
- `FileDriven.Logging/BatchContextData.cs`（新建）
- `FileDriven.Logging/LogPipeline.cs`（`LogPipelineContext` 添加 `BatchData` 属性）
- `FileDriven.Pipeline/FileDrivenPipelineContext.cs`（待添加 `BatchData` 属性）

### 2.2 CommandEngine 与 NonEventCommandHandler 命令重复 ⚠️ 低等

**重复命令：** `sleep`, `echo`, `exit`

| 位置 | 文件 |
|------|------|
| `CommandEngine.RegisterBuiltInCommands()` | `CommandExecution.cs` |
| `NonEventCommandHandler.Handle()` switch 分支 | `NonEventCommandHandler.cs` |

**影响：** 两个地方维护相同的命令处理逻辑，新增命令需同步修改。

### 2.3 CliPipelineRunner 冗余委托方法 ✅ 已修复

**修复方式：** 移除 `CliPipelineRunner.SetupLogging()` 和 `CliPipelineRunner.ShutdownLogging()` 方法。
日志设置/关闭统一通过 `Usage.SetupLogging()` / `Usage.ShutdownLogging()` 调用。

**涉及文件：**
- `FileDriven.Launcher/Runners/CliPipelineRunner.cs`

### 2.4 批次 ID 生成逻辑重复 ✅ 已修复

**修复方式：** `CliPipelineRunner.Run()` 中的回退批次 ID 格式从 `{modePrefix}-{yyyyMMdd-HHmmss}` 
统一为 `Run_{yyyyMMdd_HHmmss}`，与 `FrameworkInitializer.InitializeBatchLogging()` 保持一致。

**涉及文件：**
- `FileDriven.Launcher/Runners/CliPipelineRunner.cs`

### 2.5 路径解析逻辑重复 ⚠️ 低等

| 位置 | 功能 |
|------|------|
| `ScriptLoadSkeleton.ExecuteCore()` | JSON 脚本转换 + 命令文件路径解析 |
| `GuiModeRunner.ResolveCommandFile()` | JSON 脚本转换 + 命令文件路径解析 |

### 2.6 日志写入方式重复 ℹ️ 轻微

- `LoggingSkeletonWrapper` 直接调用 `PlaceholderLogHelper.Log()`
- `LogEntryBuilder` 直接调用 `PlaceholderLogHelper.Log()`

### 2.7 委托链过长 ℹ️ 轻微

`PipelineEntry.CreateFileDrivenPipeline()` → `PipelineFactory.CreateFileDrivenPipeline()`
